## 🎯 核心能力




**一句话**: 输入任意关键词/定额编号/自然语言问题，自动返回匹配的定额条目 + 相关解释 + 政府文件依据。

### 三层匹配架构




```
用户查询
  │
  ├─ 第一层: 定额条目匹配 (28,920 条)
  │    → 精确编号 + 关键词 + 语义搜索
  │
  ├─ 第二层: 定额解释匹配 (7 份综合解释)
  │    → Q&A 对提取 + 关联定额编号
  │
  └─ 第三层: 政府文件匹配 (30+ 份)
       → 文件分类 + 条款提取 + 适用范围
```

### 匹配模式




| 模式 | 输入 | 输出 | 引擎 |
|------|------|------|------|
| 编号查询 | `DA0001` | 定额详情 + 解释 + 文件 | 精确匹配 |
| 关键词搜索 | `混凝土浇筑` | 相关定额 + 解释 | 关键词 + 语义 |
| 自然语言 | `安全文明施工费怎么算？` | 解释Q&A + 定额依据 | 语义搜索 |
| 文件查询 | `渝建管〔2024〕38号` | 文件内容 + 关联定额 | 文档检索 |

## 🔍 匹配算法




### 1. 定额编号识别




```python

# 识别定额编号格式: 2字母 + 4数字



# 例: AA0001, DA0123, KA0456



import re
QUOTA_CODE_PATTERN = re.compile(r'([A-Z]{2})(\d{4})')
```

## 2. 关键词匹配




- **精确匹配**: 定额名称完全包含关键词
- **分词匹配**: jieba 分词后，任意词匹配
- **同义词扩展**: 混凝土=砼, 钢筋=螺纹钢

### 3. 语义搜索




- 使用 sentence-transformers (已安装)
- ChromaDB 向量数据库 (已安装)
- 中文优化模型: `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`

### 4. Q&A 匹配




- 从 7 份综合解释中提取 Q&A 对
- 问题向量化存储
- 用户问题 → 语义相似度匹配 → 返回最接近的 Q&A
