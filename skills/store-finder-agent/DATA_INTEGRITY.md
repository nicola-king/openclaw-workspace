# 开店寻址 Agent — 数据真实性铁律

> 写入日期：2026-05-16 | 优先级：宪法级

---

## 核心原则

**开店寻址 Agent 输出的所有数据必须为真实数据。严禁使用虚假、模拟或硬编码数据。**

## 数据来源优先级

| 优先级 | 来源 | 说明 |
|:----:|------|------|
| 1 | 太一共享搜索 | 调用 `data_layer/search_adapter.py` 获取实时数据 |
| 2 | 太一情报引擎 | `shared_search_service.py` 统一情报接口 |
| 3 | 公开API | Google Maps / 高德 / 政府公开数据 |
| 4 | 政府统计公报 | 统计局/商务部/地方政府公开数据 |
| 5 | 后备说明 | 以上均不可用时，标注"示例数据"并注明来源限制 |

## 禁止行为

- ❌ 硬编码虚构店铺名称（如"五道口店""南山店"用于重庆报告）
- ❌ 模拟人流/竞品等关键指标
- ❌ 使用不相关的样本数据代替目标城市数据
- ❌ 未经标注的虚假预算明细

## 违反后果

违反本原则的报告须标注「数据不可靠」并记录到自进化日志。
重复违反触发 SRE 自检并阻断输出。

## 执行检查

每次 `generate_report.py` 运行时自动检查：
1. 城市数据是否来自搜索或公开数据
2. 店铺名称是否匹配目标城市
3. 经济数据是否有真实来源标注
4. 不符合则阻断生成并提示
