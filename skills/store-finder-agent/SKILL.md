# 开店寻址 Agent — 太一智能店铺选址系统

> 商铺选址 + 投资分析 + 经济周期适配 + 真实租金数据爬取

## 功能概述

根据投资预算、业态类型和目标城市，自动生成投资选址报告，包含：
- 区域分析（多个候选点综合对比）
- 商业租金真实数据（穿透爬虫）
- 经济周期适配（动态经济背景）
- 财务测算（ROI/盈亏平衡/回本周期）
- 排名建议（1/2/3名）

## 使用方式

### 直接对话（推荐）

发送消息格式：
```
在 [城市] [区域] 开 [业态]，投资 [金额] 元
```

示例：
- `在重庆市大渡口+九龙坡区开一家重庆包子店，投资10万元`
- `在成都市武侯区南门+西门区域开中式茶馆，投资500万元开3个店`
- `在重庆江北区+渝北区开精品咖啡馆，投资30万元`

### 修复/补充

- `把大渡口巴国城加入对比`
- `重新出一份2026年8月的报告`

### 报告输出格式

报告自动输出为：
```
TaiYi · ☕️/🍜 城市·区域·业态投资选址报告
TaiYi Investment Research · 对标投行标准（PitchBook / McKinsey 格式）
```

## Skill 模块

| Skill | 文件 | 功能 |
|-------|------|------|
| 经济背景分析 | `skills/economic_background.py` | 自动获取宏观/行业经济指标·适配策略 |
| 租房爬虫 | `skills/rental_crawler.py` | 穿透搜索安居客/贝壳/58·加权租金 |
| 租金识别器 | `skills/rental_crawler.py (RentDifferentiator)` | 商业/住宅/写字楼自动匹配 |

## 报告目录

生成的报告保存在 `reports/` 目录下，Markdown 格式可直接阅读。
