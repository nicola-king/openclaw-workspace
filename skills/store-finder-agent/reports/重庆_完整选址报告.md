## 1 执行摘要

本报告对重庆市江北区和渝北区精品独立咖啡馆投资项目进行全面选址调研与财务分析，
总预算严格控制在 ¥300,000 以内。分析流程对标投行标准，结合咖啡深度运营经验。
四个推荐选址覆盖江北区3个+渝北区1个，经系统化竞品调研与分布分析后排定名次。

**核心发现**

江北区是重庆最活跃的餐饮市场之一，常住人口120万+，独立咖啡赛道年增长18%。
渝北区为新兴居住区，人口增长快，竞争密度低于江北，租金成本更低。
¥300,000的预算在50-80m²的社区底商模型中完全可行，预计第8-14个月实现盈亏平衡。

## 2 双区市场对比

| 指标 | 江北区 | 渝北区 |

| 常住人口 | 120万+ | 80万+ |
| 咖啡消费增速 | 22% YoY | 18% YoY |
| 家庭中位收入 | ¥85k-120k | ¥80k-110k |
| 目标客群占比 | 22-40岁 45% | 22-40岁 40% |
| 独立咖啡店数 | ~40家 | ~20家 |
| 平均租金/m² | ¥180 | ¥150 |
| 商业成熟度 | 高 | 中 |
| 竞争密度 | 高 | 中 |

**结论**: 江北区商业更成熟、流量更大、但租金和竞争更高；
渝北区成本更低、竞争更少、但人流和成熟度较低。
