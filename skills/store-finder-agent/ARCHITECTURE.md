# 开店寻址 Agent — 统一智能决策平台

> 开店经商寻址 + 专业投资分析 融合智能 Agent
> 一体化智能决策平台：从选址寻址 → 投资分析 → 决策建议 → 执行落地 → 运营迭代（全流程闭环）

---

## 一、数据层

| 数据源 | 说明 | 存储 |
|--------|------|------|
| 国内外地图API | Google Maps / 高德 / Bing / OSM | — |
| POI数据 | 商圈兴趣点 | PostGIS |
| 招租信息 | 店面出租数据 | PostGIS |
| 历史开店数据 | 成功/失败案例 | 数据仓库 |
| 用户行为数据 | 客群画像 | 数据仓库 |
| 经济数据 | GDP/消费/人口 | CSV/API |

**存储架构：** PostGIS（空间数据） + Redis（缓存） + MinIO（文件）

---

## 二、核心 Agent 模块（6个）

| Agent | 功能 | 技术 | 阶段 |
|-------|------|------|------|
| **城市+商圈识别** | 商圈边界 + 热力图 | Google Places API + Folium | ✅ MVP |
| **店面候选筛选** | 面积/租金/人流/交通评分 | Pandas + 多因子评分 | ✅ MVP |
| **门头可视性** | CV识别·街景分析 | YOLOv8 / SAM | 🔴 Phase 2 |
| **消费能力与客群画像** | NLP + 数据统计 | NLP / 统计局数据 | 🔴 Phase 2 |
| **ROI预测** | LightGBM / XGBoost / 贝叶斯 | LightGBM | ✅ MVP |
| **决策与推荐** | 综合评分·投资建议 | 加权评分 | 🟡 Phase 1 |

---

## 三、投资分析报告模块

| 输出 | 用途 | 格式 |
|------|------|------|
| 商圈热力图 | 空间分布可视化 | Folium HTML |
| 店面排名 | 候选排序 + 评分 | Excel / CSV |
| ROI预测报告 | 投资回报分析 | PDF / Excel |
| 敏感性分析 | 关键变量影响 | 图表 |
| 投资等级建议 | 综合决策输出 | PDF |

---

## 五、融合优势

1. **单一平台决策闭环** — 数据采集→分析→ROI预测→报告→反馈→优化，全程一个系统
2. **专业性+智能化** — 可交付投资报告 + 持续迭代优化决策模型
3. **模块化可扩展** — 门头识别/消费画像/人流预测按需接入
4. **多场景适用** — 餐饮/零售/服务等业态，调整权重即可
