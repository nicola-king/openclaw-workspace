# self-evolution 模块

Art Agent 自进化系统，集成太一宪法原则，驱动美学引擎持续优化。

## 功能
- 宪法学习循环 (Elon 五步/负熵/冰山/第一性/二阶)
- 8 条宪法规则 (CONST-001~005, STRAT-001~003)
- 7 维度进化指标追踪
- 知识沉淀管道

## 使用
```bash
# 独立运行
python core.py

# 执行宪法学习循环
python core.py --task constitution_learning --module-name aesthetic-filter

# 获取进化指标
python core.py --task get_metrics
```
