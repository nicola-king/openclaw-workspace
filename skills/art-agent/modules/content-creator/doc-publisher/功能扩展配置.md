## 🚀 使用示例

### 导出 Word
```bash
python3 doc-publisher-extensions.py word "文档.md"
python3 doc-publisher-extensions.py word "文档.md" "输出.docx"
```

### 发送邮件
```bash
python3 doc-publisher-extensions.py email "文档.pdf" "文档主题" "user1@example.com,user2@example.com"
```

### 发送微信
```bash
python3 doc-publisher-extensions.py wechat "文档.pdf" "文档标题" "user1|user2"
python3 doc-publisher-extensions.py wechat "文档.pdf" "文档标题" "@all"
```

### 发布网页
```bash
python3 doc-publisher-extensions.py web "文档.md"
python3 doc-publisher-extensions.py web "文档.md" "/var/www/html"
```

### 批量发布
```bash
python3 doc-publisher-extensions.py batch "/home/sayelf/.openclaw/workspace" "pdf,docx,html"
```

## 🔗 集成到自动化流程

### 完整流程
```bash
# 1. 创建文档
vi "文档.md"

# 2. 发布 PDF 到 Telegram
bash auto-publish-doc.sh "文档.md"

# 3. 导出 Word
python3 doc-publisher-extensions.py word "文档.md"

# 4. 发布网页
python3 doc-publisher-extensions.py web "文档.md"

# 5. 发送邮件
python3 doc-publisher-extensions.py email "文档.pdf" "文档主题" "team@example.com"

# 6. 发送微信
python3 doc-publisher-extensions.py wechat "文档.pdf" "文档标题" "@all"
```

### 一键发布脚本
```bash
#!/bin/bash
# publish-all.sh

DOC="$1"

echo "🚀 开始全渠道发布：$DOC"

# PDF + Telegram
bash auto-publish-doc.sh "$DOC"

# Word
python3 doc-publisher-extensions.py word "$DOC"

# Web
python3 doc-publisher-extensions.py web "$DOC"

# Email
python3 doc-publisher-extensions.py email "${DOC%.md}.pdf" "新文档发布" "team@example.com"

# WeChat
python3 doc-publisher-extensions.py wechat "${DOC%.md}.pdf" "新文档发布" "@all"

echo "✅ 全渠道发布完成！"
```
