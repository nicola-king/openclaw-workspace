## 🎯 核心使命

提供太一系统视觉叙事能力，将数据转化为有故事性的视觉呈现。

### 叙事原则

| 原则 | 说明 |
|------|------|
| **故事性** | 数据要有叙事线索 |
| **可视化** | 用图表讲述故事 |
| **情感化** | 引发用户共鸣 |
| **简洁性** | 信息清晰不冗余 |

---

## 📦 模块功能

### 叙事生成

```python
from visual_narrative import VisualNarrative

narrative = VisualNarrative()
story = narrative.create(data, theme="市场趋势")
```

### 可视化优化

```python
optimized = narrative.optimize(story, style="minimalist")
```

---

## 🚀 使用方式

### 1. 独立运行

```bash
python core.py --create "市场趋势" --data data.json
```

### 2. 太一系统集成

```python
from visual_narrative import VisualNarrative

narrative = VisualNarrative()
story = narrative.create(report_data, theme="季度报告")
```
