## 🏠 室内设计案例

### 案例 1: 侘寂客厅设计

**项目信息**:
- 面积：80 平米
- 风格：侘寂 + 现代
- 预算：中等
- 地点：城市公寓

**设计要点**:
| 元素 | 材料 | 色彩 | 比例 |
|------|------|------|------|
| 地板 | 原木地板 (做旧) | 深棕色 | 60% |
| 墙面 | 微水泥 + 留白 | 米白色 | 25% |
| 家具 | 低矮沙发 (麻布) | 浅灰色 | 10% |
| 装饰 | 陶土花器 + 枯枝 | 自然色 | 5% |

**侘寂评分**:
| 维度 | 得分 | 说明 |
|------|------|------|
| 材料自然度 | 95/100 | 原木 + 微水泥 |
| 时间痕迹 | 90/100 | 做旧处理 |
| 简约程度 | 92/100 | 极简布局 |
| 空间留白 | 88/100 | 40% 留白 |
| 色彩朴素 | 95/100 | 大地色系 |
| 手工质感 | 85/100 | 部分手工 |
| **总分** | **91/100** | ⭐⭐⭐⭐⭐ 纯正侘寂 |

**设计图**:
```
┌─────────────────────────────────┐
│     留白墙面 (40%)               │

│  [枯枝装饰]      [落地窗]       │
│                                 │
│        [低矮沙发]               │
│                                 │
│  [陶土花器]      [原木茶几]     │
```

### 案例 8: 侘寂建筑设计 (巴瓦风格)

**项目信息**:
- 类型：度假酒店
- 面积：2000 平米
- 风格：热带现代 + 侘寂
- 地点：东南亚

**设计要点**:
| 元素 | 材料 | 特点 |
|------|------|------|
| 结构 | 本地石材 + 原木 | 因地制宜 |
| 庭院 | 中央庭院 + 水景 | 自然通风 |
| 光影 | 格栅 + 百叶 | 光影层次 |
| 景观 | 热带植物 + 水景 | 建筑融合 |

**侘寂评分**: 93/100 ⭐⭐⭐⭐⭐

**巴瓦设计原则**:
1. 建筑与自然融合
2. 场所精神 (因地制宜)
3. 庭院借景
4. 自然通风采光
5. 本土材料使用
6. 时间痕迹接受
