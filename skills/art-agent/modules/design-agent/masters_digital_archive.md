### 基本信息

| 项目 | 信息 |
|------|------|
| **姓名** | 阿塞尔·维伍德 (Axel Vervoordt) |
| **国籍** | 比利时 |
| **出生** | 1947 年 |
| **身份** | 设计师/收藏家/策展人 |
| **风格** | 极简美学 + 侘寂美学 |
| **称号** | "侘寂美学大师" |
| **影响力** | 5.2 万点赞/9.3 万转发 |

### 设计思想

**核心理念**:
1. "少即是多"
2. "时间痕迹之美"
3. "接受不完美"
4. "古董与现代融合"
5. "静谧深邃的空间氛围"

**设计原则**:
| 原则 | 说明 | 应用 |
|------|------|------|
| 简素 | 去除多余装饰 | 空间/产品/视觉 |
| 自然 | 尊重材料本性 | 材料选择/工艺 |
| 时间痕迹 | 接受老化变化 | 表面处理/做旧 |
| 留白 | 30-50% 空白 | 空间布局/视觉 |
| 古董融合 | 古董 + 现代 | 家具/装饰 |

### 设计思想

**核心理念**:
1. "建筑与自然融合"
2. "场所精神 (因地制宜)"
3. "庭院借景"
4. "本土文化融合"
5. "自然通风采光"

**设计原则**:
| 原则 | 说明 | 应用 |
|------|------|------|
| 融合 | 建筑/自然/人文 | 景观/空间 |
| 因地制宜 | 本土材料 + 本地工艺 | 材料选择 |
| 庭院借景 | 引入外部景观 | 空间布局 |
| 自然通风 | 被动式降温 | 建筑设计 |
| 自然采光 | 光影层次 | 光影设计 |
