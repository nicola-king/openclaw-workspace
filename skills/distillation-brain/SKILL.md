# 蒸馏大脑 Skill — AI 蒸馏提炼流水线

灵感来自得到大脑（原 Get笔记），太一版 AI 蒸馏提炼系统。

## 核心理念

> **记录不是存档，是原料。AI 帮你把原料变成作品。**

一条素材的完整生命周期：

```
输入素材（语音/文字/链接/图片）
  → 第1层：理解 — AI 读懂内容、提取要点
  → 第2层：关联 — 关联历史记忆，发现连接
  → 第3层：点评 — 找到闪光点和价值
  → 第4层：拷问 — 指出盲点和漏洞
  → 第5层：打磨 — 优化表达、补充论据
  → 第6层：成果 — 一键输出多平台成品
```

## 自动触发规则（太一智能识别，无需手动指定）

### 触发条件判断矩阵

收到任何用户消息时，太一自动判断：

| 用户消息特征 | 太一判断逻辑 | 处理流程 |
|-------------|------------|---------|
| 语音消息 / 录音文件 | 素材类型=语音 → 需要提炼 | 语音转文字 → 完整六层蒸馏 |
| 分享链接（含 http/https）| 素材类型=链接 → 提取内容 | 抓取内容 → 蒸馏核心 → 点评打磨 |
| 发图片 + "帮我提炼"/"整理这个" | 素材类型=图片+VLM → 需要提炼 | 图片OCR → 提取信息 → 蒸馏 |
| 长文本 >200字（不含明确请求）| 素材类型=笔记 → 默认值得蒸馏 | 理解意图 → 完整六层蒸馏 |
| 短文本 + "我在想/我发现/我注意到" | 素材类型=碎碎念 → 有潜力 | 拷问深化 → 打磨成文 |
| 要求"整理我的笔记/提炼/蒸馏" | 触发蒸馏明确指令 | 回顾记忆 → 提炼洞见 |
| 要求"出小红书/公众号/朋友圈" | 触发成果输出指令 | 已有素材 → 适配多平台 |

### 不触发蒸馏的场景
- 明确提问（"帮我搜索"、"XX是什么意思"）→ 走正常问答，不蒸馏
- 简单确认（"好/是/可以"）→ 不走蒸馏
- 已有明确行动指令（"帮我查"、"写开发信"）→ 走对应 Skill

### 触发后自动决策

```
太一识别素材
  → 需要蒸馏？
    → 否 → 正常处理
    → 是 → 跑对应层数蒸馏流程
      → 大素材(>500字/语音/链接) → 完整六层
      → 小素材(碎碎念/短笔记) → 仅2-3层(节省配额)
```

## 六层蒸馏流程

### 第1层：理解
```
输入 → 提取要点 → 结构化摘要 → 关键词/标签
```
### 第2层：关联
```
当前素材 → 搜索记忆 → 关联历史 → 输出连接点
```
### 第3层：点评
```
素材 → 找到亮点 → 指出价值 → 输出点评
```
### 第4层：拷问
```
素材 → 识别盲区 → 提出质疑 → 输出问题
```
### 第5层：打磨
```
原始素材 + 点评 + 拷问 → 优化版本 → 输出成品
```
### 第6层：成果
```
成品 → 适配多个平台输出 → 小红书/公众号/朋友圈/报告
```

## 手动触发命令

```
/蒸馏 <内容>          → 完整六层蒸馏流程
/理解 <内容>          → 仅做理解和提取
/关联 <内容>          → 关联历史记忆
/点评 <内容>          → 仅做点评
/拷问 <内容>          → 仅做拷问
/打磨 <内容>          → 润色打磨
/出成果 <内容> <平台>  → 输出指定平台内容
```

## 调用方式

### 自动：素材入站 → 太一自动判断

```
用户发一段语音/文字/链接
  → 太一识别为蒸馏素材
  → 跑完整六层流程
  → 输出结果
```

### 手动：通过 CLI

```bash
bash skills/distillation-brain/scripts/distill.sh <mode> <content>
```
