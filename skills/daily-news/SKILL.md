## 🧬 自进化能力

本系统具备自进化能力，可根据使用反馈自动优化：

| 进化维度 | 当前状态 | 进化机制 |
|---------|---------|---------|
| **数据源优化** | ✅ 7 类数据源 | 根据搜索成功率自动调整权重 |
| **搜索策略** | ✅ 智能重试 | 根据 bot 检测频率调整重试间隔 |
| **内容质量** | ✅ 核心摘要 | 根据用户反馈调整摘要长度 |
| **推送时机** | ✅ 08:00 固定 | 可根据用户阅读习惯自适应 |
| **文件格式** | ✅ 中文 MD | 根据用户偏好自动切换格式 |

### 自进化触发条件

- 同类任务重复 3 次 → 自动优化流程
- 搜索失败率>10% → 自动切换数据源
- 用户反馈负面 → 自动调整内容策略
- 新数据源出现 → 自动评估并集成

---

## 📋 功能描述

每日北京时间 08:00 自动搜索 7 类全球新闻，每类 5 条，生成格式化新闻简报。

## 🔧 使用方法

### 手动触发
```bash
# 通过 OpenClaw 会话发送
/daily-news
```

### 定时任务（cron）
```bash
# 每天北京时间 08:00 执行
0 0 * * * /home/nicola/.openclaw/workspace/scripts/news-cron-trigger.sh
```

## 📁 文件结构

```
~/.openclaw/workspace/
├── skills/daily-news/
│   └── SKILL.md              # 技能说明
├── scripts/
│   ├── daily-news-search.py  # Python 搜索脚本
│   ├── daily-news-search.sh  # Bash 搜索脚本
│   └── news-cron-trigger.sh  # Cron 触发脚本
└── news/daily/
    └── 晨间新闻简报 -YYYY-MM-DD.md    # 每日新闻输出（中文文件名）
```

---

## 🚀 执行流程

```
1. Cron 触发 (08:00 UTC+8)
        ↓
2. news-cron-trigger.sh 执行
        ↓
3. 调用 OpenClaw sessions_spawn 启动子代理
        ↓
4. 子代理执行搜索:
   - AI/科技/时事/经济 → web_search (全球)
   - 国际热点 → agent-reach (Twitter/Reddit/YouTube)
   - 产品趋势 → 跨境贸易 Agent 数据库
   - 中国政经 → web_search (国内源)
        ↓
5. 格式化输出到 news/daily/晨间新闻简报 -YYYY-MM-DD.md
        ↓
6. 通过微信/Telegram 推送给用户
        ↓
7. 记录执行状态到 memory/YYYY-MM-DD.md
```

## ⚙️ 配置说明

### 搜索参数
- 每类新闻：5 条
- 来源：传统媒体 + 网络媒体 + 社交媒体
- 时效性：24 小时内优先
- 可验证：所有链接可访问

### 输出格式
- Markdown 格式
- 包含标题、摘要、来源、链接
- 时间戳和免责声明
