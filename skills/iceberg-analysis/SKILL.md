## 🧊 冰山理论模型

```
                    ┌─────────────┐
                    │  表面现象    │  ← 10% 可见
                    │  (事件本身)  │
    ────────────────┼─────────────┼─────── 海平面
                    │  直接原因    │
                    │  相关方利益  │  ← 30% 浅层
                    │  历史背景    │
                    ├─────────────┤
                    │  结构因素    │
                    │  系统动力    │  ← 40% 中层
                    │  权力关系    │
                    ├─────────────┤
                    │  核心矛盾    │
                    │  范式转移    │  ← 20% 深层
                    │  文明趋势    │
                    └─────────────┘
```

---

## 🎯 新闻重要性评估

### 评估维度（太一自主判断）

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| **影响范围** | 25% | 全球/区域/国家/局部 |
| **影响深度** | 25% | 范式级/系统级/事件级/噪音 |
| **紧急程度** | 20% | 立即/24h/本周/本月 |
| **持续性** | 15% | 长期/中期/短期/一次性 |
| **不确定性** | 15% | 高变数/中变数/低变数 |

### 重要性分级

| 等级 | 分数 | 选择优先级 | 分析深度 |
|------|------|-----------|---------|
| **S 级** | 90-100 | 必选 | 完整冰山分析 |
| **A 级** | 80-89 | 高优 | 标准冰山分析 |
| **B 级** | 70-79 | 中优 | 简化分析 |
| **C 级** | 60-69 | 低优 | 仅表面描述 |
| **D 级** | <60 | 忽略 | 不分析 |

## 📊 分析框架

### 第一层：表面现象（10%）

```markdown
## 📰 事件概述

- **发生了什么**: [客观描述]
- **时间地点**: [时空坐标]
- **关键人物/组织**: [参与方]
- **直接结果**: [即时影响]
```

---

### 第二层：直接原因（30%）

```markdown
## 🔍 直接原因分析

### 触发因素
- [直接触发事件]

### 相关方利益
| 相关方 | 利益诉求 | 立场 |
|--------|---------|------|
| [方 1] | [诉求] | [立场] |

### 历史背景
- [相关历史事件]
- [先例参考]
```

---

### 第三层：结构因素（40%）

```markdown
## 🏗️ 结构因素分析

### 系统动力
- [推动事件的系统性力量]

### 权力关系
- [各方权力对比]
- [权力结构变化]

### 制度约束
- [制度框架影响]
- [规则限制]
```

---

### 第四层：核心矛盾（20%）

```markdown
## 💎 核心矛盾分析

### 根本矛盾
- [深层结构性矛盾]

### 范式转移
- [是否在发生范式级变化]

### 文明趋势
- [长期历史趋势]
- [人类文明方向]
```

---

### 第五层：二阶思维

```markdown
## 🔮 二阶思维推演

### 短期影响（1-3 个月）
- [直接后果]

### 中期影响（3-12 个月）
- [连锁反应]

### 长期影响（1-5 年）
- [结构性变化]

### 黑天鹅风险
- [小概率高影响事件]
```
