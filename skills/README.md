# 太一技能库

> 版本：v1.0（蒸馏版）| 技能数：~15 个核心技能

---

## 技能分类

### 01-交易 (Trading)
- `cross-border-trade-agent` — 跨境贸易 Agent
- `gmgn` — GMGN 交易集成
- `polymarket` — Polymarket 预测市场
- `zhiji` — 知几量化策略

### 02-业务 (Business)
- `content-creator` — 内容创作
- `geo-optimizer` — GEO 优化
- `social-media` — 社媒运营

### 03-自动化 (Automation)
- `crontab-manager` — 定时任务管理
- `workflow-engine` — 工作流引擎

### 04-集成 (Integration)
- `browser-automation` — 浏览器自动化
- `feishu` — 飞书集成
- `ssh` — SSH 远程

### 05-系统 (System)
- `monitoring` — 监控告警
- `backup` — 备份工具

---

## 使用方式

每个技能目录包含：
- `SKILL.md` — 技能说明和使用方法
- `*.py` — 实现代码
- `config.yaml` — 配置文件

---

*技能库遵循 DISTILLATION-PLAN 原则：独立职责 · 互联互通 · 零重复 · 智能路由*
