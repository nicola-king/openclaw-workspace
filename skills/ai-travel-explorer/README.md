## 🎯 项目简介

太一旅游探路者 Agent 是一个智能旅游规划和探索助手，提供：
- 旅游目的地推荐
- 行程规划
- 景点信息查询
- 旅行预算估算
- 自进化学习能力

---

## 🚀 快速开始

```bash
# 克隆仓库
git clone https://github.com/nicola-king/taiyi-travel-explorer.git
cd taiyi-travel-explorer

# 安装依赖
pip install -r requirements.txt

# 运行 Agent
python3 ai_travel_explorer.py
```
