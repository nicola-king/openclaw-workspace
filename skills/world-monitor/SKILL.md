# World Monitor Skill — 全球情报融合

融合 koala73/worldmonitor 实时全球情报仪表盘（54975⭐，AGPL-3.0）。

## 已装载能力

| 能力 | 数据源 | 对跨境贸易的价值 |
|:----:|:-------|:----------------|
| 🌍 **国家风险指数** | 12 个信号维度综合评分 | 目标市场风险评估 |
| 📰 **AI 新闻聚合** | 500+ 新闻源，15 类别 | 行业动态情报日报 |
| 🏛️ **地缘政治监控** | 军事/经济/制裁/冲突 | 贸易路线安全预警 |
| 💹 **金融雷达** | 92 交易所 + 商品 + 加密货币 | 汇率/大宗商品影响 |
| 🛢️ **商品追踪** | 能源/矿产/农产品 | 原材料成本分析 |

## 自动触发规则

| 用户意图 | 路由到 | 输出 |
|---------|--------|------|
| "查XX国家风险/安全不安全" | 🌍 国家风险指数 | 风险评分 + 关键信号 |
| "XX市场能不能进" | 🌍 国家风险 + 📰 新闻 | 市场准入评估 |
| "最近XX行业有什么新闻" | 📰 AI 新闻聚合 | 行业情报简报 |
| "XX国家政局/制裁情况" | 🏛️ 地缘政治监控 | 风险预警 |
| "XX商品价格走势" | 💹 金融雷达 | 价格趋势分析 |
| "做XX国家的贸易要注意什么" | 综合评估 | 完整市场情报报告 |

## 手动触发命令

```
/风险 <国家>       → 国家风险指数 + 关键信号
/情报 <国家/行业>  → AI 合成情报简报
/监控 <国家>       → 地缘政治监控情报
/商品 <名称>       → 商品价格趋势
/市场 <国家>       → 完整市场准入评估
```

## 集成到太一

### 国家风险 → 背调模块
WorldMonitor 的国家风险指数直接输入到背景检查的贸易风险评分：

```
背调 "XX公司" -w "xx.com"
  → 公司评级 A/B/C/D（现有）
  + 国家风险评级（WorldMonitor）
  = 综合贸易风险评分
```

### 新闻聚合 → 情报日报
WorldMonitor 的 500+ AI 新闻源补充跨境贸易情报日报的内容广度。

### 商品追踪 → 成本分析
大宗商品价格走势辅助外贸报价决策。
