## 🎯 侘寂设计核心原则

### 七大核心原则

| 原则 | 说明 | 应用 |
|------|------|------|
| **简素** | 去除多余装饰，回归本质 | 空间/产品/视觉设计 |
| **自然** | 尊重材料本性，顺势而为 | 材料选择/工艺处理 |
| **残缺** | 接受不完美，欣赏时间痕迹 | 表面处理/做旧工艺 |
| **空寂** | 留白与空间感，呼吸感 | 空间布局/视觉层次 |
| **幽玄** | 深邃含蓄，不直白表达 | 光影处理/细节设计 |
| **无常** | 接受变化与衰老 | 材料老化/可持续设计 |
| **融合** | 建筑/自然/人文一体化 | 景观设计/空间设计 |

## 🎨 侘寂设计元素库

### 材料选择

| 材料 | 特性 | 应用场景 |
|------|------|---------|
| 原木 | 天然纹理/时间痕迹 | 家具/地板/墙面 |
| 石材 | 粗糙质感/自然形态 | 台面/地面/装饰 |
| 竹编 | 手工质感/透气性 | 灯具/屏风/收纳 |
| 麻布 | 天然纤维/朴素质感 | 软装/窗帘/靠垫 |
| 陶土 | 手工痕迹/质朴感 | 花器/餐具/装饰 |
| 金属 (做旧) | 氧化痕迹/时间感 | 五金/装饰/灯具 |
| 纸张 | 透光性/脆弱美 | 灯具/屏风/包装 |

### 色彩搭配

| 色系 | 颜色 | 使用比例 | 情感 |
|------|------|---------|------|
| 大地色 | 米白/浅褐/深棕 | 60% | 温暖/自然/稳定 |
| 灰色系 | 浅灰/中灰/深灰 | 25% | 沉静/内敛/高级 |
| 黑色系 | 炭黑/墨黑 | 10% | 深邃/神秘/重点 |
| 自然色 | 苔藓绿/枯叶黄 | 5% | 生机/季节/点缀 |

### 光影处理

| 光影类型 | 效果 | 应用场景 |
|---------|------|---------|
| 漫射光 | 柔和均匀 | 主照明/氛围营造 |
| 局部光 | 重点突出 | 展品/装饰/功能区域 |
| 自然光 | 时间变化 | 窗户/天窗/庭院 |
| 阴影 | 层次深邃 | 墙面/地面/装饰 |
| 反射光 | 空间延伸 | 水面/金属/石材 |

### 空间布局

| 布局原则 | 说明 | 应用 |
|---------|------|------|
| 留白 | 30-50% 空白区域 | 墙面/地面/天花板 |
| 不对称 | 避免完全对称 | 家具摆放/装饰布局 |
| 流动 | 空间自然过渡 | 房间连接/功能区域 |
| 借景 | 引入外部景观 | 窗户/庭院/露台 |
| 层次 | 前景/中景/背景 | 视觉深度/空间感 |

## 🤖 Design Agent 集成

### 侘寂设计模式

```python
class WabiSabiDesignAgent:
    """侘寂设计 Agent"""
    
    def __init__(self):
        self.principles = [
            "简素", "自然", "残缺",
            "空寂", "幽玄", "无常", "融合"
        ]
        self.materials = ["原木", "石材", "竹编", "麻布", "陶土", "做旧金属", "纸张"]
        self.colors = ["大地色", "灰色系", "黑色系", "自然色"]
    
    def evaluate(self, design: Dict) -> Dict:
        """评估设计的侘寂程度"""
        score = self._calculate_score(design)
        rating = self._get_rating(score)
        suggestions = self._generate_suggestions(design)
        
        return {
            "score": score,
            "rating": rating,
            "suggestions": suggestions
        }
    
    def generate(self, brief: Dict) -> Dict:
        """生成侘寂设计方案"""
        materials = self._select_materials(brief)
        colors = self._select_colors(brief)
        layout = self._create_layout(brief)
        lighting = self._design_lighting(brief)
        
        return {
            "materials": materials,
            "colors": colors,
            "layout": layout,
            "lighting": lighting,
            "principles": self.principles
        }
```

### 调用示例

```python
# 初始化侘寂设计 Agent
wabi_sabi = WabiSabiDesignAgent()

# 评估现有设计
design = {"materials": "原木", "colors": "大地色", "style": "极简"}
result = wabi_sabi.evaluate(design)
# 输出：{"score": 85, "rating": "⭐⭐⭐⭐", "suggestions": [...]}

# 生成新设计方案
brief = {"type": "茶室", "size": "20 平米", "budget": "中等"}
plan = wabi_sabi.generate(brief)
# 输出：{"materials": [...], "colors": [...], "layout": [...], ...}
```

## ✅ 使用指南

### 何时使用侘寂设计

- ✅ 高端酒店/度假村设计
- ✅ 茶室/禅修空间设计
- ✅ 高端住宅/别墅设计
- ✅ 博物馆/艺术空间设计
- ✅ 高端产品设计 (茶具/家具/灯具)
- ✅ 庭院/景观设计

### 何时谨慎使用

- ⚠️ 商业零售空间 (可能过于沉静)
- ⚠️ 儿童空间 (可能过于严肃)
- ⚠️ 办公空间 (需平衡效率与静谧)
- ⚠️ 预算有限项目 (天然材料成本较高)
