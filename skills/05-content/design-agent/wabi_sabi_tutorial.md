## 第 1 章：侘寂美学概述

### 1.1 什么是侘寂？

**定义**:
侘寂 (Wabi-Sabi) 是一种日本美学理念，接受不完美、不永恒、不完整的美。

**核心思想**:
- ✅ 接受不完美
- ✅ 接受变化与衰老
- ✅ 接受自然痕迹
- ✅ 追求简素与自然

### 1.2 侘寂 vs 现代极简

| 维度 | 侘寂 | 现代极简 |
|------|------|---------|
| 哲学 | 接受不完美 | 追求完美 |
| 材料 | 天然 + 时间痕迹 | 人造 + 光滑 |
| 色彩 | 大地色/灰色系 | 黑白灰 |
| 工艺 | 手工痕迹 | 机制精密 |
| 时间 | 接受老化 | 保持崭新 |

### 1.3 两位大师简介

**阿塞尔·维伍德 (比利时)**:
- 极简美学 + 侘寂美学
- 代表作品：阿曼尼酒店
- 核心理念："时间痕迹之美"

**杰弗里·巴瓦 (斯里兰卡)**:
- "亚洲建筑之父"
- 代表作品：坎达拉玛酒店
- 核心理念："建筑与自然融合"

### 1.4 课后练习

1. 收集 5 张侘寂风格图片
2. 描述侘寂与现代极简的区别
3. 找出身边的侘寂元素

## 第 2 章：侘寂七原则

### 2.1 简素 (Kanso)

**定义**: 去除多余装饰，回归本质

**应用技巧**:
- ✅ 减少装饰元素
- ✅ 简化造型线条
- ✅ 突出核心功能

**案例**:
```
❌ 错误：复杂雕花 + 多层装饰
✅ 正确：简洁线条 + 单一功能
```

### 2.2 自然 (Shizen)

**定义**: 尊重材料本性，顺势而为

**应用技巧**:
- ✅ 保留天然纹理
- ✅ 避免过度加工
- ✅ 顺势设计造型

**案例**:
```
❌ 错误：人工染色 + 强制造型
✅ 正确：天然色泽 + 自然形态
```

### 2.3 残缺 (Fukinsei)

**定义**: 接受不完美，欣赏时间痕迹

**应用技巧**:
- ✅ 保留手工痕迹
- ✅ 接受使用痕迹
- ✅ 欣赏老化过程

**案例**:
```
❌ 错误：完美无瑕 + 全新状态
✅ 正确：手工痕迹 + 时间沉淀
```

### 2.4 空寂 (Yugen)

**定义**: 留白与空间感，呼吸感

**应用技巧**:
- ✅ 30-50% 留白
- ✅ 避免过度填充
- ✅ 创造呼吸空间

**案例**:
```
❌ 错误：墙面挂满装饰
✅ 正确：40% 留白墙面
```

### 2.5 幽玄 (Yugen)

**定义**: 深邃含蓄，不直白表达

**应用技巧**:
- ✅ 间接照明
- ✅ 层次光影
- ✅ 含蓄表达

**案例**:
```
❌ 错误：直射强光 + 一览无余
✅ 正确：漫射柔光 + 层次深邃
```

### 2.6 无常 (Mujo)

**定义**: 接受变化与衰老

**应用技巧**:
- ✅ 选择会老化材料
- ✅ 接受颜色变化
- ✅ 欣赏时间痕迹

**案例**:
```
❌ 错误：永不老化人造材料
✅ 正确：会氧化铜器 + 会变色原木
```

### 2.7 融合 (Wa)

**定义**: 建筑/自然/人文一体化

**应用技巧**:
- ✅ 引入自然景观
- ✅ 使用本土材料
- ✅ 尊重地域文化

**案例**:
```
❌ 错误：与环境割裂
✅ 正确：庭院借景 + 本土石材
```

### 2.8 课后练习

1. 为每个原则找 1 个案例
2. 分析案例中的七原则体现
3. 设计一个体现七原则的小物件

## 第 3 章：材料选择与应用

### 3.1 七大侘寂材料

| 材料 | 特性 | 应用场景 | 价格区间 |
|------|------|---------|---------|
| 原木 | 天然纹理/时间痕迹 | 家具/地板/墙面 | 中 - 高 |
| 石材 | 粗糙质感/自然形态 | 台面/地面/装饰 | 中 - 高 |
| 竹编 | 手工质感/透气性 | 灯具/屏风/收纳 | 低 - 中 |
| 麻布 | 天然纤维/朴素质感 | 软装/窗帘/靠垫 | 低 - 中 |
| 陶土 | 手工痕迹/质朴感 | 花器/餐具/装饰 | 低 - 中 |
| 做旧金属 | 氧化痕迹/时间感 | 五金/装饰/灯具 | 中 |
| 纸张 | 透光性/脆弱美 | 灯具/屏风/包装 | 低 |

### 3.2 材料处理技巧

**原木处理**:
```
步骤 1: 选择天然木材 (橡木/胡桃木/榆木)
步骤 2: 保留天然纹理
步骤 3: 木蜡油保护 (非油漆)
步骤 4: 接受颜色变化
```

**石材处理**:
```
步骤 1: 选择天然石材 (非人造)
步骤 2: 保留粗糙表面
步骤 3: 不做抛光处理
步骤 4: 接受风化痕迹
```

**金属做旧**:
```
步骤 1: 选择铜/铁材质
步骤 2: 自然氧化或加速氧化
步骤 3: 保留氧化痕迹
步骤 4: 不做保护涂层
```

### 3.3 成本优化方案

| 原方案 | 替代方案 | 节省比例 |
|--------|---------|---------|
| 胡桃木 | 榆木 (做旧) | 40% |
| 天然石材 | 微水泥 | 50% |
| 手工陶器 | 机制陶器 (做旧) | 60% |
| 纯麻布 | 棉麻混纺 | 30% |
| 铜器 | 铁器 (做旧) | 50% |

### 3.4 课后练习

1. 收集 7 种侘寂材料样板
2. 对比天然材料与人造材料
3. 设计一个材料搭配方案

## 第 4 章：色彩搭配技巧

### 4.1 侘寂色彩比例

| 色系 | 颜色 | 使用比例 | 情感 |
|------|------|---------|------|
| 大地色 | 米白/浅褐/深棕 | 60% | 温暖/自然/稳定 |
| 灰色系 | 浅灰/中灰/深灰 | 25% | 沉静/内敛/高级 |
| 黑色系 | 炭黑/墨黑 | 10% | 深邃/神秘/重点 |
| 自然色 | 苔藓绿/枯叶黄 | 5% | 生机/季节/点缀 |

### 4.2 色彩搭配原则

**60-25-10-5 原则**:
```
60% 大地色 (主色调)
  ↓
25% 灰色系 (辅助色)
  ↓
10% 黑色系 (强调色)
  ↓
5% 自然色 (点缀色)
```

### 4.3 色彩搭配案例

**客厅配色**:
```
墙面：米白色 (大地色) - 60%
地板：浅褐色 (大地色)
沙发：浅灰色 (灰色系) - 25%
窗帘：深灰色 (灰色系)
茶几：深棕色 (大地色)
装饰：炭黑 (黑色系) - 10%
植物：苔藓绿 (自然色) - 5%
```

### 4.4 色彩心理学

| 颜色 | 心理效应 | 适用空间 |
|------|---------|---------|
| 米白 | 温暖/包容 | 客厅/卧室 |
| 浅褐 | 自然/稳定 | 书房/茶室 |
| 深棕 | 沉稳/厚重 | 办公室/会议室 |
| 浅灰 | 沉静/理性 | 工作室/书房 |
| 深灰 | 内敛/高级 | 展厅/商业空间 |
| 炭黑 | 深邃/神秘 | 重点装饰 |

### 4.5 课后练习

1. 为一个空间设计配色方案
2. 制作色彩比例图
3. 收集对应颜色材料样板

## 第 5 章：空间布局与留白

### 5.1 留白原则

**30-50% 留白规则**:
```
墙面留白：30-50%
地面留白：40-60%
天花板留白：50-70%
```

### 5.2 不对称布局

**原则**:
- ✅ 避免完全对称
- ✅ 创造动态平衡
- ✅ 自然随意摆放

**案例**:
```
❌ 错误：沙发居中 + 两侧对称
✅ 正确：沙发偏一侧 + 自然摆放
```

### 5.3 流动空间

**设计技巧**:
- ✅ 房间自然过渡
- ✅ 避免硬隔断
- ✅ 使用软隔断 (屏风/帘子)

### 5.4 借景手法

**类型**:
| 类型 | 说明 | 案例 |
|------|------|------|
| 远借 | 借远处景观 | 远山/湖泊 |
| 近借 | 借近处景观 | 庭院/树木 |
| 仰借 | 借上方景观 | 天空/云朵 |
| 俯借 | 借下方景观 | 水池/地面 |

### 5.5 课后练习

1. 为一个空间设计留白方案
2. 绘制不对称布局图
3. 设计一个借景方案

## 第 6 章：光影设计手法

### 6.1 五种光影类型

| 类型 | 效果 | 应用场景 |
|------|------|---------|
| 漫射光 | 柔和均匀 | 主照明/氛围 |
| 局部光 | 重点突出 | 展品/装饰 |
| 自然光 | 时间变化 | 窗户/天窗 |
| 阴影 | 层次深邃 | 墙面/地面 |
| 反射光 | 空间延伸 | 水面/金属 |

### 6.2 自然光设计

**设计要点**:
- ✅ 东侧窗户 (早晨阳光)
- ✅ 南侧窗户 (全天阳光)
- ✅ 西侧窗户 (傍晚阳光)
- ✅ 北侧窗户 (柔和光线)

### 6.3 人工照明设计

**灯具选择**:
| 灯具 | 材质 | 光效 | 适用场景 |
|------|------|------|---------|
| 竹编灯 | 竹编 | 柔和漫射 | 客厅/茶室 |
| 纸质灯 | 和纸 | 透光纹理 | 卧室/书房 |
| 陶土灯 | 陶土 | 局部照明 | 装饰/氛围 |
| 做旧金属灯 | 铁/铜 | 重点照明 | 工作台/阅读 |

### 6.4 光影层次

**三层照明**:
```
第一层：基础照明 (漫射光)
  ↓
第二层：功能照明 (局部光)
  ↓
第三层：装饰照明 (重点光)
```

### 6.5 课后练习

1. 设计一个空间的光影方案
2. 制作三层照明布局图
3. 收集不同类型灯具样板
