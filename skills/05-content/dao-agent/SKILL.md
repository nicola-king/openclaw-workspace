## 🔧 配置说明

配置文件位于 `config/dao-agent-config.json`:

```json
{
  "daily_time": "08:00",
  "card_style": "minimalist",
  "source_pool": [
    "道德经",
    "庄子",
    "列子",
    "文始真经"
  ],
  "output_formats": ["markdown", "image"],
  "auto_send": true
}
```

## 🚀 使用说明

### 生成今日智慧

```bash
# 生成今日道之智慧
python3 skills/05-content/dao-agent/src/dao_agent.py --daily

# 生成指定日期
python3 skills/05-content/dao-agent/src/dao_agent.py --date 2026-04-15
```

### 查看历史

```bash
# 查看历史智慧
python3 skills/05-content/dao-agent/src/dao_agent.py --history 7
```
