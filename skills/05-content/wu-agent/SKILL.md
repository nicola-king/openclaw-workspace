## 🔧 配置说明

配置文件位于 `config/wu-agent-config.json`:

```json
{
  "daily_time": "20:00",
  "card_style": "zen",
  "source_pool": [
    "心经",
    "金刚经",
    "六祖坛经",
    "禅宗公案"
  ],
  "output_formats": ["markdown", "image"],
  "auto_send": true
}
```

## 🚀 使用说明

### 生成今日智慧

```bash
# 生成今日悟之智慧
python3 skills/05-content/wu-agent/src/wu_agent.py --daily

# 生成指定日期
python3 skills/05-content/wu-agent/src/wu_agent.py --date 2026-04-15
```

### 查看历史

```bash
# 查看历史智慧
python3 skills/05-content/wu-agent/src/wu_agent.py --history 7
```
