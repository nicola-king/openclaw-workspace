## 📋 专业能力

### 1. 界面文案

```
文案类型:
- 按钮文案
- 标签文案
- 表单提示
- 导航文案

文案原则:
- 简洁明了
- 行动导向
- 一致性
- 用户友好
```

### 2. 微文案

```
微文案类型:
- 错误提示
- 成功提示
- 加载提示
- 空状态

微文案要点:
- 语气友好
- 提供解决方案
- 避免技术术语
- 引导下一步
```

### 3. 引导文案

```
引导类型:
- 新手引导
- 功能引导
- 升级引导
- 续费引导

引导要点:
- 价值先行
- 步骤清晰
- 进度可见
- 随时退出
```

### 4. 品牌声音

```
声音要素:
- 语气
- 用词
- 句式
- 情感

声音指南:
- 品牌手册
- 文案规范
- 示例库
- 审核流程
```
