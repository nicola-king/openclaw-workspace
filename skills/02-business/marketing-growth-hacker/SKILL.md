## 🔧 使用方式

### 命令行接口

```bash
# 增长策略生成
python3 skills/growth-hacker/cli.py generate strategy \
  --goal "用户增长" \
  --target "10000 新用户/月" \
  --budget "50000 元/月"

# A/B 测试设计
python3 skills/growth-hacker/cli.py design ab-test \
  --page "landing" \
  --element "cta-button" \
  --variants "3"

# 漏斗分析
python3 skills/growth-hacker/cli.py analyze funnel \
  --data "analytics.csv" \
  --stages "visit,signup,activate,pay"
```

### Python API

```python
from skills.growth_hacker import GrowthHacker

# 创建实例
hacker = GrowthHacker(industry="saas")

# 生成增长策略
strategy = hacker.generate_strategy(
    goal="用户增长",
    current_mau=10000,
    target_mau=50000,
    timeline="6 个月"
)

# 设计 A/B 测试
ab_test = hacker.design_ab_test(
    page="pricing",
    hypothesis="价格锚点提升转化",
    variants=["control", "anchor_low", "anchor_high"]
)

# 分析增长数据
insights = hacker.analyze_growth(
    data="metrics.csv",
    metrics=["cac", "ltv", "retention"]
)
```

## 📊 交付物示例

### 增长策略文档

```markdown
# 增长策略方案 · Q2 2026

## 一、目标
- **MAU**: 10,000 → 50,000 (5 倍增长)
- **付费用户**: 500 → 2,500
- **月收入**: 50 万 → 250 万

## 二、核心策略

### 策略 1: 内容营销
**目标**: 获取 30% 新用户
**预算**: 15,000 元/月
**渠道**:
- 公众号文章 (8 篇/月)
- 知乎问答 (20 个/月)
- 小红书笔记 (15 篇/月)

**预期**:
- 曝光：100 万/月
- 引流：3,000 用户/月
- CAC: 5 元/用户

### 策略 2: 推荐裂变
**目标**: 获取 40% 新用户
**预算**: 20,000 元/月
**机制**:
- 老用户邀请新用户
- 双方获得 7 天会员
- 邀请上限：10 人/月

**预期**:
- K 因子：1.2
- 分享率：15%
- 转化：4,000 用户/月

### 策略 3: 付费广告
**目标**: 获取 30% 新用户
**预算**: 15,000 元/月
**渠道**:
- 微信朋友圈广告
- 抖音信息流广告
- 百度 SEM

**预期**:
- 曝光：50 万/月
- 点击：10,000/月
- 转化：3,000 用户/月
- CAC: 50 元/用户

## 三、执行计划

| 周次 | 任务 | 负责人 | 预算 |
|------|------|--------|------|
| W1 | 内容素材准备 | 内容团队 | 5,000 |
| W2 | 广告账户搭建 | 投放团队 | 5,000 |
| W3 | 推荐系统开发 | 技术团队 | 10,000 |
| W4 | 全渠道上线 | 全员 | 30,000 |

## 四、监控指标

| 指标 | 目标 | 监控频率 |
|------|------|---------|
| CAC | ≤50 元 | 每日 |
| LTV | ≥300 元 | 每周 |
| 留存率 D7 | ≥30% | 每周 |
| K 因子 | ≥1.0 | 每周 |
```

### A/B 测试报告

```markdown
# A/B 测试报告 · 价格页 CTA 优化

## 测试信息
- **测试页面**: /pricing
- **测试元素**: CTA 按钮文案
- **测试时间**: 2026-04-01 ~ 2026-04-14
- **样本量**: 10,000 用户

## 测试方案

| 版本 | 文案 | 流量分配 |
|------|------|---------|
| A (对照) | 立即开始 | 33% |
| B | 免费试用 14 天 | 33% |
| C | 开始我的免费试用 | 34% |

## 测试结果

| 版本 | 曝光 | 点击 | 转化率 | 提升 |
|------|------|------|--------|------|
| A | 3,300 | 330 | 10.0% | - |
| B | 3,350 | 402 | 12.0% | +20% ✅ |
| C | 3,350 | 369 | 11.0% | +10% |

## 结论
- **获胜版本**: B (免费试用 14 天)
- **置信度**: 95%
- **统计显著**: 是 (p < 0.05)

## 建议
1. 全量上线版本 B
2. 继续测试价格锚点
3. 优化移动端体验
```
