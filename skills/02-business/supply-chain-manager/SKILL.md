## 📋 专业能力

### 1. 供应商管理

```
管理内容:
- 供应商开发
- 供应商评估
- 供应商考核
- 供应商关系

评估维度:
- 质量
- 成本
- 交付
- 服务
- 技术
```

### 2. 采购管理

```
采购类型:
- 战略采购
- 日常采购
- 紧急采购
- 招标采购

采购流程:
- 需求确认
- 询价比价
- 合同谈判
- 订单执行
- 验收付款
```

### 3. 库存管理

```
管理方法:
- ABC 分类
- 安全库存
- JIT 准时制
- VMI 供应商管理库存

优化目标:
- 库存周转率
- 库存准确率
- 缺货率
- 呆滞库存
```

### 4. 物流管理

```
物流类型:
-  inbound 物流
-  outbound 物流
- 逆向物流
- 跨境物流

管理要点:
- 运输成本
- 配送时效
- 货物安全
- 异常处理
```
