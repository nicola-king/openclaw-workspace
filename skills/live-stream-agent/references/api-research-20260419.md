## 🔍 视频号 API 调研

### 官方 API 文档
**文档地址**: https://channels.weixin.qq.com/wiki

### API 开放度评估

| 接口类型 | 开放状态 | 权限要求 | 数据实时性 |
|---------|---------|---------|-----------|
| 直播状态 | ✅ 开放 | 公众号 + 视频号绑定 | 实时 |
| 在线人数 | ✅ 开放 | 已认证视频号 | ~1 秒延迟 |
| 累计观看 | ✅ 开放 | 已认证视频号 | 实时 |
| 点赞数 | ✅ 开放 | 已认证视频号 | ~5 秒延迟 |
| 评论数据 | ⚠️ 部分开放 | 需额外申请 | ~10 秒延迟 |
| 成交数据 | ✅ 开放 | 视频号小店 + API 权限 | 实时 |
| 粉丝数据 | ✅ 开放 | 已认证视频号 | T+1 |

### 权限要求
```
基础权限:
- 已注册视频号
- 完成实名认证
- 公众号绑定（可选但推荐）

高级权限:
- 企业认证（提升数据 granularity）
- 视频号小店开通（获取交易数据）
- API 调用申请（需审核）
```

### API 调用示例
```python
# 获取直播实时数据
GET https://api.weixin.qq.com/channels/live/get_live_info

请求参数:
{
  "appid": "YOUR_APPID",
  "secret": "YOUR_SECRET",
  "live_id": "LIVE_ID"
}

响应数据:
{
  "errcode": 0,
  "errmsg": "ok",
  "data": {
    "live_status": 2,  # 2=直播中
    "viewer_count": 1234,  # 在线人数
    "total_viewer": 5678,  # 累计观看
    "like_count": 9876,  # 点赞数
    "comment_count": 543,  # 评论数
    "start_time": 1713516000  # 开播时间
  }
}
```

## 🔄 浏览器自动化兜底方案

### 适用场景
- 无 API 权限的个人主播
- API 调用受限时的备用方案
- 快速 PoC 验证

### 技术方案
```python
from playwright.sync_api import sync_playwright

def collect_live_data(platform, live_url):
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        page = browser.new_page()
        page.goto(live_url)
        
        # 等待数据加载
        page.wait_for_selector('.live-viewer-count')
        
        # 提取数据
        viewer_count = page.query_selector('.live-viewer-count').inner_text()
        like_count = page.query_selector('.like-count').inner_text()
        comments = page.query_selector_all('.comment-item')
        
        browser.close()
        
        return {
            'viewer_count': viewer_count,
            'like_count': like_count,
            'comment_count': len(comments)
        }
```

### 优劣势分析
| 优势 | 劣势 |
|------|------|
| ✅ 无需 API 权限 | ❌ 稳定性依赖平台 UI |
| ✅ 快速上线验证 | ❌ 可能触发反爬 |
| ✅ 适配所有平台 | ❌ 数据延迟较高 |
| ✅ 开发成本低 | ❌ 需要持续维护 |

### 反爬应对策略
```yaml
策略:
  - 降低采集频率（30 秒/次）
  - 使用代理 IP 池
  - 模拟真实用户行为
  - 随机 User-Agent
  - 失败自动重试 + 降级
```

## 🎯 Phase 1 MVP 推荐方案

### 平台选择：视频号优先
**理由**:
1. ✅ API 开放度高，文档完善
2. ✅ 权限门槛适中（无需企业认证）
3. ✅ 数据实时性好（秒级）
4. ✅ 微信生态集成方便
5. ✅ 用户基数大，需求广泛

### 技术方案
```
数据采集:
- 主方案：视频号官方 API
- 兜底：Playwright 浏览器自动化

数据传输:
- WebSocket 实时推送（1 秒刷新）

数据存储:
- SQLite（轻量级）
- Redis（缓存 + 实时数据）

前端展示:
- React + ECharts
- 响应式设计（PC/移动端）
```
