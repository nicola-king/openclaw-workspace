# 旅游探路者 · Bot 职责分配 & 调度路由

> 太一自动调度 · 无需 SAYELF 手动指派
> 每个 Bot 负责旅游全链路中的专业模块

---

## 一、架构总览

```
SAYELF: "去成都玩3天"
       │
       ▼
┌─────────────────────────────────┐
│        太一 (统筹/决策)           │
│  → 意图解析 (国内/国外/短/深/团)   │
│  → 任务拆解 → 分派对应 Bot        │
│  → 结果聚合 → 最终交付             │
└─────────────────────────────────┘
       │
       ├── 知几 ── 数据情报 + 省钱分析
       ├── 山木 ── 行程规划 + 输出交付
       ├── 素问 ── 目的地研究 + 技术支持
       ├── 罔两 ── 市场情报 + 真实验证
       └── 庖丁 ── 预算控制 + 成本优化
```

## 二、Bot → 模块分配

### 🧠 知几 (数据分析师)
**核心模块**: `intelligence_hub.py` + `savings_engine.py`

| 职责 | 说明 |
|------|------|
| 综合情报引擎 | 多平台数据聚合 + 权重评分 + 性价比排序 |
| 大数据分析 | 旺季/淡季数据对比、出游人数预测、热门趋势 |
| 省钱方案 | savings_engine: 折扣分析、套餐对比、优惠路线 |
| 评分加权 | 酒店/餐馆/景点的(评分+情感)/价格 排序算法 |
| 最佳时段 | 历史天气+价格波动数据 → 推荐最优出行时间 |

**触发场景**: 用户问"哪个时间段便宜"、"性价比高的酒店"、"数据分析"

---

### 🏔️ 山木 (业务执行者)
**核心模块**: `planner.py` + 流程编排 (short_tour/deep_tour)

| 职责 | 说明 |
|------|------|
| 行程规划 | 每日动线安排、景点间衔接、时间分配 |
| 短游编排 (1-3天) | 执行 short_tour.py 流程：快准稳 |
| 深度游编排 (5-14天) | 执行 deep_tour.py 流程：沉浸式体验设计 |
| 团体游编排 | 多成员行程协同、弹性空间、留白设计 |
| 输出交付 | 格式化最终产出（清晰可执行的行程单） |

**触发场景**: 用户说"帮我规划"、"做个行程"、"安排3天"

---

### 📚 素问 (技术研究员)
**核心模块**: `destination_guide.py` + `weather_safety.py`

| 职责 | 说明 |
|------|------|
| 目的地文化指南 | 风俗习惯、历史背景、语言支持、当地法规 |
| 签证/证件研究 | 签证要求、办理渠道、有效期 |
| 天气安全预警 | 实时天气、极端天气预警、健康预防建议 |
| 紧急预案 | 大使馆/医院/报警/保险信息（国外特有） |
| API 服务 | serve --port 模式的技术支持和维护 |

**触发场景**: 用户问"当地有什么风俗"、"需要签证吗"、"天气怎么样"、"安全吗"

---

### 🔍 罔两 (市场情报官)
**核心模块**: 多平台搜索 + 大V/博主查询 + 真实验证

| 职责 | 说明 |
|------|------|
| 酒店真实信息 | 多渠道比价、真实地址/电话/图片验证 |
| 餐馆真实评价 | 去除水军、真实评价聚合、特色菜验证 |
| 景点真实信息 | 开放时间、票价、地图、当前状态 |
| 大V/博主情报 | 44位大V·12平台·含粉丝/风格/链接 |
| 竞品/同行动态 | 旅行社报价对比、目的地热度监控 |

**触发场景**: 用户问"这个酒店真的好吗"、"哪个博主去过"、"真实评价"

---

### 💰 庖丁 (财务管控官)
**核心模块**: `savings_engine.py` + 预算分解

| 职责 | 说明 |
|------|------|
| 三档预算 | 穷游/标准/奢华 完整预算分解 |
| 成本优化 | 机票+住宿+餐饮+门票+购物的总成本 |
| 省钱秘籍 | 折扣通道、学生/老人优惠、团体优惠 |
| 财务风险 | 汇率波动（国外）、隐藏消费、退款政策 |
| ROI 分析 | 每条路线/景点的花钱值不值 |

**触发场景**: 用户问"多少钱"、"预算"、"穷游"、"帮我算账"

---

### 🌟 太一 (统筹者/最终决策)
- 用户一句话进来 → 太一解析意图
- 单域任务 → 直接指定一个 Bot
- 跨域任务 → 拆解 → 并行分派 → 聚合
- **每个 Bot 的结果必须经太一确认才算输出**
- **太一有权打断/重分配/否决任何 Bot 的结果**

**触发场景**: 所有旅行请求 → 必经太一

| 用户意图 | 主Bot | 辅Bot | 说明 |
|---------|-------|-------|------|
| "去X玩X天"（纯规划） | 山木 | 素问（目的研究） | 自动触发路线+文化 |

| "X预算够吗" | 庖丁 | 知几（数据） | 成本分解+对比 |
| "X有什么景点" | 罔两 | 山木（行程） | 景点验证+动线 |
| "X天气安全吗" | 素问 | 知几（数据） | 天气+季节趋势 |
| "X餐馆好吃吗" | 罔两 | 知几（评分） | 真实评价+性价比 |
| "帮全家规划X"（团体） | 山木 | 庖丁+罔两 | 行程+预算+住宿 |
| "去X自由行攻略" | 知几 | 所有Bot | 综合评估→全链路 |
| "X签证怎么办" | 素问 | — | 纯研究任务 |
| "X值得去吗" | 罔两 | 知几（数据） | 情报+评分 |
| "X比Y哪个划算" | 知几 | 庖丁 | 数据对比+财务 |

## 四、调度流程（每次请求）

```
第1步：太一接收 → 意图解析
        ├── 国内/国际？
        ├── 短游/深度/团体？
        ├── 单域/跨域？
        └── 优先级？
        
第2步：任务拆解 → Bot分派
        ├── 单域 → 直接派一个Bot
        └── 跨域 → 拆子任务 → 并行派多个Bot
        
第3步：结果聚合 → 太一整合
        ├── 合并各个Bot产出
        ├── 冲突时辩论投票
        └── 太一最终裁决
        
第4步：交付 → 格式化输出给SAYELF
        ├── 清晰可执行的行程/信息
        └── 所有数据附带 verification_links
```

## 五、API 与自动化

- **短游 CLI**: `domestic-travel-agent/travel_cli.py short --city X --days N`
- **深度游 CLI**: `domestic-travel-agent/travel_cli.py deep --city X --days N`
- **国际版**: `international-travel-agent/cli.py short --city X --days N`
