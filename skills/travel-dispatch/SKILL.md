# 太一 · 旅游探路者自动调度系统

> 使用说明：SAYELF 只需说旅行需求，太一自动调度对应 Bot

---

## 📋 职责分配总表

| Bot | 负责模块 | 场景关键词 |
|-----|---------|-----------|
| **知几** (数据分析师) | 情报引擎·省钱分析·数据对比 | 数据/分析/评分/性价比/什么时候/对比 |
| **山木** (业务执行者) | 行程规划·短游/深度/团体编排·输出交付 | 规划/安排/行程/攻略/路线/做计划 |
| **素问** (技术研究员) | 目的文化·签证·天气安全·紧急预案 | 签证/文化/风俗/天气/安全/使领馆/法律 |
| **罔两** (市场情报官) | 真实酒店/餐馆/景点·大V博主·真实验证 | 推荐/评价/好吃/好玩/博主/口碑/真实 |
| **庖丁** (财务管控官) | 预算分解·成本优化·省钱方案 | 多少钱/预算/穷游/划算/成本/性价比 |

**太一**: 接收需求 → 意图解析 → 任务拆解 → 分派 Bot → 聚合结果 → 交付

## ⚙️ 自动调度逻辑

### 步骤 1: 意图解析
收到 SAYELF 的旅行需求后，立即分析：
- **国内/国际？** → 国内调 `domestic-travel-agent`，国际调 `international-travel-agent`
- **短游/深度/团体？** → 短游走 short_tour 流程，深度走 deep_tour 流程
- **单域/跨域？** → 单域直接派，跨域拆解分派
- **优先级？** → P0 立即做 / P1 顺次做 / P2 有空做

### 步骤 2: 任务分派

**单域请求 → 直接分派（示例）：**
```
"东京签证怎么办"  → 素问（纯研究任务）
"成都玩3天帮我规划" → 山木（纯规划任务）
"普吉岛最值得住的酒店" → 罔两（情报+验证）
```

**跨域请求 → 拆解→并行分派（示例）：**
```
"去三亚家族旅行10天，预算5万" 
→ 山木(行程规划) + 庖丁(预算控制) + 罔两(酒店验证) 并行

"去曼谷深度玩一周，有什么要注意的"
→ 知几(数据+季节) + 素问(文化+天气) + 山木(行程)
```

### 步骤 3: 聚合交付
- 并行 Bot 结果 → 太一聚合
- 冲突时走辩论投票（置信度加权）
- 最终输出附带 verification_links

## 🤖 自动调度引擎

> traveled dispatcher.py — 自然语言 → 意图解析 → Bot 分派 → 结果聚合

`travel_dispatcher.py` 是调度代码，替代原先纯文档驱动的路由方式：

```bash
python3 travel_dispatcher.py "去成都玩3天"
python3 travel_dispatcher.py "东京7天深度游要多少钱"
```

### 三层路由

| 模式 | 用户说 | 返回 |
|------|-------|------|
| `selected`（默认） | "推荐""精华""热门" | Top N 精选景点/餐厅/酒店 |
| `daily` | "规划""行程""攻略" | 完整逐日行程打包 |
| `all` | "全部""所有""全量" | 全部数据含冷信息 |

### Bot 自动分派

| 触发词 | 分派 Bot | 调用模块 |
|--------|---------|--------|
| 数据/分析/评分 | 知几 | intelligence_hub |
| 规划/行程/安排 | 山木 | planner |
| 签证/天气/安全 | 素问 | destination_guide |
| 推荐/酒店/餐厅 | 罔两 | hotels/restaurants |
| 预算/费用/划算 | 庖丁 | savings_engine |

## ✅ 使用示例

**SAYELF**: "去成都玩3天"
**太一自动执行**:
```
① 意图: 国内·短游·跨域(情报+规划+天气)
② 并行:
   知几 → 情报引擎搜索成都数据
   罔两 → 成都酒店/餐馆/景点验证
   素问 → 成都天气+风俗检查
③ 聚合:
   山木 → 生成3天行程（含知几+罔两+素问输入）
④ 交付: 完整攻略+验证链接
```

**SAYELF**: "东京7天深度游要多少钱"
**太一自动执行**:
```
① 意图: 国际·深度·跨域(预算+情报)
② 并行:
   知几 → 东京消费数据+季节分析
   庖丁 → 机票+住宿+餐饮+门票预算分解
③ 交付: 三档预算方案+季节建议
```
