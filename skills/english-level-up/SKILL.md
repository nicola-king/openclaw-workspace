# English Level-Up Skill — AI 英语学习

基于开源项目 byoungd/English-level-up-tips（⭐45839），整合 2026 版 AI 学英语方法论。

## 核心原则

> **不要把 AI 当词典/翻译器——把 AI 配成一个会带节奏、会出题、会纠错、会追问的英语私教。**

## 自动触发规则

| 场景 | 触发条件 | 调用方式 |
|------|---------|---------|
| **英文写作** | 需要写英文邮件、开发信、文章 | Gemini CLI 润色 + 指南写作方法论 |
| **词汇扩展** | 遇到生词、需要更地道表达 | 词汇章节方法 + Gemini 例句生成 |
| **口语练习** | 需要练口语、准备英文演讲 | Gemini Live + Guided Learning |
| **阅读辅助** | 看不懂英文文章、合同、邮件 | Gemini 阅读理解 + 词汇解析 |
| **听力训练** | 需要练听力、看英文视频 | 听力章节方法 + Gemini 生成测验 |
| **开发信优化** | 外贸开发信需要更地道 | Gemini CLI 改写 + 商务英语风格 |
| **GEO 内容** | 需要生成英文社媒内容 | Gemini CLI 创作 + 语法校对 |

## 手动触发命令

```
/英语 <问题>        → 英语学习/翻译/语法问答
/写作 <内容>        → AI 辅助英文写作
/润色 <内容>        → 英文润色 + 改写建议
/开发信 <产品> <市场> → 生成英文开发信
/词汇 <词>          → 词汇深度解析 + 记忆技巧
/口语 <场景>        → 场景口语练习提纲
```

## 核心方法论（来自指南 2026 版）

1. **用 Gemini 搭英语私教系统** — 不零散对话，而是持续出题、纠错、追问、复习
2. **Guided Learning** — 让 AI 分步引导，不直接给答案
3. **Quiz & Flashcards** — 阅读/听力后自动生成测验和闪卡
4. **Canvas 改作文** — 批量改写、润色、调整语气
5. **Gemini Live 练口语** — 自然来回对话，随时开口
