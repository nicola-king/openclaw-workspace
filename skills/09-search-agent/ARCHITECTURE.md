# 🔍 智能搜索 Agent 架构文档

## 📋 概述

智能搜索 Agent 是太一系统的统一搜索入口，具备以下核心能力：

- **多层反反爬策略** - Playwright 浏览器自动化 + 代理轮换 + 指纹伪装
- **智能路由选择** - 根据区域/优先级自动选择最佳搜索引擎
- **自进化学习** - 持续优化搜索策略和参数
- **模块化架构** - 易于扩展和维护

## 📦 模块说明

### 1. 搜索路由层 (Search Router)

**功能：** 智能选择最佳搜索渠道

**决策逻辑：**
```python
if 区域 == 海外:
    引擎 = "bing"  # 海外优先
elif 区域 == 国内:
    引擎 = "baidu"  # 国内备用
elif 优先级 == 高:
    引擎 = "google"  # 高质量结果
else:
    引擎 = "duckduckgo"  # 快速搜索
```

### 2. 反爬对抗层 (Anti-Scraping)

**功能：** 多层反反爬策略

**策略清单：**
- **Playwright 浏览器** - 绕过 JS 渲染
- **代理轮换** - 海外/国内代理池
- **指纹伪装** - 隐藏 WebDriver 特征
- **速率控制** - 随机延迟 + 请求间隔
- **验证码处理** - 自动检测 + 解决

### 3. 搜索引擎层 (Search Engines)

**功能：** 多引擎搜索支持

**引擎特性：**
| 引擎 | 优先级 | 特点 | 适用场景 |
|------|--------|------|----------|
| Bing | 高 | 海外覆盖广 | 国际采购 |
| Google | 最高 | 结果质量高 | 精确搜索 |
| DuckDuckGo | 中 | 隐私保护 | 快速搜索 |
| Baidu | 低 | 国内覆盖 | 国内采购 |

### 4. 数据提取层 (Data Extractor)

**功能：** 结构化数据提取和验证

**提取流程：**
```
HTML 响应 → BeautifulSoup 解析 → 信息提取 → 数据验证 → 置信度评分
```

**验证规则：**
- 公司名称必须包含关键词
- 网站 URL 必须有效
- 邮箱格式必须正确
- 电话号码必须合理

### 5. 自进化层 (Self-Evolution)

**功能：** 持续优化搜索策略

**进化循环：**
```
搜索请求 → 执行搜索 → 结果评估 → 策略更新 → 知识库保存
    ↓
成功率统计 → 策略优化 → 配置更新 → 下次搜索
```

**进化指标：**
- 成功率 (>80%)
- 响应时间 (<5s)
- 数据质量 (>90%)
- 反爬率 (<20%)

## 🚀 使用方式

### 命令行接口

```bash
# 基本搜索
python3 main.py --query "foldable container house" --regions "Southeast Asia"

# 高级搜索
python3 main.py --query "steel structure house" --priority high --engine bing

# 系统管理
python3 main.py --status    # 查看状态
python3 main.py --test      # 运行测试
python3 main.py --evolve    # 执行进化
```

### Python API

```python
from core.search_agent import SearchAgent, SearchRegion, SearchPriority

# 创建搜索 Agent
agent = SearchAgent()

# 执行搜索
results = agent.search(
    query="foldable container house buyer",
    regions=[SearchRegion.SOUTHEAST_ASIA, SearchRegion.MIDDLE_EAST],
    priority=SearchPriority.HIGH
)

# 处理结果
for result in results:
    print(f"{result.company_name}: {result.website}")

# 关闭
agent.close()
```

### 太一系统集成

```python
from skills.09_search_agent.core.search_agent import SearchAgent

# 在太一系统中使用
agent = SearchAgent()
results = agent.search("container house importer", ["Europe", "USA"])
```

## 🔄 自进化机制

### 学习循环

1. **数据收集** - 记录每次搜索的指标
2. **性能分析** - 计算平均成功率和响应时间
3. **策略优化** - 根据分析结果调整参数
4. **知识库更新** - 保存成功和失败的经验
5. **配置更新** - 应用优化后的配置

### 进化策略

```python
if 成功率 < 70%:
    切换引擎 = "google"
    重试次数 = 3
elif 响应时间 > 5s:
    启用代理轮换 = True
    延迟范围 = [0.5, 1.5]
else:
    保持当前配置
```

## 🛠️ 配置说明

### 搜索引擎配置

```json
{
  "search_engines": {
    "priority": ["bing", "google", "duckduckgo", "baidu"],
    "fallback": true,
    "max_retries": 3
  }
}
```

### 代理配置

```json
{
  "proxy": {
    "enabled": true,
    "overseas": ["http://proxy1:8080"],
    "domestic": ["http://proxy2:8080"]
  }
}
```

### 反爬配置

```json
{
  "anti_scraping": {
    "enabled": true,
    "delay_range": [1, 3],
    "max_retries": 3
  }
}
```

## 📈 扩展性

### 新增搜索引擎

1. 在 `modules/` 目录创建新引擎文件
2. 实现 `search()` 方法
3. 在 `search_agent.py` 中添加路由逻辑
4. 更新配置文件

### 新增反爬策略

1. 在 `strategies/` 目录创建新策略文件
2. 实现策略接口
3. 在 `anti_scraping.py` 中集成
4. 更新配置

### 新增数据提取器

1. 在 `modules/` 目录创建新提取器
2. 实现 `extract()` 方法
3. 在 `data_extractor.py` 中注册
4. 更新验证规则

## 🔒 安全考虑

### 数据安全
- 所有搜索数据本地存储
- 不上传用户查询到第三方
- 加密存储敏感信息

### 反爬安全
- 遵守 robots.txt 协议
- 合理控制请求频率
- 使用合法代理服务

### 隐私保护
- 不收集个人信息
- 搜索历史本地保存
- 支持数据删除
