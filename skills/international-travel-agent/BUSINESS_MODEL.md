# 旅游探路者 — 三方价值模型

## 👤 个人用户 (B2C)
**场景:** 短游/深度游/自由行
**接入:** CLI / Telegram Bot / Web UI
**免费功能:**
- 行程规划（自动生成+手动调整）
- 真实酒店/餐馆/景点信息（验证链接）
- 天气+安全预警
- 博主/社交媒体综合评估

## 👥 团体/公司用户 (B2B/企业)
**场景:** 团建/会议/奖励旅游/考察
**接入:** CLI (批量) / API / MCP
**增值功能:**
- 多成员行程协调
- 团队预算管理
- 批量酒店/租车/导游预订
- 行程共享+PDF导出
- 企业差旅报告

## 🏪 商家端 (B2B/供应商)
**场景:** 导游/租车/酒店/餐馆 入驻
**接入:** API / MCP
**商业模式:**
- 免费入驻（信息验证）
- 付费推广（置顶/推荐）
- 预订抽佣（可选）
