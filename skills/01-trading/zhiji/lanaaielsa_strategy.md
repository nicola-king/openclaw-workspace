## 🛑 止损策略

### 核心原则

```
"无论开多大仓位，亏 200U 就出"
```

### 特点

| 特点 | 说明 |
|------|------|
| **固定金额止损** | 不是百分比，是固定 200U |
| **无关仓位** | 无论开多大仓位，都亏 200U 止损 |
| **严格执行** | AI 执行纪律是优势 |
| **行情依赖** | "行情占 90%" |

### 计算公式

```
止损价格 = 入场价格 × (1 - 止损金额 / 仓位大小)

示例:
• 仓位：100U
• 止损：200U
• 入场：$100
• 止损价格 = $100 × (1 - 200/100) = $100 × (-1) = 负数

注意：当止损金额 > 仓位时，意味着全仓止损
实际应该：
• 仓位：1000U
• 止损：200U (20%)
• 入场：$100
• 止损价格 = $100 × (1 - 200/1000) = $100 × 0.8 = $80
```

## 🎯 知几策略融合

### 配置更新

```python
# 知几交易配置
TRADING_CONFIG = {
    # 社交信号配置
    'social_signals': {
        'enabled': True,
        'min_post_count': 100,      # 最小发帖量
        'min_likes': 400,           # 最小点赞数
        'min_views': 100000,        # 最小浏览量 (10 万)
        'sources': ['binance_square', 'twitter', 'telegram'],
    },
    
    # 止损配置 (lanaaielsa 风格)
    'stop_loss': {
        'type': 'fixed_usdt',       # 固定金额止损
        'amount': 200,              # 亏 200U 就出
        'not_percentage': True,     # 不是百分比
    },
    
    # 仓位配置
    'position': {
        'initial': 100,             # 100U 起步
        'max_per_trade': 1000,      # 单笔最大 1000U
    },
}
```

### 交易流程

```
1. 爬虫抓取币安广场/推特数据
   ↓
2. 分析社交热度 (发帖量/点赞/浏览)
   ↓
3. 筛选热门币种 (前 10)
   ↓
4. 对应涨幅榜找异动 (>5%)
   ↓
5. 生成交易信号
   ↓
6. 自动买入 + 挂止损
   ↓
7. 严格执行止损 (亏 200U 就出)
```

## 📈 关键洞察

### lanaaielsa 的评价

> "行情占 90%，AI 执行纪律是优势，换个行情可能就失效了。"

### 解读

| 因素 | 占比 | 说明 |
|------|------|------|
| **行情** | 90% | 牛市/熊市决定成败 |
| **AI 执行** | 10% | 纪律性是唯一优势 |
| **策略** | - | 换个行情可能失效 |

### 启示

1. **顺势而为**: 只在牛市使用此策略
2. **严格止损**: AI 执行纪律是核心优势
3. **灵活调整**: 熊市需要切换策略
4. **风险控制**: 固定止损保护本金
