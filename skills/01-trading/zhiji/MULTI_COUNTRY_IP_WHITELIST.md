## 🔍 监控 IP 变化

### 定时检测

```bash
# 添加到 crontab
*/30 * * * * curl -s -x http://127.0.0.1:7890 https://api.ipify.org >> /home/nicola/.openclaw/workspace/logs/export_ip.log
```

### IP 变化告警

```bash
# 检测 IP 是否变化
LAST_IP=$(cat /tmp/last_export_ip.txt)
CURRENT_IP=$(curl -s -x http://127.0.0.1:7890 https://api.ipify.org)

if [ "$LAST_IP" != "$CURRENT_IP" ]; then
  echo "⚠️ IP 变化告警：$LAST_IP → $CURRENT_IP"
  echo "$CURRENT_IP" > /tmp/last_export_ip.txt
  # 可以添加 Telegram 告警
fi
```
