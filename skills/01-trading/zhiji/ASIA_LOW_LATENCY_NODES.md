## 🔧 测试方法

### 测试节点延迟

```bash
# 切换到对应节点后测试
curl -s -o /dev/null -w "延迟：%{time_total}s\n" -x http://127.0.0.1:7890 https://api.binance.com
```

### 测试节点 IP

```bash
# 切换到对应节点后测试

```

### 多次测试确保稳定

```bash
# 测试 10 次
for i in $(seq 1 10); do 
  echo "测试 $i: $(curl -s -x http://127.0.0.1:7890 https://api.ipify.org)"
  sleep 0.3
done
```
