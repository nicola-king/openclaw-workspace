# IP 监控 - 后台静默模式

> 版本：v3.0 (Silent Mode)  
> 创建：2026-04-23  
> 指令：SAYELF - 后台处理，需要时查询

---

## 🎯 工作模式

```
IP 监控 → 后台静默运行 → 自动切换 → 需要时查询
```

---

## 🔕 静默处理

### 已禁用的通知

| 场景 | 原行为 | 现行为 |
|------|--------|--------|
| IP 变化 | 发送 Telegram | 记录到日志 |
| IP 飘浮 | 发送告警 | 记录到告警历史 |
| IP 稳定 | 发送确认 | 记录到日志 |

### 保留的功能

| 功能 | 状态 | 说明 |
|------|------|------|
| IP 监控 | ✅ 运行 | 每 5 分钟检查 |
| 日志记录 | ✅ 运行 | 所有事件写入日志 |
| 告警历史 | ✅ 运行 | 重要事件单独记录 |
| 自动切换 | ✅ 运行 | 知几自动读取新 IP |

## 📊 查询命令

### 查看当前 IP

```bash
bash skills/01-trading/zhiji/ip_monitor.sh status
```

**输出**:
```
========================================
IP 监控状态
========================================

当前 IP: 141.11.146.70
告警计数：0
日志文件：/home/nicola/.openclaw/workspace/logs/ip_monitor.log
检查间隔：300 秒
```

### 查看 IP 历史

```bash
bash skills/01-trading/zhiji/ip_monitor.sh history
```

**输出**:
```
========================================
IP 历史记录
========================================

2026-04-23 10:05:01,141.11.146.70,141.11.146.70
2026-04-23 09:35:02,103.151.173.206,103.151.173.206
...
```

### 查看告警历史

```bash
bash skills/01-trading/zhiji/ip_monitor.sh alerts
```

**输出**:
```
========================================
IP 告警历史 (后台静默记录)
========================================

[2026-04-23 09:35:41] IP 变化：141.11.146.70 → 103.151.173.206
[2026-04-23 09:30:15] IP 飘浮：连续 3 次不稳定
...
```

### 测试 IP 固定性

```bash
bash skills/01-trading/zhiji/ip_monitor.sh test
```

## 📂 文件位置

| 文件 | 用途 | 查询方式 |
|------|------|---------|
| `/tmp/last_export_ip.txt` | 当前 IP | `cat /tmp/last_export_ip.txt` |
| `logs/ip_monitor.log` | 完整日志 | `tail -100 logs/ip_monitor.log` |
| `logs/ip_monitor.log.alerts` | 告警历史 | `bash ip_monitor.sh alerts` |

## 📊 监控指标

| 指标 | 频率 | 记录位置 |
|------|------|---------|
| IP 检查 | 每 5 分钟 | ip_monitor.log |
