## 🐆 猎豹交易哲学

### 核心原则

```
1. 伺机而动 - 等待最佳时机
2. 可以潜伏 - 耐心等待高置信度机会
3. 可以出击 - 机会来临时果断出手
4. 不能为了动而动 - 拒绝低质量交易
5. 王牌狙击手 - 不动则已，动则一击必中
```

---

## 📊 交易质量对比

| 模式 | 交易频率 | 胜率 | 盈亏比 | 总收益 |
|------|---------|------|--------|--------|
| **频繁交易** | 高 (50+/天) | 低 (40-50%) | 低 (1:1) | 低 |
| **猎豹式** | 低 (5-10/天) | 高 (70-80%) | 高 (1:3) | 高 |

## 📈 猎豹式交易流程

```
1. 市场扫描 (持续)
   ↓
2. 机会识别 (等待)
   ↓
3. 置信度评估 (>80%?)
   ↓
   ├─ 否 → 继续潜伏等待
   └─ 是 → 果断出击
       ↓
4. 执行交易 (一击必中)
   ↓
5. 风控保护 (止损/止盈)
   ↓
6. 学习进化
```

## 📊 猎豹式 vs 频繁交易

### 猎豹式 (推荐)
```
• 每日交易：5-10 笔
• 平均置信度：85%
• 胜率：70-80%
• 盈亏比：1:3
• 月收益：20-30%
• 最大回撤：<10%
• 心态：平静、耐心
```

### 频繁交易 (不推荐)
```
• 每日交易：50+ 笔
• 平均置信度：55%
• 胜率：40-50%
• 盈亏比：1:1
• 月收益：5-10% (或亏损)
• 最大回撤：>20%
• 心态：焦虑、急躁
```

## 🧠 心理建设

✅ "等待我的最佳机会"

❌ "市场在涨，我要马上买入"

❌ "已经 1 小时没交易了"
✅ "潜伏是猎豹的天性"
```

### 接受错过
```
❌ "错过了那次交易好后悔"
✅ "错过是常态，抓住关键几次就够了"

❌ "应该早点出手的"
✅ "当时置信度不足，等待是正确的"
```

⏳ 资金不足
⏳ 重大事件即将发生
```
