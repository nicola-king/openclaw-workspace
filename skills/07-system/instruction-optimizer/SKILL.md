## 📐 四维度评估框架

```
指令质量 = 角色清晰度 × 方法论指定 × 背景完整度 × 行动具体度
```

| 维度 | 权重 | 评估标准 |
|------|------|---------|
| **角色设定** | 25% | 是否指定专家身份/思维框架 |
| **方法论指定** | 25% | 是否指定方法论/参考框架 |
| **背景交代** | 25% | 领域/目标/基础/脉络是否完整 |
| **行动导向** | 25% | 输出是否可执行/可落地 |

## 🧠 核心算法

### 指令质量评分算法

```python
def evaluate(instruction: str) -> Dict:
    score = 0
    dimensions = {}
    
    # 角色清晰度 (25 分)
    role_keywords = ["专家", "顾问", "教练", "教授", "身份", "角色"]
    dimensions["role"] = min(25, len([k for k in role_keywords if k in instruction]) * 5)
    
    # 方法论指定 (25 分)
    method_keywords = ["方法", "理论", "框架", "模型", "法则", "原理", "技巧"]
    dimensions["method"] = min(25, len([k for k in method_keywords if k in instruction]) * 5)
    
    # 背景完整度 (25 分)
    context_keywords = ["目标", "基础", "背景", "领域", "时间", "约束"]
    dimensions["context"] = min(25, len([k for k in context_keywords if k in instruction]) * 4)
    
    # 行动具体度 (25 分)
    action_keywords = ["方案", "计划", "步骤", "行动", "执行", "落地", "具体"]
    dimensions["action"] = min(25, len([k for k in action_keywords if k in instruction]) * 5)
    
    score = sum(dimensions.values())
    
    return {
        "score": score,
        "dimensions": dimensions,
        "level": get_level(score),
        "missing": get_missing(dimensions),
        "suggestions": generate_suggestions(dimensions)
    }
```
