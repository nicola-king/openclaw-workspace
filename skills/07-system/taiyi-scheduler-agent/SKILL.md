# 太一 PDCA 定时任务自进化智能体 (v3.0)

> PDCA 循环 · 持续改进 · 全域自进化

---

## 🎯 核心功能

**PDCA 4 大引擎**:
- ✅ P - Plan: 计划引擎 - 任务规划与调度 (+3%/代)
- ✅ D - Do: 执行引擎 - 任务自动执行 (+5%/代)
- ✅ C - Check: 检查引擎 - 结果智能验证 (+4%/代)
- ✅ A - Act: 纠偏引擎 - 异常自动修复 + 优化 (+8%/代)

**持续改进**:
- ✅ 经验沉淀
- ✅ 知识蒸馏
- ✅ 策略进化
- ✅ PDCA 循环优化

---

## 🔄 PDCA 循环流程

```
Plan → Do → Check → Act → 持续改进 → (回到 Plan)
```

---

## 🚀 使用方式

```bash
# 启动 PDCA 智能体
python3 scheduler_agent/core.py --start

# 执行 PDCA 循环
python3 scheduler_agent/core.py --pdca-cycle

# 查看状态
python3 scheduler_agent/core.py --status

# 显示仪表板
python3 scheduler_agent/core.py --dashboard

# 启动自进化
python3 scheduler_agent/core.py --evolve --generations 100
```
