# 📋 太一 Agent 标准化交接模板

> **版本**: v1.0  
> **创建时间**: 2026-04-16 20:04  
> **用途**: 标准化 Agent 间上下文传递

## 1. 标准交接模板

用于任何 Agent 到 Agent 的工作交接。

```markdown
# 太一 Agent 交接文档

## 元数据
| 字段 | 值 |
|------|-----|
| **从** | [Agent A 名称] |
| **到** | [Agent B 名称] |
| **阶段** | Phase [N] - [阶段名称] |
| **任务** | [Task ID] |
| **优先级** | Critical/High/Medium/Low |
| **时间戳** | [YYYY-MM-DDTHH:MM:SSZ] |

## 上下文
**项目**: [项目名称]
**当前状态**: [已完成的工作 - 具体描述]
**相关文件**:
- [file/path/1] - [内容描述]
- [file/path/2] - [内容描述]
**依赖关系**: [依赖项列表]
**约束条件**: [技术/时间/资源约束]

## 交付请求
**需要什么**: [具体交付物描述]
**验收标准**:
- [ ] [标准 1 - 可衡量]
- [ ] [标准 2 - 可衡量]
- [ ] [标准 3 - 可衡量]
**参考资料**: [规范/设计/历史工作路径]

## 质量期望
**必须通过**: [具体质量标准]
**需要证据**: [完成证据形式 - 截图/日志/数据]
**下一环节**: [接收方和格式要求]
```

## 2. Dev→QA 交接模板

```markdown
# Dev→QA 交接文档

|------|-----|
| **从** | [Developer Agent] |
| **到** | [QA Agent] |
| **阶段** | Dev↔QA Loop |

| **尝试** | [N] of 3 |

## 实现上下文
**任务描述**: [任务详细描述]
**实现方法**: [实现方法描述]
**修改文件**:
- [file/path/1] - [修改内容]
- [file/path/2] - [修改内容]
**测试数据**: [测试数据路径]

## 验收标准
- [ ] [验收标准 1]
- [ ] [验收标准 2]
- [ ] [验收标准 3]

## 自验证
**开发者自测**: [是/否]
**自测结果**: [通过/失败]
**已知问题**: [任何问题列表]

## QA 验证请求
**验证类型**: [功能/性能/安全/兼容性]
**验证环境**: [环境描述]
**特殊说明**: [任何特殊说明]
```

## 3. QA→Dev 反馈模板

用于 QA Agent 到 Developer Agent 的反馈。

```markdown
# QA 反馈文档

## 元数据
| 字段 | 值 |
|------|-----|
| **从** | [QA Agent] |
| **到** | [Developer Agent] |
| **任务** | [Task ID] |
| **尝试** | [N] of 3 |
| **裁决** | PASS/FAIL |

## 裁决：[PASS/FAIL]

## 发现的问题

### 问题 1: [类别] - [严重程度：Critical/High/Medium/Low]
**描述**: [问题的具体描述]
**期望**: [根据验收标准应该怎样]
**实际**: [实际发生了什么]
**证据**: [截图文件名/测试输出]
**修复说明**: [具体的修复说明]
**修改文件**: [需要修改的文件路径]

### 问题 2: [类别] - [严重程度]
**描述**: [...]
**期望**: [...]
**实际**: [...]
**证据**: [...]
**修复说明**: [...]
**修改文件**: [...]

[继续列出所有问题]

## 验收标准状态
- [x] [标准 1] - 通过
- [ ] [标准 2] - 失败 (见问题 1)
- [ ] [标准 3] - 失败 (见问题 2)

## 重试说明
**给 Developer Agent**:
1. 仅修复上述问题
2. 不要引入新功能或更改
3. 修复完成后重新提交 QA
4. 这是第 [N] 次尝试，共 3 次最大

**如果第 3 次失败**: 任务将升级到太一 NEXUS 编排器
```

## 5. 升级报告模板

用于任务超过 3 次重试时的升级。

```markdown
# 太一升级报告 🚨

## 任务
| 字段 | 值 |
|------|-----|
| **任务 ID** | [ID] |
| **任务描述** | [描述] |
| **Developer Agent** | [Agent 名称] |
| **QA Agent** | [Agent 名称] |
| **尝试次数耗尽** | 3/3 |
| **升级到** | [太一 NEXUS 编排器/Studio Producer] |
| **时间戳** | [YYYY-MM-DDTHH:MM:SSZ] |

## 失败历史

### 第 1 次尝试
- **发现问题**: [摘要]
- **应用修复**: [Developer 修改了什么]
- **结果**: 失败 - [为什么仍然失败]

### 第 2 次尝试
- **发现问题**: [摘要]
- **应用修复**: [Developer 修改了什么]
- **结果**: 失败 - [为什么仍然失败]

### 第 3 次尝试
- **发现问题**: [摘要]
- **应用修复**: [Developer 修改了什么]
- **结果**: 失败 - [为什么仍然失败]

## 根因分析
**任务持续失败的原因**: [潜在问题分析]
**系统性问题**: [是单一问题还是模式]
**复杂度评估**: [任务范围是否合适]

## 建议解决方案
- [ ] **重新分配** 给不同的 developer agent ([建议 agent])
- [ ] **分解** 为更小的子任务 ([建议分解])
- [ ] **修改方法** - 需要架构/设计更改
- [ ] **接受** 当前状态并记录限制
- [ ] **推迟** 到下一冲刺

## 影响评估
**阻塞**: [哪些其他任务被阻塞]
**时间线影响**: [如何影响整体时间表]
**质量影响**: [如果接受当前状态存在什么质量妥协]

## 需要决策
**决策者**: [太一 NEXUS 编排器/Studio Producer]
**截止时间**: [避免进一步延迟的决策时间]
```

## 使用指南

| 情况 | 使用的模板 |
|------|------------|
| 分配工作给另一个 Agent | 标准交接 (#1) |
| QA 批准任务 | QA PASS (Dev→QA #2) |
| QA 拒绝任务 | QA FAIL (QA→Dev #3) |
| 任务超过 3 次重试 | 升级报告 (#5) |
| Phase 间过渡 | Phase 门禁交接 (#4) |
