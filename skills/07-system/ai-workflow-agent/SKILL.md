## 📊 核心模块

### 1. 工作流编排

**功能**:
- ✅ 任务拆解
- ✅ 依赖关系管理
- ✅ 并行/串行执行
- ✅ 错误处理

**示例**:
```
每日新闻推送工作流:
1. 抓取新闻源
2. 过滤分类
3. LLM 摘要生成
4. 格式化输出
5. 推送给用户
```
