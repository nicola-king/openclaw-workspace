## 🔧 OBS 配置

### 配置文件位置

```
~/.config/obs-studio/basic/profiles/未命名/basic.ini
```

### 关键配置

```ini
[Video]
BaseCX=1920
BaseCY=1080
OutputCX=1280
OutputCY=720
FPSCommon=30

[SimpleOutput]
FilePath=/home/nicola/Videos
RecFormat2=mp4
VBitrate=6000
Encoder=obs_x264
```

## 🎯 使用场景

## ⚠️ 注意事项

### 录制前检查

- [ ] OBS 已安装
- [ ] 录制目录存在 (~/Videos/)
- [ ] 麦克风权限已授予
- [ ] 屏幕录制权限已授予

### 录制中注意

- 不要最小化 OBS 窗口
- 确保有足够磁盘空间
- 避免运行高性能占用程序

### 录制后检查

- [ ] 文件已生成
- [ ] 文件大小正常 (>0MB)
- [ ] 播放测试正常
- [ ] 音频质量可接受
