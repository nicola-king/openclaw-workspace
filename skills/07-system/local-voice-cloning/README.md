## 🚀 快速上手

### 1. 安装依赖和模型 (首次运行)

```bash
cd /home/nicola/.openclaw/workspace
python3 skills/07-system/local-voice-cloning/local_voice_cloning.py setup
```

**预计时间**: 10-15 分钟 (下载 2GB 模型)

---

### 2. 准备声音样本

**录音要求**:

| 要求 | 详情 |
|------|------|
| **时长** | 30 秒 -5 分钟 (推荐 1 分钟) |
| **格式** | MP3, WAV, M4A |
| **质量** | 清晰、无背景噪音 |
| **内容** | 自然说话、多种语调 |
| **语言** | 中文 (推荐) |

**录音示例**:

```
"你好，这是我的声音样本。
我正在录制这段音频用于声音克隆。
今天天气不错，我希望这个克隆效果能够成功。
太一 AGI 是一个非常强大的系统。"
```

---

### 3. 克隆声音

```bash
# 将 sample.wav 替换为你的音频文件
python3 skills/07-system/local-voice-cloning/local_voice_cloning.py clone 我的声音 sample.wav
```

**输出**:
```
🎙️ 正在克隆声音：我的声音
样本文件：sample.wav
✅ 声音克隆成功：我的声音
配置文件：/home/nicola/.openclaw/workspace/voices/我的声音.json
```

---

### 4. 生成语音

```bash
python3 skills/07-system/local-voice-cloning/local_voice_cloning.py speak 我的声音 "你好，这是用我的声音生成的语音"
```

**输出**:
```
🔊 正在生成语音：你好，这是用我的声音生成的语音...
⏳ 生成中... (CPU 推理约需 30-60 秒)
✅ 语音生成成功：/home/nicola/.openclaw/workspace/audio/我的声音_20260418_075200.wav
```

---

### 5. 查看已克隆的声音

```bash
python3 skills/07-system/local-voice-cloning/local_voice_cloning.py list
```

**输出**:
```
📋 已克隆的声音 (1 个):

  名称：我的声音
  语言：zh-cn
  创建时间：2026-04-18T07:52:00
  样本：/home/nicola/.openclaw/workspace/voices/sample.wav
```
