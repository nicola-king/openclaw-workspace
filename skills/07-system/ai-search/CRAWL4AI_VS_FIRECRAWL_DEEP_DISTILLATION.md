Crawl4AI 是 GitHub 58k+ 星标的 Python 原生 LLM 友好爬虫，异步架构 6 倍速度提升，支持 Markdown 输出/LLM 提取/3 层反检测，完全开源免费无 API 限制。

Firecrawl 是 GitHub 70k+ 星标的 AI 数据 API 平台，支持搜索/爬取/交互/Agent 自主采集，多语言 SDK，开源 + 托管服务双模式，覆盖 96% 网页。
