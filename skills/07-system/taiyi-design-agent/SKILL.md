# 太一 Design Agent 全域自进化智能体 (v5.0)

> 互联网穿透学习 · 知识蒸馏 · 递归进化 · 全域自进化

---

## 🎯 核心功能

**融合 3 个设计 Agent**:
- ✅ visual-designer - 图表生成 + 信息卡片
- ✅ art-director - 艺术指导 + 质量把控
- ✅ taiyi-design-system - 组件库 + 设计令牌

**互联网穿透学习**:
- ✅ 知名博主：20 个 (知乎/小红书/Twitter/Dribbble)
- ✅ 专业博客：15 个 (Smashing Magazine/CSS-Tricks/设计癖)
- ✅ 设计网站：10 个 (Dribbble/Behance/Pinterest)
- ✅ 设计系统：5 个 (Apple/Material/Carbon/Ant Design)

**自进化能力**:
- ✅ 设计进化：+5%/代
- ✅ 艺术进化：+4%/代
- ✅ 组件进化：+6%/代
- ✅ 规范进化：+3%/代

## 🚀 使用方式

```bash
# 启动 Design Agent
python3 design_agent/core.py --start

# 执行学习循环
python3 design_agent/core.py --learn

# 执行进化循环
python3 design_agent/core.py --evolve --generations 100

# 显示仪表板
python3 design_agent/core.py --dashboard

# 生成图表
python3 design_agent/core.py --chart --type flowchart --data data.json

# 设计卡片
python3 design_agent/core.py --card --content content.txt
```
