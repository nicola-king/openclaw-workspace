## 📸 手机拍照测试

### 测试对象选择

**推荐对象**:
```
✅ 小型物体 (水杯/玩具/水果)
✅ 中等物体 (椅子/盆栽)
✅ 室内角落
✅ 庭院一角
```

**避免对象**:
```
❌ 反光物体 (镜子/金属)
❌ 透明物体 (玻璃)
❌ 移动物体 (人/宠物)
❌ 纯色墙面
```

---

### 拍照要求

| 要求 | 详情 | 示例 |
|------|------|------|
| **照片数量** | 20-50 张 | 第一圈 20 张 |
| **角度** | 环绕 360° | 上下左右 |
| **重叠度** | 60-80% | 每张有重叠 |
| **光线** | 均匀明亮 | 避免阴影 |
| **距离** | 0.5-2 米 | 根据物体大小 |
| **分辨率** | 1080p+ | 手机默认 |

---

### 拍照步骤

#### Step 1: 准备物体

```
1. 选择测试物体 (如水杯)
2. 放在稳定平面
3. 确保光线均匀
4. 清理背景杂物
```

#### Step 2: 第一圈 - 平视角度

```
1. 站在物体前方
2. 拍摄第 1 张
3. 向右移动一小步
4. 拍摄第 2 张 (确保 60% 重叠)
5. 继续环绕一圈 (约 20 张)
```

#### Step 3: 第二圈 - 俯视角度

```
1. 手机举高 45°
2. 同样环绕一圈 (约 15 张)
```

#### Step 4: 第三圈 - 仰视角度

```
1. 手机放低 45°
2. 环绕一圈 (约 15 张)
```

#### Step 5: 细节特写 (可选)

```
• 物体顶部
• 物体底部
• 特殊细节
```

---

### 拍照检查清单

```
□ 照片总数：20-50 张
□ 环绕完整：360°
□ 角度多样：平视/俯视/仰视
□ 重叠充足：60-80%
□ 光线均匀：无强烈阴影
□ 画面清晰：无模糊
□ 物体完整：无遮挡
```

## 🔧 常见问题解决

### 问题 1: 照片数量不足

**现象**: 重建失败或质量差  
**解决**: 增加照片数量至 20+ 张

---

### 问题 2: 重建不完整

**现象**: 物体部分缺失  
**解决**: 
```
• 增加拍摄角度
• 确保 360°环绕
• 增加俯视/仰视角度
```

---

### 问题 3: 色彩异常

**现象**: 颜色失真  
**解决**:
```
• 确保光线均匀
• 避免强光直射
• 使用自然光
```

---

### 问题 4: 处理时间过长

**现象**: 超过 1 小时  
**解决**:
```
• 减少照片数量
• 降低照片分辨率
• 升级 GPU
```
