## 📸 拍摄技巧详解

### 视频拍摄要点

**1. 起始位置**
```
• 站在物体正前方
• 手机稳定
• 点击录制
```

**2. 第一圈 (平视)**
```
• 缓慢向右移动
• 保持相同距离
• 完整环绕一圈
• 时长 30 秒
```

**3. 第二圈 (俯视)**
```
• 手机举高 45°
• 同样环绕
• 时长 15 秒
```

**4. 第三圈 (仰视)**
```
• 手机放低 45°
• 环绕
• 时长 15 秒
```

**5. 结束**
```
• 点击停止
• 检查视频完整性
```

---

### 拍照要点

**照片分布**:
```
• 第一圈 (平视): 20 张
• 第二圈 (俯视): 15 张
• 第三圈 (仰视): 15 张
• 细节特写：5-10 张
• 总计：50-60 张
```

**重叠度检查**:
```
✅ 每张照片有 60-80% 重叠
✅ 相邻照片相似度高
✅ 无遗漏角度
```
