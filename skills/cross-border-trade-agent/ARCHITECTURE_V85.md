## 📊 模块分层架构

### Layer 1: 用户交互层

| 模块 | 接口 | 协议 | 用途 |
|------|------|------|------|
| Telegram Bot | API | HTTPS | 消息推送/交互 |
| 微信 | API | HTTPS | 中国市场触达 |

| CLI | 命令行 | Local | 开发者工具 |
| API | REST | JSON | 第三方集成 |
| Dashboard | Web | WebSocket | 实时监控 |

### Layer 2: 智能路由层

| 模块 | 文件 | 功能 |
|------|------|------|

## 🔄 完整工作流程

### 获客工作流程

```
用户请求
    ↓
1. prospect_search.py (7 大数据源)
   ↓
2. data_verification.py (数据验证/SABC 分级)
   ↓
3. auto_outreach_module.py (5 渠道触达/HIR 复核)
   ↓
4. lead_nurturing_module.py (4 阶段培育)
   ↓
5. conversion_funnel_module.py (转化分析/ROI)
   ↓
6. multi_channel_outreach_module.py (渠道优化)
   ↓
成交 → 订单管理 → 物流 → 售后
```

### GEO 外贸开发流程

```
输入 HS 编码 (如 8507.60)
    ↓
1. geo_outbound_skill.md (市场分析 15 分钟)
   ↓
2. ai_search_skill.py (潜客名单 1 小时)
   ↓
3. schema_annotation_module.py (Schema 标注)
   ↓
4. content_marketing_module.py (LinkedIn/Quora 内容)
   ↓
5. ai_citation_monitor.py (Perplexity 监测)
   ↓
6. geo_acquisition_fusion.md (与获客之王融合)
   ↓
潜客转化 (转化率 2% → 8%)
```
