## 🛡️ 反爬机制详解

### 1. 浏览器指纹伪装

| 属性 | 伪装策略 | 等级 |
|------|---------|------|
| User-Agent | 轮换常见浏览器UA | L1 |
| 视口尺寸 | 随机选择常见分辨率 | L2 |
| 语言环境 | 随机选择locale | L2 |
| 时区 | 随机选择timezone | L2 |
| WebDriver | 隐藏navigator.webdriver | L3 |
| 插件列表 | 伪装plugins数量 | L3 |
| Chrome属性 | 注入window.chrome | L3 |

### 2. 人类行为模拟

| 行为 | 模拟方式 | 等级 |
|------|---------|------|
| 鼠标移动 | 贝塞尔曲线 + 随机偏移 | L2 |
| 页面滚动 | 分段滚动 + 随机延迟 | L2 |
| 点击间隔 | 随机1-3秒延迟 | L1 |
| 页面停留 | 随机2-5秒等待 | L1 |

### 3. 反检测脚本注入

```javascript
// 隐藏自动化标志
Object.defineProperty(navigator, 'webdriver', {
    get: () => undefined
});

// 伪装插件
Object.defineProperty(navigator, 'plugins', {
    get: () => [1, 2, 3, 4, 5]
});

// 伪装语言
Object.defineProperty(navigator, 'languages', {
    get: () => ['zh-CN', 'zh', 'en']
});

// 注入Chrome对象
window.chrome = { runtime: {} };
```

## 🚀 使用方式

### 基础使用

```python
from browser_search_engine import BrowserSearchEngine

# 启动浏览器 (L3反检测)
with BrowserSearchEngine(headless=True, anti_detection_level=3) as engine:
    # 执行搜索
    results = engine.search("Python programming", "google")
    
    for result in results:
        print(f"标题: {result['title']}")
        print(f"链接: {result['url']}")
```

### 智能适配器

```python
from browser_search_engine import AntiScrapingSearchAdapter

adapter = AntiScrapingSearchAdapter()

# 自动选择最佳搜索模式
results = adapter.search_with_fallback("智能水杯", "https://www.google.com")
```

### 集成到现有搜索

```python
from prospect_search import SearchEngineSource

# 启用浏览器+反爬
search_engine = SearchEngineSource(
    use_browser=True,
    anti_detection_level=3
)

# 自动使用反爬机制
results = await search_engine.search("智能水杯", "US")
```

## ⚠️ 注意事项

### 法律合规
- 遵守 robots.txt
- 控制请求频率
- 不爬取私有数据
- 尊重网站服务条款

### 技术限制
- Playwright 不支持 Ubuntu 26.04 (使用系统 Chromium)
- 浏览器模式比 requests 慢 3-5 倍
- 内存占用更高 (约 100MB/实例)

### 最佳实践
- 优先使用 requests (快速)
- 失败时回退到 browser (可靠)
- 合理设置反检测等级 (平衡)
- 定期更新 UA 池和脚本
