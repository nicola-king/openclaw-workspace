## ⛏️ 2. 矿业营地需求 ⭐ **重点市场**

### 澳大利亚矿业概况
- **铁矿**: 世界最大出口国 (西澳 Pilbara 地区)
- **煤炭**: 世界最大出口国 (昆士兰)
- **锂矿**: 世界第二大生产国
- **矿业从业**: 25 万人

### FIFO 模式 (Fly-In Fly-Out)
```
矿工工作 2-4 周 → 营地住宿 → 飞回家休息 1-2 周
↓
营地需求：住宿 + 食堂 + 办公室 + 医疗站 + 娱乐设施
```

### 主要矿业公司
| 公司 | 业务 | 员工数 |
|------|------|--------|
| **BHP** | 铁矿/煤矿/铜 | 80,000+ |
| **Rio Tinto** | 铁矿/铝/铜 | 47,000+ |
| **Fortescue** | 铁矿 | 13,000+ |
| **Newcrest** | 金矿 | 10,000+ |

### 需求估算
| 指标 | 数值 |
|------|------|
| 年需求量 | **2,000-5,000 套** |
| 单价区间 | 3-8 万澳元 |
| 市场规模 | **6-40 亿澳元/年** |

