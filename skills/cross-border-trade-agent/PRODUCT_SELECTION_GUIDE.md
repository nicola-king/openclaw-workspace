## 🎯 BOC 四大关键逻辑

### 1️⃣ 体积小

**核心**: 运费按柜计价，体积小才能摊薄成本

**评估标准**:
| 体积 (m³/件) | 评分 | 说明 |
|-------------|------|------|
| < 0.01 | ✅ 优秀 | 运费成本低 |
| 0.01-0.03 | 🟡 良好 | 运费适中 |
| 0.03-0.05 | 🟠 一般 | 运费较高 |
| > 0.05 | ❌ 差 | 运费刺客，避免 |

**避免**: 发泡制品、大件家具、大型装饰品

**推荐**: 3C 配件、小家电、办公用品、个人护理

---

### 2️⃣ 利润足

**核心**: 国外售价需超出厂价 1 倍 +

**评估标准**:
| 售价/出厂价 | 评分 | 说明 |
|------------|------|------|
| ≥ 2.5 倍 | ✅ 优秀 | 利润充足 |
| 2.0-2.5 倍 | 🟡 良好 | 利润达标 |
| 1.5-2.0 倍 | 🟠 一般 | 利润偏低 |
| < 1.5 倍 | ❌ 差 | 不建议 |

**市场验证**:
- ✅ 月销 500+ 且评价 500+ = 值得做
- 🟡 月销 100+ 且评价 100+ = 可以考虑
- ❌ 月销<100 = 需进一步调研

---

### 3️⃣ 复购强

**核心**: 优先耗材/配件等持续消耗品

**高复购品类**:
| 品类 | 月复购率 | 说明 |
|------|---------|------|
| 打印耗材 | 25-30% | 墨盒/硒鼓/墨水 |
| 滤芯 | 20-25% | 净水器/空气净化器 |
| 配件 | 15-20% | 手机壳/数据线 |
| 耗材 | 20-30% | 办公/清洁用品 |
| 个人护理耗材 | 15-25% | 牙刷头/剃须刀 |

**评估标准**:
| 月复购率 | 评分 | 说明 |
|---------|------|------|
| > 30% | ✅ 优秀 | 持续消耗 |
| 20-30% | 🟡 良好 | 稳定消耗 |
| 10-20% | 🟠 一般 | 复购一般 |
| < 10% | ❌ 差 | 一次性购买 |

---

### 4️⃣ 零售后

**核心**: 避免易碎/食品/需维修产品

**高风险品类**:
| 品类 | 风险 | 说明 |
|------|------|------|
| 玻璃制品 | 🔴 高 | 易碎，运输破损 |
| 食品 | 🔴 高 | 保质期/海关风险 |
| 电子产品 | 🟡 中 | 需维修/技术支持 |
| 服装鞋帽 | 🟡 中 | 尺码/退换货 |
| 机械设备 | 🔴 高 | 安装/维修复杂 |

**评估标准**:
| 售后风险 | 评分 | 说明 |
|---------|------|------|
| 无风险因素 | ✅ 优秀 | 适合外贸 |
| 1 个低风险 | 🟡 良好 | 风险可控 |
| 2 个风险 | 🟠 一般 | 需谨慎 |
| 3+ 风险 | ❌ 差 | 不建议 |

### 评估流程

1. **收集产品数据**
   - 体积 (m³)
   - 重量 (kg)
   - 出厂价 (元)
   - 海外售价 (元)
   - 月销量
   - 评价数
   - 产品类型
   - 是否耗材/配件
   - 风险因素

2. **运行评估工具**
   ```python
   from product_selector import ProductEvaluator
   
   evaluator = ProductEvaluator()
   
   result = evaluator.evaluate_product(
       product_name="产品名称",
       volume_m3=0.005,
       factory_price=20,
       overseas_price=60,
       monthly_sales=800,
       reviews=600,
       is_consumable=True,
       is_fragile=False
   )
   
   print(evaluator.generate_report(result))
   ```

3. **解读结果**
   - 总分 ≥ 85: 立即行动
   - 总分 75-84: 可以推进
   - 总分 60-74: 优化后再做
   - 总分 < 60: 放弃

## 🎯 选品 Checklist

### 必查项 (P0)

- [ ] 体积 < 0.01 m³/件
- [ ] 售价/出厂价 ≥ 2 倍
- [ ] 月销量 > 500 单
- [ ] 评价数 > 500
- [ ] 非易碎品
- [ ] 非食品
- [ ] 无需维修

### 加分项 (P1)

- [ ] 耗材/配件类
- [ ] 月复购率 > 20%
- [ ] 重量轻 (< 1kg)
- [ ] 次品率 < 2%
- [ ] 市场竞争适中

### 减分项 (P2)

- [ ] 电子产品 (售后风险)
- [ ] 服装鞋帽 (尺码问题)
- [ ] 需要认证 (CE/FCC 等)
- [ ] 季节性产品
- [ ] 专利风险
