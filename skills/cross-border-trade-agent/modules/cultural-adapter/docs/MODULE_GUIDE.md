# cultural-adapter 模块指南

## 简介
跨境贸易 Agent v10.0 的 cultural-adapter 模块。

## 快速开始

```bash
# 独立运行
python3 core.py

# 执行任务
python3 core.py --task <任务名>
```

## 配置

编辑 `config.json` 设置模块参数。

## 测试

```bash
pytest tests/test_core.py
```

## 依赖
- Python 3.8+
- cross-border-core
