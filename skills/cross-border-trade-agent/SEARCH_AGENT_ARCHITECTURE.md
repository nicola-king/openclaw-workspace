## 🔍 搜索 Agent 核心模块

### 1. 搜索引擎整合模块 (`search_engines_integrator.py`)

**功能**: 整合全球 Top 10 搜索引擎数据

| 搜索引擎 | 市场份额 | 日搜索量 | 区域 |
|---------|---------|---------|------|
| Google | 91.5% | 850亿次 | 全球 |
| Bing | 3.5% | 30亿次 | 全球 |
| Yahoo | 1.5% | 12亿次 | 全球 |
| Yandex | 1.2% | 10亿次 | 俄罗斯 |
| Baidu | 0.8% | 60亿次 | 中国 |
| DuckDuckGo | 0.6% | 5亿次 | 全球 |
| Naver | 0.5% | 4亿次 | 韩国 |
| Seznam | 0.3% | 2亿次 | 捷克 |
| Ecosia | 0.2% | 1.5亿次 | 全球 |
| Qwant | 0.1% | 1亿次 | 欧洲 |

**核心能力**:
- 搜索量分析
- 关键词趋势
- 竞争程度评估
- 用户意图分析
- 商业价值评估

---

### 2. 关键词研究模块 (`keyword_research.py`)

**功能**: Semrush/Ahrefs/Mangools 核心能力

| 能力 | 功能 | 来源 |
|------|------|------|
| 关键词发现 | 短语发现/相关词 | Semrush |
| 难度评估 | 准确率评分 | Mangools |
| 搜索量分析 | 月度/年度趋势 | Ahrefs |
| 竞争分析 | 竞争程度/机会 | 综合 |
| 长尾挖掘 | 低难度高价值词 | 综合 |

**输出**:
- 相关关键词列表 (5-10个)
- 长尾关键词列表 (5-10个)
- 关键词难度评分 (0-100)
- 机会关键词识别 (P0/P1)

---

### 3. 全网穿透搜寻模块 (`prospect_search.py`)

**功能**: 7 大数据源整合搜寻

| 数据源 | 覆盖范围 | 搜寻能力 |
|--------|---------|---------|
| 搜索引擎 | Google/Bing/Baidu | 全网信息 |
| 社交媒体 | LinkedIn/微博/抖音 | 人脉/内容 |
| 企业数据库 | 天眼查/企查查 | 企业信息 |
| 电商平台 | 亚马逊/eBay/1688 | 产品/卖家 |
| 贸易数据 | 海关数据 | 进出口记录 |
| 行业目录 | 协会/展会 | 行业资源 |
| 厂家数据 | 供应商数据库 | 生产能力 |

**搜寻流程**:
```
输入关键词 → 多源并行搜寻 → 数据验证 → 智能分级 → 输出结果
```

```
用户请求
    ↓
[任务识别] → 搜索类型判断
    ↓
[模型调度] → Qwen/Gemini/本地模型
    ↓
[搜索执行]
    ├── 搜索引擎 → 关键词/趋势/竞争
    ├── 全网搜寻 → 潜客/企业/产品
    └── GEO搜索 → HS编码/AI引用
    ↓
[数据验证] → 冰山理论蒸馏
    ↓
[智能分级] → S/A/B/C 分级
    ↓
[输出报告] → Markdown/JSON/CSV
```
