# 跨境贸易 · Bot 职责分配 & 调度路由

> 太一自动调度 · SAYELF 只需说出贸易需求
> 每个 Bot 负责跨境贸易全链路中的专业模块

---

## 一、架构总览

```
SAYELF: "帮我查XX产品在欧洲的市场机会"
       │
       ▼
┌──────────────────────────────────────┐
│       太一（跨境贸易·统筹/决策）        │
│  → 意图解析（情报/报价/履约/合规/寻源）  │
│  → 任务拆解 → 分派对应 Bot              │
│  → 结果聚合 → 最终交付                  │
└──────────────────────────────────────┘
       │
       ├── 知几 ── 情报分析·数据挖掘·市场研究
       ├── 山木 ── 业务执行·触达推进·履约交付

       ├── 罔两 ── 竞品监控·真实验证·市场情报
       └── 庖丁 ── 报价成本·支付结算·风险控制
```

## 四、调度流程（每次请求）

```
第1步：太一接收 → 意图解析
        ├── 情报类（市场/趋势/数据）？
        ├── 寻源类（找买家/找供应商）？
        ├── 报价类（报价/成本/利润）？
        ├── 履约类（合同/物流/支付）？
        ├── 合规类（关税/认证/法律）？
        ├── 监控类（竞品/动态/验证）？
        └── 全链路（上述混合）？

第2步：任务拆解 → Bot分派
        ├── 单域 → 直接派一个Bot（如"查HS编码"→素问）
        └── 跨域 → 拆子任务 → 并行派多个Bot
             例："做钢结构的中东市场分析"
             → 知几(市场数据)+罔两(竞品情报)+素问(合规政策)

第3步：结果聚合 → 太一整合
        ├── 合并各个Bot产出
        ├── 冲突时走辩论投票（置信度加权）
        └── 太一最终裁决

第4步：交付 → 格式化输出给SAYELF
        ├── 清晰可执行的商业情报/方案
        └── 所有数据附带 verification_links
```

### Squad 编队协议

复杂任务自动组建 Squad 代替串行/并行派 Bot：

```
第1步：太一接收 → 意图解析
第2步：识别是否需 Squad 编队
       ├── 简单任务（查HS/报价/验证）→ 单Bot，不组建
       └── 复杂任务（冷启动/竞品深挖/全链路）→ 组建 Squad
第3步：SquadOrchestrator.assemble() → 创建 WarRoom
       ├── 指定 Team Leader（知几/罔两/庖丁 按意图定）
       ├── 组建成员 Squad（从 Bot 池动态选人）
       └── 拉起共享上下文白板
第4步：Squad 并行执行
       ├── Leader 拆解任务写入白板
       ├── 成员并行执行各子任务
       ├── 成员通过白板共享上下文
       └── 需决策项 Leader 裁决
第5步：结果聚合 → 太一确认 → 交付 SAYELF
```
