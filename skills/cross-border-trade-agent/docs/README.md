### HIR (High-Intent Review)

```
🔐 高意向客户人工复核

S 级 (90+ 分) - 极高意向 - 必须 HIR 复核 ✅
A 级 (75-89 分) - 高意向 - 必须 HIR 复核 ✅
B 级 (50-74 分) - 中意向 - 可选 HIR 复核
C 级 (0-49 分) - 低意向 - 自动触达
```

---

### 7 阶段转化漏斗

```
1. 线索获取 → 2. 线索清洗 → 3. 首次触达
   → 4. 互动培育 → 5. 商机确认 → 6. 报价谈判
```
