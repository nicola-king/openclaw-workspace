## 📊 综合置信度计算

### 权重分配

| 数据源 | 权重 | 说明 |
|--------|------|------|
| 全球海关数据 | 20% | 官方权威数据 |
| 电商销售数据 | 20% | 直接销售记录 |
| 互联网平台 | 15% | 品牌影响力 |
| 搜索引擎 | 15% | 网络存在度 |
| 第三方报告 | 10% | 行业认可度 |
| 海陆空运输 | 10% | 实际贸易记录 |
| Google Ads | 10% | 市场活跃度 |

### 计算公式

```
综合置信度 = Σ(各数据源置信度 × 权重)

示例:
海关 (85% × 0.20) + 电商 (80% × 0.20) + 平台 (75% × 0.15) 
+ 搜索 (90% × 0.15) + 报告 (60% × 0.10) + 物流 (55% × 0.10) 
+ Ads (70% × 0.10) = 76.2%
```

### 置信度等级

| 综合置信度 | 等级 | 行动建议 |
|-----------|------|---------|
| 90-100% | ✅ 已验证 | 可直接使用 |
| 80-89% | ✅ 高度可信 | 建议使用 |
| 70-79% | ⚠️ 部分验证 | 谨慎使用 |
| 60-69% | ⚠️ 低置信度 | 需补充验证 |
