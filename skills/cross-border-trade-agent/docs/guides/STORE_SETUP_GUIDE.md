### 9.2 库存管理

**安全库存公式**:
```
安全库存 = 日均销量 × 备货周期 × 安全系数

示例:
日均销量：10 件
备货周期：30 天
安全系数：1.5
安全库存 = 10 × 30 × 1.5 = 450 件
```

**补货提醒**:
```
当库存 < 安全库存 × 0.5 时，触发补货
即：450 × 0.5 = 225 件时补货
```

---

### 9.3 财务核算

**成本结构**:
```
产品成本：30-40%
物流成本：10-15%
平台佣金：2-15%
支付手续费：3-4%
广告费用：20-30%
其他：5%
净利润：15-25%
```

**定价公式**:
```
售价 = 产品成本 ÷ (1 - 目标利润率)

示例:
产品成本：$10
目标利润率：40%
售价 = 10 ÷ (1 - 0.4) = $16.67
实际售价：$29.99 (考虑市场竞争)
```
