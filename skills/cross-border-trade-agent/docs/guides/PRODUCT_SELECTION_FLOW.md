## 📊 选品流程对比

### 优化前

```
1. 读取监控产品列表
   ↓
2. 显示产品数据
   ↓
3. 简单增长率判断 (>20% / 10-20% / <-5%)
   ↓
4. 生成建议
```

**问题**:
- ❌ 缺少全网搜寻
- ❌ 缺少多维度分析
- ❌ 仅依赖增长率
- ❌ 建议不够精准

---

### 优化后融合

```
1. 全网全域搜寻
   ↓ (prospect_search.py)
   收集候选产品 (50+ 产品)

2. 5 大维度数据分析
   ↓
   • 趋势数据 (时间序列分析)
   • 搜索关键词 (全网搜索量)
   • 竞品数据 (价格/策略对比)
   • 社交媒体 (热度分析)
   • 电商平台 (销量/评价)
   ↓

3. 综合评分 (100 分制)
   ↓
   • 增长率 (30 分)
   • 搜索量 (25 分)
   • 竞争度 (20 分)
   • 利润率 (15 分)
   • 社交声量 (10 分)
   ↓

4. 产品分级
   ↓
   • S 级 (>90 分) - 爆品
   • A 级 (80-90 分) - 优品
   • B 级 (70-80 分) - 合格
   • C 级 (<70 分) - 淘汰

5. 选品建议生成
   ↓ (根据分级)
   • S 级：立即进入，重点推广
   • A 级：建议进入，优化 listing
   • B 级：观察中，择机进入
   • C 级：清仓处理，寻找替代品

6. 新品推荐 (推陈出新)
   ↓
   每周更新选品建议
   每月淘汰 10% 滞销
   每月引入 15% 新品

7. 持续监控
   ↓ (每 4 小时)
   趋势跟踪/动态调整
```

---

## 📋 详细流程说明

### 步骤 1: 全网全域搜寻

**工具**: `prospect_search.py`

**搜寻维度**:
```
✅ 搜索引擎 (Google/Bing/Baidu)
✅ 社交媒体 (LinkedIn/微博/抖音)
✅ 企业数据库 (天眼查/企查查)
✅ 电商平台 (亚马逊/eBay/1688)
✅ 贸易数据 (海关数据)
✅ 行业目录 (协会/展会)
```

**输出**: 50+ 候选产品列表

---

### 步骤 2: 5 大维度数据分析

#### 2.1 趋势数据 (30 分)

**数据源**: `product_trend_forecaster.py`

**分析内容**:
```
• 时间序列分析 (12 个月历史数据)
• 增长率计算 (近 3 月 vs 前 3 月)
• 趋势阶段判断 (上升/成熟/衰退)
• 生命周期预测
```

**评分标准**:
| 增长率 | 得分 |
|--------|------|
| >20% | 30 分 |
| 10-20% | 25 分 |
| 5-10% | 20 分 |
| 0-5% | 15 分 |
| <-5% | 5 分 |

---

#### 2.2 搜索关键词 (25 分)

**数据源**: `web_search` / Google Trends

**分析内容**:
```
• 月搜索量
• 搜索趋势 (上升/下降)
• 相关关键词数量
• 竞争程度
```

**评分标准**:
| 月搜索量 | 得分 |
|---------|------|
| >100,000 | 25 分 |
| 50,000-100,000 | 20 分 |
| 10,000-50,000 | 15 分 |
| 1,000-10,000 | 10 分 |
| <1,000 | 5 分 |

---

#### 2.3 竞品数据 (20 分)

**数据源**: `monitor_products.json` / 竞品监控

**分析内容**:
```
• 竞品数量
• 竞品价格对比
• 竞品动态 (新品/促销)
• 市场份额
```

**评分标准**:
| 竞争度 | 得分 |
|--------|------|
| 低 (竞品<5) | 20 分 |
| 中低 (竞品 5-10) | 15 分 |
| 中 (竞品 10-20) | 10 分 |
| 高 (竞品>20) | 5 分 |

---

#### 2.4 利润率 (15 分)

**数据源**: 成本核算 / 价格对比

**分析内容**:
```
• 目标毛利率
• 实际毛利率
• 价格优势
• 成本控制
```

**评分标准**:
| 毛利率 | 得分 |
|--------|------|
| >40% | 15 分 |
| 30-40% | 12 分 |
| 20-30% | 10 分 |
| 10-20% | 5 分 |
| <10% | 0 分 |

---

#### 2.5 社交声量 (10 分)

**数据源**: 社交媒体 API

**分析内容**:
```
• 话题热度
• 用户口碑
• KOL 推荐
• 社交分享量
```

**评分标准**:
| 声量 | 得分 |
|------|------|
| 爆火 | 10 分 |
| 热门 | 8 分 |
| 一般 | 5 分 |
| 冷门 | 2 分 |

---

### 步骤 3: 综合评分

**计算公式**:
```
总分 = 趋势 (30) + 搜索 (25) + 竞品 (20) + 利润 (15) + 社交 (10)
```

**产品分级**:
| 等级 | 分数 | 比例 | 行动 |
|------|------|------|------|
| **S 级** | >90 分 | 10% | 立即进入，重点推广 |
| **A 级** | 80-90 分 | 20% | 建议进入，优化 listing |
| **B 级** | 70-80 分 | 40% | 观察中，择机进入 |
| **C 级** | <70 分 | 30% | 清仓处理，寻找替代品 |

---

### 步骤 4: 选品建议生成

#### S 级产品 (爆品)

```
✅ 立即进入
✅ 重点推广
✅ 加大备货
✅ 增加广告预算
✅ 优化 listing 到最佳
```

**示例**:
```
✅ 智能水杯 (S 级 95 分)
   理由：增长率 25% + 搜索量 10 万 + 竞争度低
   行动：立即补货 1000 件，广告预算$5000/月
```

---

#### A 级产品 (优品)

```
🟡 建议进入
🟡 优化 listing
🟡 维持库存
🟡 适度广告
```

**示例**:
```
🟡 瑜伽垫 (A 级 85 分)
   理由：增长率 15% + 搜索量 5 万 + 利润率高
   行动：维持库存 500 件，优化关键词
```

---

#### B 级产品 (合格)

```
⚠️ 观察中
⚠️ 择机进入
⚠️ 少量备货
```

**示例**:
```
⚠️ LED 台灯 (B 级 75 分)
   理由：增长率 5% + 竞争激烈
   行动：观察中，寻找差异化卖点
```

---

#### C 级产品 (淘汰)

```
❌ 清仓处理
❌ 寻找替代品
❌ 减少广告
❌ 准备退出
```

**示例**:
```
❌ 旧款产品 (C 级 60 分)
   理由：增长率 -10% + 利润下降
   行动：清仓处理，寻找替代品
```

---

### 步骤 5: 新品推荐 (推陈出新)

**更新频率**: 每周更新

**推荐逻辑**:
```
1. 监控全网趋势
2. 发现新兴产品
3. 评估市场潜力
4. 生成推荐列表
```

**示例**:
```
📦 新品推荐 (推陈出新)

• 智能家居：智能插座/智能灯泡 (趋势 +50%)
• 健康产品：按摩器/健康监测 (趋势 +35%)
• 季节性产品：夏季防晒/冬季保暖 (季节性)

• 数据来源：全网趋势分析 + 竞品监控
• 更新频率：每周更新选品建议
```

---

### 步骤 6: 持续监控

**监控频率**: 每 4 小时

**监控内容**:
```
• 趋势变化
• 搜索量波动
• 竞品动态
• 价格变化
• 社交声量
```

**动态调整**:
```
• 增长率>20% → 升级为 S 级
• 增长率<-5% → 降级为 C 级
• 竞品降价 → 调整策略
• 社交爆火 → 加大推广
```
