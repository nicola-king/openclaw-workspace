## 🔄 贸易流程分析

### 标准出口流程

```
┌─────────────────────────────────────────────────────────┐
│  1. 客户开发 → 2. 报价 → 3. 签约 → 4. 收款 (70%)      │
│         ↓                                               │
│  5. 生产 (60 天) → 6. 质检 → 7. 包装 → 8. 订舱         │
│         ↓                                               │
│  9. 报关 → 10. 装运 → 11. 收款 (20%) → 12. 清关       │
│         ↓                                               │
│  13. 运输 → 14. 交付 → 15. 安装 → 16. 收款 (10%)      │
│         ↓                                               │
│  17. 质保 → 18. 售后 → 19. 复购/推荐                   │
└─────────────────────────────────────────────────────────┘
```

### 关键节点控制

| 节点 | 风险 | 控制措施 |
|------|------|---------|
| **签约** | 合同条款风险 | 使用标准合同模板，明确付款/质保/争议解决 |
| **收款 (70%)** | 付款延迟 | 合同约定违约金，到账后生产 |
| **生产** | 质量/延期 | ISO 9001 管控，60 天周期留缓冲 |
| **质检** | 不合格 | 第三方检验 (SGS/BV)，客户可参与 |
| **报关** | 单证问题 | 提前准备完整单证，预留 3-5 天 |
| **清关** | 认证/关税 | 提前获取 AS/NZS 认证，计算落地成本 |
| **收款 (尾款)** | 拖欠风险 | 控制货权，购买出口信用保险 |

## 🛃 关务与合规

### 中国出口报关

**所需单证**:
- ✅ 商业发票 (Commercial Invoice) × 3
- ✅ 装箱单 (Packing List) × 3
- ✅ 销售合同 (Sales Contract) × 1
- ✅ 报关单 (Customs Declaration) × 1
- ✅ 原产地证 (Certificate of Origin) × 1
- ✅ 质量合格证 (Quality Certificate) × 1
- ✅ 提单 (Bill of Lading) × 1

**出口退税**:
- 退税率：13% (钢结构产品)
- 退税周期：1-3 个月
- 预计收益：合同金额 × 13%

### 澳大利亚进口清关

**所需单证**:
- ✅ 商业发票
- ✅ 装箱单
- ✅ 提单
- ✅ 原产地证
- ✅ AS/NZS 认证证书
- ✅ 进口许可证 (如适用)

**进口税费**:
| 税费类型 | 税率 | 计算基数 |
|---------|------|---------|
| 进口关税 | 5% | FOB 价格 + 海运费 |
| GST | 10% | FOB 价格 + 海运费 + 关税 |
| 清关费 | 200-500 澳元 | 固定 |
| 港口费 | 300-800 澳元 | 固定 |

**落地成本计算**:
```
FOB 中国价格：100%
+ 海运费用：10-15%
+ 进口关税：5%
+ GST: 10%
+ 清关/港口费：约 2%
+ 认证费用：2-5 万澳元 (一次性)
= 澳洲落地成本：约 130-140%
```

### 认证要求

| 认证 | 说明 | 难度 | 周期 | 费用 |

- 装载量：可折叠设计 4-8 套/柜
- 海运费：中国→澳洲 $3,000-6,000/柜

**装载优化**:
```
方案 A (经济型): 8 套/柜
- 折叠包装，最大化利用空间

- 部分预组装，减少现场安装

方案 C (豪华型): 4 套/柜
- 大部分预组装，快速部署

## 🎯 结论

### 市场机会：⭐⭐⭐⭐⭐ **强烈推荐进入**

### 核心理由

1. ✅ **市场规模大**: 100-500 亿元/年 (20-99 亿澳元)
2. ✅ **矿业需求稳定**: 资源出口导向经济，FIFO 模式刚需

4. ✅ **订单验证**: Crystalbrook 8 套 ($695,000) 已签约
5. ✅ **差异化竞争**: 可折叠设计 + 快速交付 + 本地服务

```
1. 快速完成认证 (6-12 个月) - 市场准入
2. 本地合作伙伴 (安装/售后) - 解决后顾之忧
3. 聚焦矿业营地 (价格敏感、量大) - 现金流保障
4. GEO 优化 (AI 可见度) - 长期贵客管道
