### 2. 线索评分模型

**评分维度**:
```
📊 公司信息完整性 (20 分)
   • 公司名称 (5 分)
   • 国家 (5 分)
   • 网站 (5 分)
   • 联系人 (5 分)

🎯 需求匹配度 (30 分)
   • 产品类别 (15 分)
   • 数量范围 (10 分)
   • 目标价格 (5 分)

💰 预算/时间意向 (30 分)
   • 预算范围 (15 分)
   • 采购时间 (15 分)

💬 互动历史 (20 分)
   • 邮件打开 (5 分)
   • 曾回复 (10 分)
   • 索要报价 (5 分)
```

**分级标准**:
```
A 级：80-100 分 - 高意向，立即跟进 ⭐⭐⭐⭐⭐
B 级：60-79 分  - 中意向，定期跟进 ⭐⭐⭐⭐
C 级：40-59 分  - 低意向，培育中 ⭐⭐⭐
D 级：<40 分    - 无效线索 ⭐
```

### 整合到主 Agent

```python
# 在 cross_border_agent.py 中
from lead_generation import LeadGenerationModule

class CrossBorderAgent:
    def __init__(self):
        # 新增：贵客模块
        self.lead_gen = LeadGenerationModule()
        
    async def marketing_loop(self):
        """营销贵客循环"""
        while True:
            # 搜寻客户
            leads = self.lead_gen.generate_leads(
                keywords=self.config['target_products'],
                target_countries=self.config['target_countries']
            )
            
            # 触达 A 级线索
            for lead in [l for l in leads if l['grade'] == 'A']:
                self.lead_gen.auto_outreach(lead, "email")
            
            # 跟进已有线索
            await self.followup_existing_leads()
            
            # 等待下次循环
            await asyncio.sleep(3600)  # 每小时
```
