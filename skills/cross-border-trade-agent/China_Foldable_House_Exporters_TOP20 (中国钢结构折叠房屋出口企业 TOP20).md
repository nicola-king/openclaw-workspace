## 📋 典型出口合同条款 (行业惯例)

| 条款 | 常见做法 |
|------|---------|
| **付款方式** | T/T 30% 定金 + 70% 见提单副本 (80% 订单) |
| **大额订单** | L/C 即期信用证 ($50 万 + 订单) |
| **澳洲客户** | 30% 定金 + 40% 发货前 + 30% 到港后 |
| **交货期** | 样品 7-15 天 / 批量 30-60 天 |
| **价格条款** | FOB 中国港口 (60%) / CIF 目的港 (35%) / EXW (5%) |
| **40HQ 装载** | 可折叠设计：1 集装箱 = 4-8 套 |
| **质量标准** | ISO 9001 + CE (欧洲) + AS/NZS (澳洲) |
| **钢材规格** | Q550/Q355 镀锌钢，锌层≥80μm |
| **质保期** | 结构 5 年 / 防水 2 年 / 电气 1 年 |
| **备件赠送** | 1-5% 免费备件 |
