### 四层架构
Layer 1 File Cache — 文件内容缓存（mtime 感知，变更自动失效）
Layer 2 Context Cache — 上下文缓存（TTL 1小时）
Layer 3 Result Cache — 结果缓存（LRU 200 + 摘要提取）
Layer 4 Memory Cache — 持久化记忆（LRU 200 + 7天过期 + 磁盘持久化）

### 宪法铁律（新增5条）
11. 读文件强制走缓存
12. 命中率硬指标 > 90%
13. 命中时禁止传全文给 LLM（只传摘要）
14. LRU 200 条上限
15. 7 天过期自动清理

### 与 LLM 缓存优化层的关系
- cache-optimizer/ → LLM prompt 前缀缓存（外层）
- cache-engine/ → 文件/数据/结果缓存（内层）
- 两者互补，共同确保系统缓存命中率 > 90%
