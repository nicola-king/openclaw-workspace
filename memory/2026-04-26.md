## Session 7: 搜索 Agent 全面重构 🎯






**时间**: 16:00 - 22:22
**决策人**: SAYELF

### 关键决策





1. **搜索 Agent 独立部署** - 不融合到智能路由 Agent，作为独立服务
2. **双通道架构** - 国内流量直连 / 海外流量走 Clash 代理
3. **GitHub 高星项目调研** - 筛选 3000+ 星的开源爬虫/浏览器项目
4. **模块化 + 自进化** - 支持动态加载搜索引擎和内容提取策略

### 搜索引擎路由策略





| 场景 | 搜索引擎 | 路由 |
|------|---------|------|
| 海外搜索 | Bing → Google → DuckDuckGo | Clash 代理 (127.0.0.1:7890) |
| 国内搜索 | 百度 → 搜狗 → 必应中国 | 直连 |
| 学术搜索 | arXiv → Google Scholar | 代理 |
| 社交媒体 | Twitter → Reddit → 微博 | 按来源路由 |

### 技术架构





```
搜索 Agent (独立服务)
├── 智能路由层 (国内/海外自动判断)
├── 搜索引擎层 (Bing/Google/百度/DuckDuckGo)
├── 爬虫层 (Playwright Chromium + curl)
├── 内容提取层 (Trafilatura + 回退策略)
└── API 接口 (供其他 Agent 调用)
```

### 完成事项





- ✅ search-agent.py v1-vN 多次迭代
- ✅ DuckDuckGo 代理搜索验证通过
- ✅ Trafilatura 内容提取验证通过
- ✅ curl 代理测试通过 (Bing 302, DDG 202, Google 200)
- ✅ 域名过滤机制 (BLOCKED_DOMAINS)
- ✅ CLI 接口 (query/max-results/output/format)
- ⚠️ 待：GitHub 高星项目筛选和融合
- ⚠️ 待：国内搜索引擎集成 (百度/搜狗)
- ⚠️ 待：智能路由层实现

### 踩坑记录





1. **Bing 重定向到 cn.bing.com** - 返回法国论坛无关结果，根因是未走代理
2. **DuckDuckGo 直连不可达** - 必须通过 Clash 代理
3. **Playwright 未配置代理** - curl 可通但 Playwright 超时
4. **web_fetch 大量 403/Cloudflare** - 需要浏览器级渲染
5. **agent-reach 模块缺失** - `ModuleNotFoundError: No module named 'agent_reach.cli'`

### 待办 (P0)
