## ⚠️ 核心禁令 (绝对禁止)

### 1. 市场操纵行为 ❌

```
禁止行为:
• 洗盘交易 (Wash Trading) - 自买自卖制造虚假交易量
• 幌骗交易 (Spoofing) - 虚假挂单后撤销
• 哄抬价格 (Pump and Dump) - 操纵价格后抛售
• 内幕交易 - 利用未公开信息交易

违规后果:
• 账户冻结
• 资金冻结
• 法律追责
```

### 2. API 滥用行为 ❌

```
禁止行为:
• 超过 API 速率限制 (每秒 1200 次权重)
• 高频交易干扰系统 (订单/秒 > 10)
• 恶意请求导致系统负载
• 未授权访问他人账户

API 限制:
• 现货交易：1200 权重/秒
• 下单：10 次/秒 (单个交易对)
• 撤单：10 次/秒 (单个交易对)
• 查询余额：10 次/秒
```

### 3. 洗钱行为 ❌

```
禁止行为:
• 多账户对倒转移资金
• 拆分交易规避 KYC
• 与制裁地址交易
• 可疑资金来源

合规要求:
• 完成 KYC 认证
• 资金来源合法
• 配合反洗钱调查
```

## ✅ 合规交易准则

### 1. 正常交易行为 ✅

```
允许行为:
• 基于市场价格的正常买卖
• 合理的挂单和撤单
• 网格交易 (正常频率)
• 套利交易 (合法渠道)
• 做市行为 (真实流动性)

建议频率:
• 网格交易：每 5-15 分钟一次
• 撤单率：< 50% (避免幌骗嫌疑)
• 持仓时间：> 1 分钟 (避免高频交易)
```

### 2. API 合理使用 ✅

```
最佳实践:
• 请求间隔：≥ 100ms
• 订单间隔：≥ 1 秒
• 错误处理：指数退避
• 日志记录：所有交易行为

监控指标:
• API 调用频率
• 订单成交率
• 撤单率
• 账户异常行为
```

### 3. 资金管理合规 ✅

```
合规要求:
• 单笔交易 ≥ $5 (最小名义价值)
• 账户余额充足 (避免爆仓)
• 杠杆使用合规 (≤ 账户权限)
• 不参与非法项目

风控措施:
• 止损设置
• 仓位限制
• 日交易限额
• 异常行为监控
```

### 2. 合规检查函数

```python
def compliance_check(order):
    """合规检查"""
    # 1. 检查最小名义价值
    if order['quantity'] * order['price'] < 5:
        return False, "最小名义价值$5"
    
    # 2. 检查持仓时间
    if current_time - last_order_time < 60:
        return False, "最小持仓时间 60 秒"
    
    # 3. 检查撤单率
    if cancel_ratio > 0.50:
        return False, "撤单率超过 50%"
    
    # 4. 检查 API 频率
    if requests_per_second > 10:
        return False, "API 请求超限"
    
    return True, "合规"
```

## ⚠️ 风险预警信号

### 可能触发风控的行为

| 行为 | 阈值 | 后果 |
|------|------|------|
| **撤单率过高** | > 80% | 警告 → 限制交易 |
| **订单频率过高** | > 100 单/分钟 | 限制 API |
| **自买自卖** | 同账户对倒 | 账户冻结 |
| **异常盈利** | 日收益 > 100% | 调查 |
| **IP 频繁变更** | > 10 次/小时 | 安全验证 |
| **多账户关联** | 同一设备/IP | 关联封禁 |

### 安全交易建议

```
✅ 建议做法:
• 保持稳定的交易频率
• 撤单率控制在 50% 以内
• 使用固定 IP 地址
• 完成 KYC 认证
• 开启 2FA 安全验证
• 定期更换 API 密钥

❌ 避免做法:
• 频繁大额撤单
• 秒级高频交易
• 多账户操作
• 异常时间交易 (凌晨大量交易)
• 新账户立即大额交易
```

## 📞 违规处理流程

### 如果收到警告

```
1. 立即停止自动交易
2. 检查交易记录
3. 分析违规原因
4. 调整交易参数
5. 联系币安客服申诉
6. 等待处理结果
```

### 如果账户受限

```
1. 不要创建新账户 (关联封禁)
2. 联系币安客服了解原因
3. 提供所需证明材料
4. 配合调查
5. 等待解封或申诉
```
