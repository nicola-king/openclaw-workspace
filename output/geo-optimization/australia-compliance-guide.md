# 澳洲市场合规指南 — 储能电池进口与销售

> 初稿 · 2026-05-19
> 适用产品：储能锂电池（HS 8507.60）
> 目标市场：澳大利亚

---

## 一、澳洲储能市场概况

澳大利亚是全球户用储能渗透率最高的市场之一：
- 户用光伏+储能配套率 > 30%
- 2026年工商业储能需求加速
- 联邦政府 + 州政府双重补贴机制（STCs + 州级电池补贴）

## 二、核心合规框架

### 2.1 产品安全标准

| 标准 | 适用范围 | 强制/推荐 |
|------|---------|:--------:|
| AS/NZS 5139:2019 | 电池储能系统安装 | ⚠️ 强制 |
| IEC 62619 / AS 62619 | 工业储能电池安全 | ⚠️ 必要 |
| UN 38.3 | 锂电池运输安全 | ⚠️ 强制 |
| IEC 62040 (UPS类) | 不间断电源 | 📌 相关 |

### 2.2 认证要求

#### RCM 标志 (Regulatory Compliance Mark)
- **适用**：所有在澳洲销售的电气产品
- **要求**：供应商声明 + 合规文件
- **流程**：
  1. 产品测试至相关标准
  2. 准备技术文件（DoC）
  3. 在ERAC数据库注册
  4. 在产品/包装上打RCM标志

#### CEC 列名 (Clean Energy Council)
- **适用**：需要安装补贴的储能系统
- **要求**：CEC批准产品列表注册
- **如果列名被拒**：仍可销售，但用户无法获得政府补贴

### 2.3 新兴安全框架：TS 5398

2025-2026年，澳大利亚正在推进：
- **TS 5398**：新的电池安全技术标准
- 取代旧的BPG (Battery Best Practice Guide)
- 涵盖：热失控防护、BMS要求、安装间距、灭火系统

## 三、进口流程

### 3.1 通关文件清单

| 文件 | 说明 |
|------|------|
| 商业发票 | 含HS编码、数量、单价 |
| 装箱单 | 每箱电池数量、重量 |
| 提单/空运单 | 运输文件 |
| UN 38.3测试报告 | 锂电池运输安全 |
| MSDS | 材料安全数据表 |
| 原产地证 | 中澳FTA优惠关税 |
| 进口商声明 | 说明产品用途和安全信息 |

### 3.2 关税与税率

- HS 8507.60：锂电池
- 中澳FTA税率：0%（需中国原产地证）
- GST：10%（进口时缴纳，可抵扣）

### 3.3 危险品运输

- 锂电池归类为 **UN 3480**（锂离子电池单独运输）
- 或 **UN 3481**（与设备合装）
- 包装必须符合 **Packing Group II** 要求
- 运输标签：Class 9（杂项危险品）

## 四、2026年法规更新

### 4.1 BESS合规责任变化
- 从2026年1月起，储能用电不再视为"相关购电"
- 减少了BESS运营者的合规报告负担
- **注意**：这是运营层面变化，不影响产品安全合规

### 4.2 CEFC融资新方向
- 澳洲清洁能源金融公司 (CEFC) 扩大储能融资
- 更大容量、更长时长的储能项目优先
- 对进口商而言：信用良好的终端客户可获融资

## 五、合规路线图（操作指南）

### 第1步：产品测试（6-8周）
- 送样至认可实验室（中国CQC/澳洲SAA等）
- 完成IEC 62619 / AS/NZS 5139测试

### 第2步：认证申请（2-4周）
- 准备RCM技术文件
- 申请CEC列名（如需补贴资格）

### 第3步：进口备案（1-2周）
- 确定澳洲进口商/代理商
- 备案ERAC数据库

### 第4步：物流准备（持续）
- 确认危险品运输资质
- 准备UN 38.3包装

### 第5步：市场准入（持续）
- 注册ABN（商业编号）
- 购买产品责任险（建议$2M+）

## 七、风险提示

1. ⚠️ **认证周期**：测试→认证→入市，至少3个月
2. ⚠️ **法规变更**：TS 5398可能在2026-2027生效，建议跟踪
3. ⚠️ **产品责任**：澳洲消费者法严格，需购买PL保险
4. ⚠️ **售后网络**：澳洲地广人稀，需建立本地技术支持
5. ⚠️ **汇率风险**：AUD波动大，建议锁定汇率或分期结汇
