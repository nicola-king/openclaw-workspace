## 二、渠道详解

### 渠道A：EU TED — 欧盟官方招标数据库

**概况：**
- 网址：ted.europa.eu
- 费用：**完全免费**（浏览+搜索）
- 语言：24种欧盟官方语言
- 年发布量：20万+招标公告
- 覆盖：欧盟27国 + EEA

**适用产品：**
- ✅ 钢结构房屋 → 基建/营房/灾后重建招标
- ✅ 变压器 → 电网升级/新能源配套招标
- ✅ 通用发动机 → 工业设备/备用电源招标
- ⚠️ 移动电源 → 少量（军事/应急采购）

**搜索关键词（英文/本地语言）：**
```
"steel structure building" "modular building" "foldable house"
"transformer" "power transformer" "electrical substation"
"engine" "diesel generator" "power generator"
"portable power" "battery energy storage"
```

**TED.gov 数据源：** ted.europa.eu 提供RSS/XML订阅，可免费监控

### 渠道B：Allegro.pl — 波兰#1

**概况：**
| 指标 | 数据 |
|------|------|
| 月访问量 | 2亿+ |
| 年GMV | ~$120亿 |
| 活跃卖家 | 12万+ |
| 活跃买家 | 1400万+ |
| 国际卖家 | ✅ 2023年开放 |
| 佣金 | 8-15%（按品类） |

**适用产品：**
- ✅ 移动电源 → 最佳渠道（3C电子高流量）
- ❌ 钢结构房屋 → 不适合
- ❌ 变压器 → 不适合
- ❌ 通用发动机 → 不适合

**入驻步骤：**
1. 注册商业账户 → allegro.pl/business
2. 提供公司注册证明
3. 欧盟VAT税号（波兰VAT）
4. 波兰仓储或FBA（Allegro Smart!）
5. 产品列表 + 翻译（波兰语必须）
6. 付款方式：波兰本地银行 + 国际卡

### 🔥 核心渠道D：Prom.ua — 乌克兰#1（主战场）

**概况：**
| 指标 | 数据 |
|------|------|
| 平台类型 | B2B/B2C混合 |
| 月访问量 | 1亿+ |
| 年UV | 3亿+ |
| 商品数 | 2亿+ |
| 所属集团 | EVO Group（乌克兰最大电商集团） |
| 跨境卖家 | ✅ 明确支持 |
| 品类覆盖 | 全品类（含工业品/建筑/电子/五金） |

**为什么Prom.ua适合全部4类产品：**

| 产品 | 在Prom.ua的定位 | 理由 |
|:----|:---------------|:-----|
| 钢结构折叠集成房屋 | B2B板块 + 建材品类 | 战后重建，建筑商/开发商在Prom.ua找供应商 |
| 变压器 | B2B板块 + 工业电气品类 | 电网修复，采购商在Prom.ua核价 |
| 移动电源 | B2C板块 + 电子产品 | 电力不稳定，消费者电商刚需 |
| 通用发动机 | B2B板块 + 五金工具品类 | 工业设备采购渠道 |

**Prom.ua入驻步骤：**

| 步骤 | 动作 | 周期 |
|:---:|:-----|:----:|
| 1 | 访问 prom.ua → 注册卖家账户 | 当天 |
| 2 | 提交公司注册文件 + 产品目录 | 1-3天 |
| 3 | 设置付款方式（乌克兰本地+国际） | 1-2天 |
| 4 | 翻译产品信息至乌克兰语（必需） | 1周 |
| 5 | 上传首批产品 + 设定价格 | 2-3天 |
| 6 | 设置物流（可用第三方跨境物流） | 持续 |
| 7 | 响应买家询盘 + 报价 | 持续 |

**产品上架建议：**
- 钢材房屋 → 归入 Budivelni materialy（建材） + 提供图纸/尺寸/报价
- 变压器 → 归入 Elektroobladnannya（电气设备） + 提供技术参数/认证
- 移动电源 → 归入 Elektronika（电子） + 强调便携/容量/价格
- 发动机 → 归入 Instrumenty（工具/设备） + 提供规格/用途说明

**Prom.ua定价策略：**
- 战后乌克兰购买力较弱，建议中低价位切入
- 钢结构房屋：$5,000-15,000/套（比西欧低30%）
- 移动电源：$20-100（百元以内）
- 变压器+发动机：按规格报价，提供竞品对比

**关键优势：**
- 🇺🇦 乌克兰战后重建是未来5年确定的超级刚需
- Prom.ua B2B模式天然适合工业品交易
- 与 ProZorro 政府招标形成互补（平台获客+招标获客）
