## 📐 推荐配置

### OBS 基础设置

1. **启动 OBS**
   ```bash
   obs
   ```

2. **自动配置向导**
   - 选择"优化仅用于录制"
   - 选择"1080p 30fps"
   - 完成向导

3. **添加录制源**
   - 点击"+"添加"显示器采集"
   - 点击"+"添加"视频采集设备"(摄像头)
   - 调整摄像头到右下角 (150x150px)

4. **设置录制参数**
   - 设置 → 输出 → 录制
   - 格式：MP4
   - 比特率：6000 Kbps
   - 编码器：x264

5. **设置快捷键**
   - 设置 → 快捷键
   - 开始/停止录制：F9
   - 暂停/继续录制：F10

## 🔧 常见问题

### Q1: OBS 无法启动？

```bash
# 检查安装
which obs

# 重新安装
sudo apt reinstall obs-studio

# 检查依赖
ldd /usr/bin/obs
```

### Q2: 录制没有声音？

```
1. 设置 → 音频
2. 添加音频输入捕获 (麦克风)
3. 添加音频输出捕获 (系统声音)
4. 测试音频电平
```

### Q3: 摄像头不显示？

```
1. 检查摄像头权限
2. 添加"视频采集设备"源
3. 选择正确的摄像头设备
4. 调整大小和位置
```

### Q4: 录制文件太大？

```
1. 降低比特率 (3000-6000 Kbps)
2. 降低分辨率 (1280x720)
3. 降低帧率 (24 FPS)
4. 使用更高效的编码器 (NVENC/AMF)
```
