## ⚠️ 常见问题

### Q1: 录制文件在哪？

```
默认位置：~/Videos/
命名格式：YYYY-MM-DD_HH-MM-SS.mp4
示例：2026-04-21_16-32-32.mp4
```

### Q2: 如何修改录制路径？

```bash
# 编辑配置文件
nano ~/.config/obs-studio/basic/profiles/未命名/basic.ini

# 修改这一行
FilePath=/home/nicola/Videos
```

### Q3: 如何提高录制质量？

```ini
# 编辑 basic.ini
[SimpleOutput]
VBitrate=10000        # 提高比特率 (6000→10000)
RecQuality=Lossless   # 提高质量 (Small→Lossless)
```

### Q4: 如何添加摄像头画中画？

```
1. 启动 OBS
2. 点击"+"添加源
3. 选择"视频采集设备"
4. 选择摄像头
5. 调整大小和位置 (推荐右下角 150x150px)
6. 保存场景
```
