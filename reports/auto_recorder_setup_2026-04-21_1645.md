# 太一自动录屏设置指南

> **版本**: v2.0  
> **更新时间**: 2026-04-21 16:45  
> **优化**: 语音指令后自动录制，用户只需操作屏幕

---

## 🎯 核心优化

### 优化前

```
用户："太一，开始录屏"
太一：→ 检查 OBS
     → 打开 OBS
     → 用户手动点击"开始录制"
     → 用户操作屏幕
     → 用户手动点击"停止录制"
```

### 优化后

```
用户："太一，开始录屏"
太一：→ 自动打开 OBS
     → 自动开始录制 ✅
     → 用户只需操作屏幕 ✅
     → 60 分钟后自动停止 ✅
或说"太一，停止录屏"立即停止
```

---

## 🚀 使用方式

### 语音指令 (最简单)

```
1. 说："太一，开始录屏"
   → OBS 自动启动
   → 录制自动开始
   → 你只需操作屏幕

2. 进行你的演示/讲解/操作

3. 说："太一，停止录屏"
   → 录制自动停止
   → 文件自动保存

或等待 60 分钟自动停止
```

### 文字指令

```
/录屏 开始
/录屏 停止
```

## ⚙️ 自动配置

### 默认设置

| 参数 | 值 | 说明 |
|------|-----|------|
| **自动停止** | 60 分钟 | 可自定义 |
| **分辨率** | 1280x720 | 高清 |
| **帧率** | 30 FPS | 流畅 |
| **比特率** | 6000 Kbps | 高质量 |
| **格式** | MP4 | 通用格式 |
| **文件路径** | ~/Videos/ | 默认目录 |

### 自定义自动停止时间

```python
# 编辑 auto_recorder.py
recorder.start_recording(auto_stop_minutes=30)  # 30 分钟
recorder.start_recording(auto_stop_minutes=120)  # 2 小时
```

## ⚠️ 注意事项

### 录制前

- [ ] 确保 OBS 已安装
- [ ] 确保 ~/Videos/ 目录存在
- [ ] 关闭不必要的通知
- [ ] 确保有足够磁盘空间

### 录制中

- [ ] 不要最小化 OBS 窗口
- [ ] 避免运行高性能占用程序
- [ ] 保持电源连接 (笔记本)
- [ ] 保持麦克风静音 (如不需要录音)

### 录制后

- [ ] 检查文件是否生成
- [ ] 播放测试

## 🔧 故障排除

### Q1: 说"太一，开始录屏"没反应？

```bash
# 检查 OBS 是否安装
which obs

# 手动测试
obs --startrecording
```

### Q2: 录制文件在哪？

```bash
# 查看录制文件
ls -lht ~/Videos/*.mp4

# 最新文件
ls -t ~/Videos/*.mp4 | head -1
```

### Q3: 如何修改自动停止时间？

```python
# 编辑 auto_recorder.py
# 找到这一行：
recorder.start_recording(auto_stop_minutes=60)

# 修改为：
recorder.start_recording(auto_stop_minutes=30)  # 30 分钟
```

### Q4: 笔记本电池续航短？

```
优化建议：
1. 接通电源录制
2. 降低屏幕亮度
3. 关闭 WiFi (如不需要)
4. 使用省电模式
```
