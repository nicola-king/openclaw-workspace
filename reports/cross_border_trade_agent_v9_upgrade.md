## 📊 BOC 选品逻辑融合

### 四大关键逻辑

| 逻辑 | 核心 | 评估标准 | 权重 |
|------|------|---------|------|
| **体积小** | 运费按柜计价 | 体积<0.01m³/件 | 25% |
| **利润足** | 国外售价≥出厂价 2 倍 | 售价/成本≥2 | 30% |
| **复购强** | 优先耗材/配件 | 月复购率>20% | 25% |
| **零售后** | 避免易碎/食品/需维修 | 售后率<5% | 20% |

### 智能打分系统

```python
总分 = 体积小×25% + 利润足×30% + 复购强×25% + 零售后×20%

≥85 分：✅ 强烈推荐，立即行动
75-84 分：🟡 推荐，可以推进
60-74 分：🟠 谨慎考虑，需优化
<60 分：❌ 不推荐，建议放弃
```

### 使用示例

```bash
# 评估单个产品
python3 product_selector.py --product "打印机滤芯" \
  --volume 0.005 \
  --factory-price 20 \
  --overseas-price 60 \
  --is-consumable

# 批量评估
python3 product_selector.py --batch products.csv

# 生成选品报告
python3 product_selector.py --report
```

## 🌍 GEO 推广优势融合
