## 📊 Token 节约策略

### 策略 1: 本地模型优先

**优先级**:
```
1. 本地模型 (qwen2.5:7b, llama3:8b)
   → Token 成本：0 CNY
   → 响应速度：最快
   → 适用场景：简单任务

2. 国内模型 (qwen-turbo, deepseek-chat)
   → Token 成本：0.002-0.01 CNY/1K
   → 响应速度：快
   → 适用场景：中等任务

3. 国外模型 (gpt-4, claude-3)
   → Token 成本：0.1-1.0 CNY/1K
   → 响应速度：中等
   → 适用场景：复杂任务
```

**Token 节约效果**:
```
本地模型 vs 国外模型:
- 成本节约：100%
- 速度提升：50-80%
```

国内流量 vs 代理流量:

```

### 策略 5: 配额控制

```

**Token 节约效果**:
```
配额控制 vs 无限制:

```
