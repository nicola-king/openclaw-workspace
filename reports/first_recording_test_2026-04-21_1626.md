## ⚠️ 常见问题

### Q1: OBS 无法启动

```bash
# 检查安装
which obs

# 重新安装
sudo apt reinstall obs-studio
```

### Q2: 录制没有画面

```
1. 检查显示器采集源
2. 确保选择了正确的显示器
3. 检查 OBS 预览窗口
```

### Q3: 录制没有声音

```
1. 设置 → 音频
2. 添加音频输入捕获 (麦克风)
3. 添加音频输出捕获 (系统声音)
```

### Q4: 摄像头不显示

```
1. 添加"视频采集设备"源
2. 选择正确的摄像头
3. 检查摄像头权限
```
