# 📋 报告完整版标准 (Report Completeness Standard)

**生效:** 2026-05-04 | **适用范围:** 所有 Agent 输出的报告

## 强制性字段

### 信息类型完整度要求

| 领域 | 必备字段 | 可选字段 | 验证要求 |
|------|---------|---------|---------|
| 🏨 酒店 | 名称+地址+电话+验证链接 | 图片/评分/房型/配套 | Google Maps + 官网 |
| 🍜 餐馆 | 名称+地址+电话+特色菜+营业时间+验证链接 | 人均价格/图片 | Google Maps + 点评 |
| 🏛️ 景点 | 名称+地址+电话+营业时间+票价+验证链接 | 图片/建议游玩时间 | 官网 + Google Maps |
| ✈️ 交通 | 航司+班次+时间+价格+验证链接 | 机型/餐食 | 航司官网 + 携程 |
| 👤 导游 | 姓名+电话+执照号+验证链接 | 评价/语言 | 工商 + 身份验证 |
| 🚗 租车 | 公司+电话+地址+验证链接 | 车型/价格 | 工商 + 官网 |
| 🏛️ 大使馆 | 名称+电话+地址+办公时间+验证链接 | 服务范围 | 外交部官网 |
| 🏥 医院 | 名称+电话+地址+24小时+验证链接 | 科室 | Google Maps |
| 💊 药店 | 名称+电话+地址+营业时间 | 24小时/否 | Google Maps |

### 验证链接 (verification_links) 标准

每条信息必须附带至少1个可点击验证链接：
- **企业信息** → 官网 + Google Maps + ABN/工商查询
- **景点/餐馆** → Google Maps + 官网 + 点评平台
- **住宿** → Booking/Agoda + 官网 + Google Maps
- **交通** → 航司官网 + 航班追踪
- **服务机构** → 政府官网 + Google Maps

### 格式标准

```
信息名
📞 电话: +65 1234 5678
📍 地址: Street Name, City, Country
🕐 营业时间: Mon-Sat 09:00-21:00
🔗 验证: [官网](url) | [Google Maps](url)
```

---

*此标准由太一强制实施，所有模块输出前自动检查完整度。*
