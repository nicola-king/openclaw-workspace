## 📋 文件格式标准

### 默认格式

| 场景 | 格式 | 说明 |
|------|------|------|
| **报告输出** | .md | Markdown 格式 |
| **文档输出** | .md | Markdown 格式 |
| **分析结果** | .md | Markdown 格式 |
| **调研数据** | .md | Markdown 格式 |
| **会议记录** | .md | Markdown 格式 |
| **学习笔记** | .md | Markdown 格式 |

### 特殊格式 (需客户明确要求)

| 格式 | 使用场景 | 触发条件 |
|------|---------|---------|
| .pdf | 正式文档/打印 | 客户明确要求 PDF |
| .xlsx | 数据表格/财务 | 客户明确要求 Excel |
| .docx | 合同/正式文件 | 客户明确要求 Word |
| .pptx | 演示文稿 | 客户明确要求 PPT |
| .json | 数据交换/API | 客户明确要求 JSON |
| .csv | 数据导出 | 客户明确要求 CSV |
| .txt | 纯文本 | 客户明确要求 TXT |
| .html | 网页/邮件 | 客户明确要求 HTML |

## 📤 Telegram 发送标准

### 发送方式

```
1. 生成 MD 文件
   ↓
2. 调用 Telegram Bot API
   ↓
3. sendDocument 方法
   ↓
4. 附带简要说明 (Caption)
   ↓
5. 确认发送成功
```

### Caption 标准

| 要素 | 说明 | 示例 |
|------|------|------|
| 文件标题 | 清晰描述内容 | 🔬 医疗器械市场调研报告 |
| 核心数据 | 3-5 个关键数据 | 82.34 分/A 级/320% ROI |
| 行动建议 | 简要建议 | P0 立即布局/东南亚市场 |
| 生成时间 | 报告时间 | 2026-04-19 10:45 |
| 工具署名 | 生成工具 | 太一跨境贸易 Agent v8.4 |

### Caption 示例

```
🔬 医疗器械/变压器/3D 打印机 - 市场调研报告

📊 核心结论:
✅ 医疗器械：82.34 分 (A 级) - 重点推荐

⚠️ 变压器：71.23 分 (B 级) - 谨慎推荐

📈 增长率对比:
• 医疗器械：+58%
• 3D 打印机：+52%
• 变压器：+28%

💰 ROI 对比:
• 医疗器械：320%
• 3D 打印机：260%
• 变压器：180%

太一跨境贸易 Agent v8.4 · 2026-04-19 10:45
```

## 📁 MD 文件标准格式

### 文件头

```markdown
# 📊 报告标题

> **分析时间**: YYYY-MM-DD HH:mm  
> **分析工具**: 太一 XX Agent vX.X  
> **分析方法**: XXX 分析法  
> **数据覆盖**: XXX 范围

---
```

### 核心结论

```markdown
## 📊 核心结论

| 项目 | 数据 | 评级 | 推荐 |
|------|------|------|------|
| 产品 A | XX 分 | A 级 | ✅ 推荐 |
| 产品 B | XX 分 | B 级 | ⚠️ 谨慎 |

---
```

### 详细分析

```markdown
## 🔍 详细分析

### 产品 A

| 维度 | 得分 | 权重 |
|------|------|------|
| 趋势 | XX/100 | 30% |
| 搜索 | XX/100 | 25% |
| ... | ... | ... |

---
```

### 建议行动

```markdown
## 🎯 建议行动

### P0 立即行动

| 行动 | 说明 | 时间 |
|------|------|------|
| 行动 1 | 说明 | 1 周内 |
| 行动 2 | 说明 | 2 周内 |

---
```

### 文件尾

```markdown
*太一 XX Agent vX.X · YYYY-MM-DD HH:mm*  
*XXX 分析法 · 数据覆盖 XXX*
```

## 🔄 执行流程

### 标准流程

```
用户请求
    ↓
生成内容
    ↓
格式化为 MD
    ↓
保存到本地
    ↓
Telegram 发送
    ↓
确认发送成功
    ↓
Git 提交归档
```

```

    ↓

    ↓

    ↓
保存到本地
    ↓
Telegram 发送
    ↓
确认发送成功
    ↓
Git 提交归档
```
