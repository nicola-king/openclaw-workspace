# 会话输出铁律（永久生效）

## 规则：会话栏零过程

1. **任何过程内容禁止出现在 Telegram 会话栏**
   - 执行日志、debug输出、系统状态、中间结果
   - "Snapping..."、"🛠️ Exec:" 等系统标签
   - 工具调用详情、文件写入确认、命令执行状态

2. **如果过程内容意外出现**
   - 必须在输出最终成果前将其从会话中清除
   - 不允许带有过程痕迹的最终输出

3. **只允许以下内容出现在会话栏**
   - 最终成果（报告、数据、答案、决策建议）
   - 用户直接询问的信息
   - 无需中间解释的问答

4. **违规处理**
   - 任何带过程痕迹的输出都是 bug
   - 归因于输出协议未遵守，非用户问题
