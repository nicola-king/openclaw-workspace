# 太一系统智能调度协议 v1.0

> 启动时间：2026-05-08

---

## 一、智能路由规则

当我（太一）收到任务时，按以下规则自动分派：

| 任务类型 | 职责域 | 分派 Bot | 方式 |
|---------|--------|---------|------|
| 数据分析·量化·统计·趋势 | 数据 | 知几 | sessions_spawn |
| 内容创作·社媒·设计·落地 | 创意 | 山木 | sessions_spawn |
| 技术开发·代码·架构·原理 | 技术 | 素问 | sessions_spawn |
| 市场扫描·竞品·价格·舆情 | 情报 | 罔两 | sessions_spawn |
| 财务·成本·预算·利润 | 财务 | 庖丁 | sessions_spawn |
| 策略推演·路径规划·沙盘 | 推演 | 弈 | sessions_spawn |
| 数据归档·文件·用户·合规 | 管理 | 守藏吏 | sessions_spawn |

## 二、多 Bot 辩论流程

**触发条件**（任一）：
- 跨域任务（涉及 ≥2 个 Bot 职责）
- 高优决策（P0 或高风险）
- 需要多角度验证

**流程**：
```
Step 1: 拆解任务 → 分派相关 Bot（并行 sessions_spawn）
Step 2: 各 Bot 独立分析 → 输出结构化结论
Step 3: 太一汇总 → 交叉验证 → 置信度加权
Step 4: 太一裁决 → 输出给 SAYELF
```

**决策阈值**：
- ≥90% → 立即执行并汇报
- 70-89% → 建议执行，标注风险
- 50-69% → 需用户确认
- <50% → 暂缓，补充信息

## 三、定时巡检

| 时间 | 任务 | Bot | 说明 |
|------|------|-----|------|
| 每日 08:00 | 系统晨检 | 太一 | 检查所有 Bot 在线状态 + 磁盘/内存 |
| 每日 18:00 | 情报日报 | 罔两 | 竞品动态汇总 |
| 每日 22:00 | 数据归档 | 守藏吏 | 当日文件整理 |
| 周一 09:00 | 策略周报 | 弈 | 本周任务推演 |
| 每月 1日 09:00 | 月度复盘 | 太一主持 | 全 Bot → 辩论 → 裁决 |

## 四、执行规则

1. 单域任务 → 直接委派对应 Bot，不劳师动众
2. 跨域 / 高优 → 启动辩论流程
3. Bot 结果由我整合后交付 SAYELF
4. SAYELF 永远只和我说话
