# 上下文卫生规则

> 版本：v1.0 | 状态：✅ 常驻生效

---

## 核心原则

**保持上下文整洁，避免信息污染。**

---

## 规则

### 1. 不重复加载
- 已读取的文件不重复读取
- 已确认的信息不重复确认

### 2. 及时压缩
- context >80K 时触发 TurboQuant 压缩
- 旧对话及时归档到 memory

### 3. 隔离敏感信息
- MEMORY.md 仅在主 session 加载
- 群聊中不泄露个人上下文

### 4. 清理过期信息
- 临时 TODO 超过 7 天清理
- 对话记录超过 30 天归档

---

## 检查清单

- [ ] 当前 context 是否已超载？
- [ ] 是否有重复信息？
- [ ] 敏感信息是否已隔离？
- [ ] 过期信息是否已清理？

---

*上下文卫生 = 系统健康的基石*
