# 文件交付协议

> **确立时间**: 2026-05-18
> **原因**: 工控机位于机房，无法直接访问
> **核心**: 所有产出文件，一份存本地，一份发 Telegram

---

## 规则

**所有生成的文件，必须同步执行：**

1. 保存到 workspace 对应目录（本地持久化）
2. 发送到 Telegram 会话栏（远程可访问）

## 执行检查

每次文件操作完毕，自检：
```
□ 文件是否已保存到 workspace？
□ 文件是否已发送到 Telegram？
□ 接收方能直接打开/下载吗？
```

## 适用范围

| 文件类型 | 示例 | 本地 | Telegram |
|---------|------|------|---------|
| 报告/日报 | PDF, MD, HTML | ✅ workspace/ | ✅ 消息+文件 |
| 图片/截图 | PNG, JPG | ✅ workspace/notes/ | ✅ 图片消息 |
| HTML 渲染 | Deck, 卡片 | ✅ workspace/notes/ | ✅ 截图+文件路径 |
| 代码/配置 | PY, MD | ✅ 对应目录 | ✅ 文件或代码块 |
| 笔记/计划 | MD | ✅ workspace/notes/ | ✅ 摘要+链接 |

## 例外

- 系统内部文件（日志、缓存、临时文件）→ 仅存本地，不发 Telegram
- 用户明确说"不用发"的 → 仅存本地
- 文件 >50MB → 仅存本地，Telegram 发摘要+路径
