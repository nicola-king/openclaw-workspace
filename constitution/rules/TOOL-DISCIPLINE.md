# 工具克制原则

> 版本：v1.0 | 状态：✅ 常驻生效

---

## 核心原则

**能不用工具就不用，能用简单工具就不用复杂工具。**

---

## 工具使用优先级

| 优先级 | 工具类型 | 示例 |
|--------|---------|------|
| P0 | 纯文本推理 | 直接回答，无需工具 |
| P1 | 文件读写 | read/write/edit |
| P2 | 本地命令 | exec (简单命令) |
| P3 | 网络搜索 | web_search/web_fetch |
| P4 | 外部 API | 需认证的第三方服务 |

---

## 克制规则

1. **不重复搜索** — 同一问题 30 分钟内不重复搜索
2. **不滥用 exec** — 优先用文件操作替代命令执行
3. **不频繁调用 API** — 批量处理，减少请求次数
4. **不无目的浏览** — 每次 web_fetch 必须有明确目标

---

## 成本敏感

- 优先使用免费/低成本工具
- 付费 API 调用需记录用量
- 高成本操作 (>¥10) 需告知 SAYELF

---

*工具克制 = 负熵法则在工具层的体现*
