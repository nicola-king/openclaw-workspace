## 🎯 核心原则

**强制 AI 分步思考，而不是直接给答案**

---

## 📋 思维链框架

### 标准流程（5 步法）

```
1. 理解问题 → 2. 分析条件 → 3. 制定计划 → 4. 执行步骤 → 5. 验证结果
```

---

## ✅ 好 vs ❌ 坏示例

### 示例 1: 数学问题

❌ **直接给答案**:
```
问：1+2+3+...+100 = ?
答：5050
```

✅ **思维链**:
```
让我一步步思考：

1. **理解问题**: 求 1 到 100 的等差数列和

2. **分析条件**:
   - 首项 a1 = 1
   - 末项 an = 100
   - 项数 n = 100
   - 公差 d = 1

3. **制定计划**: 使用等差数列求和公式
   Sn = n(a1 + an) / 2

4. **执行计算**:
   S100 = 100(1 + 100) / 2
        = 100 × 101 / 2
        = 10100 / 2
        = 5050

5. **验证结果**:
   - 检查：1+100=101, 2+99=101, ..., 50+51=101
   - 共 50 对，每对和为 101
   - 50 × 101 = 5050 ✅

答案：5050
```

### 示例 2: 代码调试

❌ **直接修复**:
```
问：这个函数为什么报错？
def process(data):
    return data[0] / len(data)

答：改成 return data[0] / len(data) if data else 0
```

✅ **思维链**:
```
让我一步步分析：

1. **理解问题**: 函数 process() 报错

2. **分析错误**:
   - 错误类型：IndexError 或 ZeroDivisionError
   - 触发条件：data 为空列表时
   - 问题位置：data[0] 或 len(data)

3. **定位原因**:
   - 当 data = [] 时：
     - data[0] → IndexError: list index out of range
     - len(data) = 0 → ZeroDivisionError

4. **制定方案**:
   - 方案 1: 添加空列表检查
   - 方案 2: 使用默认值
   - 方案 3: 抛出明确异常

5. **选择最佳方案**: 方案 1（返回默认值 0）

6. **实现代码**:
```python
def process(data):
    if not data:  # 空列表检查
        return 0
    return data[0] / len(data)
```

7. **验证修复**:
   - 测试：process([]) → 0 ✅
   - 测试：process([10, 20]) → 5.0 ✅
```

## 🔧 太一系统实施

### 强制执行思维链

```python
def enforce_chain_of_thought(task):
    """强制 AI 使用思维链"""
    prompt = f"""
请按照以下步骤解决问题：

1. **理解问题**: 重述问题，确保理解正确
2. **分析条件**: 列出已知条件和约束
3. **制定计划**: 列出解决步骤
4. **执行步骤**: 详细执行过程
5. **验证结果**: 检查答案正确性

问题：{task}
"""
    return prompt
```

### 思维链质量检查

```python
def check_chain_quality(response):
    """检查思维链质量"""
    required_steps = ['理解', '分析', '计划', '执行', '验证']
    
    missing = []
    for step in required_steps:
        if step not in response:
            missing.append(step)
    
    if missing:
        return False, f"缺少步骤：{missing}"
    return True, "思维链完整"
```
