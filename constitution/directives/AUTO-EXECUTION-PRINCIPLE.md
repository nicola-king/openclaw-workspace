## 📋 执行标准

### 优先级定义

| 优先级 | 定义 | 执行时间 | 汇报时机 |
|--------|------|---------|---------|
| **P0** | 关键紧急 | 立即执行 (0 延迟) | 完成后 |
| **P1** | 重要紧急 | 立即执行 (<1 分钟) | 完成后 |

```

    ↓

    ↓
立即自动化执行
    ↓
持续执行直到完成
    ↓
执行后一次性汇报
    ↓
Git 归档保存
```

### ✅ 立即执行

- ✅ 按 P0→P1→P2→P3 顺序自动执行
- ✅ 不等待确认，持续执行直到完成

## 🔄 执行流程详解

### Step 1: 接收指令

```
用户指令/太一建议
    ↓
解析意图
    ↓
提取任务列表
    ↓
分配优先级 (P0/P1/P2/P3)
```

### Step 2: 立即执行

```
P0 任务 → 立即执行 (0 延迟)
    ↓ 完成？
   是 → P1 任务
   否 → 继续执行
    ↓
P1 任务 → 立即执行 (<1 分钟)
    ↓ 完成？
   是 → P2 任务
   否 → 继续执行
    ↓
P2 任务 → 立即执行 (<5 分钟)
    ↓ 完成？
   是 → P3 任务
   否 → 继续执行
    ↓
P3 任务 → 立即执行 (<10 分钟)
    ↓ 完成？
   是 → 执行后汇报
   否 → 继续执行
```

### Step 3: 执行后汇报

```
所有任务完成
    ↓
生成完整报告
    ↓
MD 文件格式化
    ↓
Telegram 发送
    ↓
Git 归档保存
```
