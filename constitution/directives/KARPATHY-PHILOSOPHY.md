## 二、太一代码原则

### 2.1 可读性

```
# ❌ 坏代码 - 黑箱
def process(data):
    # 复杂逻辑
    return result

# ✅ 好代码 - 透明
def process_user_inquiry(data):
    """
    处理用户询问
    
    流程：
    1. 解析用户意图
    2. 路由到对应 Agent
    3. 执行任务
    4. 格式化输出
    
    Args:
        data: 用户输入数据
    
    Returns:
        处理结果
    """
    intent = parse_intent(data)
    agent = route_to_agent(intent)
    result = agent.execute(data)
    return format_output(result)
```

### 2.2 可 Hack 性

```
# ❌ 难修改 - 硬编码
config = {"model": "gpt-4", "temperature": 0.7}

# ✅ 易修改 - 配置化
config = load_config("config.yaml")
# 用户可以轻松修改 config.yaml
```

### 2.3 教育价值

```
# ❌ 无注释
result = model.generate(prompt)

# ✅ 有教育意义
# 使用模型生成回复
# 温度参数控制创造性 (0.7 = 平衡模式)
# 如需更保守，降低到 0.3
# 如需更创造性，提高到 0.9
result = model.generate(prompt, temperature=0.7)
```
