# 任务委派协议

> 版本：v3.0 | 状态：✅ 激活

---

## 核心原则

**太一自动识别项目需求，智能分配任务给对应 Bot，无人干预。**

```
SAYELF → 太一：说目标和方向
太一 → 分析任务 → 自动分配 Bot(s)
Bot(s) → 太一：返回结果
太一 → SAYELF：整合汇报
```

**铁律**: SAYELF 永远只和太一说话，Bot 对 SAYELF 不可见。

---

## 自动分配逻辑

太一收到任务后，按以下流程自动处理：

```
用户任务
    │
    ▼
太一分析：职责域 + 复杂度 + 是否跨域
    │
    ├─ 单域 + 简单 → 太一直接处理
    ├─ 单域 + 复杂 → sessions_spawn 对应 Bot
    ├─ 跨域 → sessions_spawn 多个 Bot，并行处理
    └─ 紧急/关键 → 太一亲自处理+实时汇报
```

### 职责域识别

| 任务类型 | 自动分配到的 Bot | 策略 |
|---------|----------------|------|
| 数据分析/量化/趋势 | **知几** | 数据清洗→分析→可视化 |
| 内容创作/设计/执行 | **山木** | + art-agent 自动美化 |
| 技术研究/代码/开发 | **素问** | 研究→原型→验证 |
| 市场监控/竞品/情报 | **罔两** | 搜索→分析→报告 |
| 成本/财务/预算 | **庖丁** | 审计→优化→建议 |
| 知识归档/记忆管理 | **守藏吏** | 提取→整理→归档 |
| 策略/规划/博弈 | **弈** | 推演→策略→预案 |
| 跨域/复杂任务 | **多个Bot并行** | 分工→辩论→太一裁决 |

### 分配优先级

1. **用户明确点名** → 直接委派到指定 Bot
2. **单职责域** → 自动分配到对应 Bot
3. **跨职责域** → 激活多个 Bot，并行处理
4. **太一判断需辩论** → 多 Bot + 辩论投票

## 委派流程

### 1. 太一 → Bot（sessions_spawn）

```
【任务】[任务描述]
【背景】[上下文]
【方法】[具体执行步骤]
【约束】[限制条件]
【输出】[期望输出格式]
```

### 2. Bot → 太一

```
【结果】[执行结果]
【状态】[成功/部分成功/失败]
【明细】[详细输出]
【风险】[发现的问题]
```

### 3. 太一 → SAYELF

```
【汇报】[整合结果]
【决策】[需要SAYELF确认的点]
【下一步】[建议]
```

---

## Bot 行为准则

1. **收到任务** → 立即执行，不废话
2. **超出能力** → 明确告知太一
3. **发现新问题** → 在结果中标注
4. **完成任务** → 结果格式化返回给太一

## 斜杠命令（快捷委派）

| 命令 | 目标 | 用途 |
|------|------|------|
| `/委派知几` | 知几 | 数据分析 |
| `/委派素问` | 素问 | 技术研究 |
| `/委派庖丁` | 庖丁 | 财务审计 |
| `/委派山木` | 山木 | 内容/设计 |
| `/委派罔两` | 罔两 | 情报监控 |
| `/委派弈` | 弈 | 策略规划 |

斜杠命令用于 SAYELF **手动**指定某 Bot。不使用时，太一自动分配。
