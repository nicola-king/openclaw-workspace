## 📊 智能分流决策树






```
用户请求
  ↓

  ├─ 是 → deepseek-v4-flash
  │     └─ (需要更强推理) → deepseek-v4-pro
  └─ 否 ↓
[4] 默认路由
  └─ deepseek-v4-flash (主力)
```

## 🎯 自动切换机制






### 规则 1：DeepSeek 限额 → 切换 Gemini 免费额度






**触发条件**：
- DeepSeek API 不可用
- DeepSeek 配额耗尽
- 连续失败 3 次

**动作**：
1. 切换当前模型为 `gemini-2.5-pro`（免费额度）
2. 记录切换原因
3. 后续任务使用 Gemini

**降级路由**：
```
DeepSeek 限额 → 任务重新分类 →
  ├─ 简单任务 → 本地模型 (Gemma 2 9B) ✅
  ├─ 中等任务 → Gemini 2.5 Pro (免费额度)
  ├─ 复杂任务 → Gemini 2.5 Pro (免费额度)
  └─ 代码任务 → Gemini 2.5 Pro (免费额度)
```

---

### 规则 2：Gemini 免费额度 90% → 自动切换本地模型






**触发条件**：
- Gemini 免费额度使用量达到 90%

**动作**：
1. 切换当前模型为本地 `Gemma 2 9B`
2. 复杂任务降级处理（分段/摘要）
3. 记录切换原因

**降级路由**：
```
Gemini 90% 触发 → 任务重新分类 →
  ├─ 简单任务 → 本地 Gemma 2 9B ✅
  ├─ 中等任务 → 本地 Gemma 2 9B (分段处理)
  ├─ 复杂任务 → 本地 Gemma 2 9B (摘要模式)
  └─ 代码任务 → 本地 Gemma 2 9B
```

---

### 规则 3：配额告警






| 周期 | 阈值 | 动作 | 降级策略 |
|------|------|------|---------|
| **DeepSeek 连续失败 3 次** | 🔄 切换 | 自动切 Gemini | Gemini → 本地 |
| **Gemini 免费额度 90%** | 🚨 紧急 | 全力启动本地模型 | 非必要任务全部本地化 |
