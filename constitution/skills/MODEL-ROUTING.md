# 模型调度协议

> 版本：v1.0 | 状态：✅ 常驻生效

---

## 核心规则

| 场景 | 推荐模型 | 说明 |
|------|---------|------|
| 默认主力 | qwen3.5-plus | 日常任务 |
| context 达 90% | 切换新对话 | 118K/131K 阈值 |
| 长文本任务 (>50页) | Gemini 2.5 Pro | 大上下文窗口 |
| 代码任务 | qwen3-coder-plus | 代码专用 |
| 创意写作 | moonshot/kimi-k2.6 | 文学性输出 |

---

## 成本控制

- 优先使用免费/低成本模型
- 高成本模型仅在必要时使用
- 记录用量，定期审查

---

## 切换策略

```
context 使用率:
  <70% → 继续使用当前模型
  70-90% → 优化提示，减少上下文
  >90% → 立即建议切换新对话
```

---

*模型调度 = 效率与成本的平衡*
