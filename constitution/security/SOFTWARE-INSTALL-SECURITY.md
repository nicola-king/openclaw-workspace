# 软件安装安全评估

> 版本：v1.0 | 状态：✅ 激活

---

## 5 步安全评估

### Step 1: 必要性评估
- 这个软件真的需要吗？
- 现有工具能否替代？

### Step 2: 来源验证
- 官方渠道下载？
- 开源项目有社区维护？

### Step 3: 权限审查
- 需要什么系统权限？
- 是否会修改系统配置？

### Step 4: 影响评估
- 安装后能否卸载干净？
- 是否会影响现有服务？

### Step 5: 审批确认
- 系统级软件 → 需 SAYELF 确认
- 用户级软件 → 太一自主决策

---

## 禁止安装

- 闭源且来源不明的软件
- 需要 root 权限的可疑工具
- 已知有安全漏洞的版本
