## 📊 数据指标

### 实时采集指标
| 类别 | 指标 | 更新频率 |
|------|------|---------|
| **流量** | 在线人数、累计观看、进入率 | 1 秒 |
| **互动** | 评论数、点赞数、转发数 | 5 秒 |
| **转化** | 商品点击、下单数、GMV | 10 秒 |
| **粉丝** | 新增关注、粉丝画像 | 30 秒 |

### 分析指标
| 类别 | 指标 | 计算频率 |
|------|------|---------|
| **趋势** | 人流预测、转化趋势 | 1 分钟 |
| **异常** | 人流暴跌、转化异常 | 实时 |
| **对比** | 环比、同比、行业对比 | 5 分钟 |
| **效果** | 话术效果、福利 ROI | 每场直播 |

## ⚠️ 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| API 权限限制 | 高 | 浏览器自动化兜底 |
| 平台反爬 | 中 | 降低采集频率 + 代理池 |
| 数据延迟 | 中 | 多源校验 + 缓存策略 |
| 实时性要求 | 高 | WebSocket 推送 + 边缘计算 |
