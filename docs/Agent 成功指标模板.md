## 一、通用成功指标框架

```markdown
## ✅ 成功指标 (Success Metrics)

### 效率指标
- **响应时间**: <1 分钟 (P0 任务) / <5 分钟 (P1 任务)
- **任务完成率**: ≥95%
- **准确率**: ≥90%

### 质量指标
- **用户满意度**: ≥4.5/5.0
- **输出质量**: 通过质量检查清单
- **代码质量**: 测试覆盖率≥80% (如适用)

### 业务指标
- **价值创造**: 量化业务影响
- **成本节约**: 时间/人力成本降低
- **可复用性**: 输出可被其他 Agent 使用
```

## 三、成功指标使用指南

### 3.1 如何定义指标

```
1. 明确 Agent 职责域
2. 识别关键结果领域 (KRA)
3. 为每个 KRA 定义量化指标
4. 设定基准值和目标值
5. 建立监控和报告机制
```

### 3.2 指标分级

| 级别 | 说明 | 示例 |
|------|------|------|
| **P0** | 核心指标，必须达标 | 交易胜率≥55% |
| **P1** | 重要指标，努力达成 | 年化收益≥15% |
| **P2** | 参考指标，持续优化 | 用户满意度≥4.5 |

### 3.3 监控频率

| 指标类型 | 监控频率 | 报告对象 |
|---------|---------|---------|
| 实时指标 | 每分钟 | Dashboard |
| 日常指标 | 每天 | 日报 |
| 周期指标 | 每周 | 周报 |
| 战略指标 | 每月 | 月报 |

## 四、指标计算公式

### 4.1 效率指标

```
任务完成率 = (完成任务数 / 总任务数) × 100%
准时交付率 = (准时交付数 / 总交付数) × 100%
响应时间 = 任务接收时间 - 任务开始时间
```

### 4.2 质量指标

```
准确率 = (正确输出数 / 总输出数) × 100%
用户满意度 = (满意评价数 / 总评价数) × 100%
Bug 率 = (Bug 数量 / 代码行数) × 1000 (每千行)
```

### 4.3 业务指标

```
ROI = (收益 - 成本) / 成本 × 100%
转化率 = (转化用户数 / 总用户数) × 100%
客户终身价值 (LTV) = 平均订单值 × 购买频次 × 客户寿命
```
