## 二、核心功能详解

### 2.1 智能旅行规划

**支持类型**：
- ✅ 国内游（自动识别城市）
- ✅ 跨国游（自动判断签证/汇率/时差）
- ✅ 多城市联游（智能路线优化）

**规划内容**：
```
1. 航班/火车推荐（3 个选项 + 价格对比）
2. 酒店推荐（经济/舒适/豪华 3 档）
3. 行程规划（每日景点 + 交通 + 餐饮）
4. 预算分配（自动计算最优比例）
5. 旅行清单（根据目的地自动生成）
6. 注意事项（签证/天气/货币/禁忌）
```

**如何提问**：
```
标准格式：
"我想去 [目的地]，[开始日期] 到 [结束日期]，
 [人数] 个人，预算 [金额] 元，
 需要 [包车/导游/其他服务]"

示例：
"我想去泰国普吉岛，6 月 1 日到 6 月 8 日，
 4 个人（2 大 2 小），预算 20000 元，
 需要包车接机和亲子导游"
```

---

### 2.2 落地服务预订

**服务类型**：

| 服务 | 说明 | 价格参考 |
|------|------|---------|
| **包车接机** | 机场到酒店专车接送 | ¥500-1,000/次 |
| **当地包车** | 按天包车（含司机） | ¥600-1,500/天 |
| **地陪导游** | 当地华人导游服务 | ¥800-1,500/天 |
| **全包套餐** | 包车 + 导游 + 门票 | ¥1,500-3,000/天 |

**预订流程**：
```
1. 发送："需要 [城市] 的 [服务类型]"
   例："需要东京的包车接机"

2. Agent 推荐供应商（3 个选项）
   - 供应商名称
   - 服务价格
   - 用户评分
   - 联系方式

3. 确认预订
   回复："预订 [供应商编号]"

4. Agent 发送预订确认单
   - 服务详情
   - 联系人电话
   - 支付方式
```

## 三、常见问题

### 3.1 旅行者常见问题

**Q1: 规划免费吗？**
> A: 基础规划完全免费！预订服务时供应商会收取正常费用。

**Q2: 推荐可靠吗？**
> A: 所有供应商经过资质审核 + 用户评价双重验证，放心选择！

**Q3: 可以修改行程吗？**
> A: 当然可以！随时告诉我你的需求变化，我实时调整。

**Q4: 支持哪些国家？**
> A: 目前支持：日本、韩国、泰国、新加坡、马来西亚、澳大利亚等主流目的地，持续增加中！

**Q5: 如何支付？**
> A: 直接与供应商协商支付，Agent 不参与交易，保障资金安全。

**Q6: 有售后保障吗？**
> A: 有！如遇服务问题，联系 Agent 协助处理，严重问题列入黑名单。

---

### 3.2 供应商常见问题

**Q1: 入驻收费吗？**
> A: 入驻完全免费！仅在成交后收取 10-15% 佣金。

**Q2: 如何管理订单？**
> A: 通过 Telegram/微信接收订单通知，也可登录后台管理。

**Q3: 如何提高排名？**
> A: 提高评分（服务好）+ 降低价格（竞争力）+ 增加销量（活跃度）。

**Q4: 可以拒绝订单吗？**
> A: 可以，但频繁拒绝会影响排名和曝光。

**Q5: 如何提现？**
> A: 与 Agent 协商结算周期（周结/月结），直接转账到您的账户。
