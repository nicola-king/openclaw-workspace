## 四、跟进策略

### 4.1 首次联系

```
时间：发送后 24 小时
内容：友好提醒
方式：同一渠道
```

### 4.2 二次跟进

```
时间：首次跟进后 48 小时
内容：提供更多信息
方式：同一渠道
```

### 4.3 三次跟进

```
时间：二次跟进后 72 小时
内容：最后邀请
方式：更换渠道（如可能）
```

### 4.4 放弃跟进

```
条件：三次跟进无回复
动作：标记为"暂无意向"
后续：3 个月后再次尝试
```

## 八、常见问题

### Q1: 如何找到潜在贡献者？

**方法**：
- GitHub 搜索相关项目贡献者
- 技术社区搜索活跃用户
- 社交媒体搜索相关话题
- 朋友/同事推荐

### Q2: 如何提高回复率？

**技巧**：
- 个性化消息，提到对方成就
- 清晰说明项目价值
- 明确贡献方式
- 提供激励机制

### Q3: 如何维持贡献者活跃度？

**方法**：
- 定期社区活动
- 及时回应问题
- 公开表彰贡献
- 提供成长路径

### Q4: 如何处理贡献者流失？

**方法**：
- 了解流失原因
- 改进社区体验
- 保持联系
- 欢迎随时回归
