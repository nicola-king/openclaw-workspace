手把手教大家用太一 Agent！🎯

📝 **步骤**：

1️⃣ **克隆项目**
```bash
git clone https://github.com/nicola-king/taiyi-agents.git
cd taiyi-agents
```

2️⃣ **安装依赖**
```bash
pip install -r requirements.txt
```

3️⃣ **配置 API Key**
```bash
cp .env.example .env
nano .env
# 填入你的 API Key
```

4️⃣ **运行 Agent**
```bash
python3 main.py
```

5️⃣ **开始对话**
