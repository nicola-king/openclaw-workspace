## 🚀 使用示例

### 1. 生成行程

```python
from taiyi_travel_agent import TaiyiTravelAgent

agent = TaiyiTravelAgent()
plan = agent.generate_itinerary(
    destination="三亚",
    days=7,
    budget=10000,
    mode="comfortable"  # 或 "economic"
)
```

---

### 2. 查询机票

```bash
python3 provider_cli.py flight \
    --from 北京 \
    --to 三亚 \
    --date 2026-05-01 \
    --class economy
```

---

### 3. 酒店推荐

```bash
python3 ground_services.py hotel \
    --destination 三亚 \
    --check-in 2026-05-01 \
    --check-out 2026-05-08 \
    --budget 500
```

---

### 4. 知识学习

```bash
python3 travel_knowledge_learner.py \
    --destination 三亚 \
    --learn
```

---

### 5. 自进化

```bash
python3 self_evolving_travel_agent.py \
    --evolve \
    --generations 10
```
