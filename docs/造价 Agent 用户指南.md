## 二、核心功能详解

### 2.1 道路工程造价

**支持类型**：
- ✅ 城市道路（主干路/次干路/支路）
- ✅ 公路（高速/一级/二级/三级）
- ✅ 厂区道路
- ✅ 乡村道路

**计算内容**：
```
1. 路基工程
   - 土石方开挖/回填
   - 路基处理（换填/加固）

2. 路面工程
   - 沥青混凝土路面
   - 水泥混凝土路面
   - 碎石路面

3. 附属工程
   - 路缘石
   - 人行道
   - 绿化带
```

**使用示例**：
```python
from cost_agent import CostCalculator

calc = CostCalculator(region="上海", standard="2020 定额")

# 城市主干路
road = calc.calculate_road(
    length=1000,          # 米
    width=20,             # 米
    structure="沥青混凝土路面",
    grade="城市主干路",
    soil_type="三类土"
)

print(f"总造价：¥{road.total:,.2f}")
print(f"单位造价：¥{road.unit_price:.2f}/㎡")
```

**输出详情**：
```

```

```
   - 承台
   - 桥台

2. 下部结构
   - 墩柱
   - 盖梁

3. 上部结构
   - 预制梁/现浇梁
   - 桥面铺装
   - 护栏

4. 附属工程
   - 伸缩缝
   - 支座
   - 排水系统
```


```
建议 1：与供应商签订长期协议
```

```
1. 提出变更申请

5. 实施变更

```

## 六、最佳实践

### 6.1 提高准确性

```
技巧 1：现场踏勘
  - 核实地形地貌
  - 确认地质条件
  - 了解周边环境

技巧 2：图纸会审
  - 发现设计问题
  - 明确施工要求
  - 避免后期变更

技巧 3：多方询价
  - 至少 3 家供应商
  - 对比价格质量
  - 考虑运输成本
```

### 6.2 控制成本

```
技巧 1：优化设计
  - 合理选择结构形式
  - 优化材料规格
  - 减少不必要的装饰

技巧 2：施工组织
  - 合理安排工期
  - 减少窝工浪费
  - 提高机械利用率

技巧 3：采购策略
  - 集中采购降低成本
  - 淡季采购价格优惠
  - 长期合作建立信任
```

### 6.3 风险防范

```
风险 1：工程量漏项
  应对：清单逐项核对 + 现场复核

风险 2：价格波动
  应对：价格风险条款 + 调价机制

风险 3：变更频繁
  应对：严格变更审批 + 及时签证

风险 4：结算纠纷
  应对：过程资料完整 + 第三方审核
```
