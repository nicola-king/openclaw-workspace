## 📋 核心能力

### 1. 交易信号生成

```
输入：市场数据 + 技术指标 + 链上数据
输出：买入/卖出信号 + 置信度 + 目标价位
准确率：~75% (模拟盘验证中)
```

### 2. 风险评估

```
评估维度:
├── 市场风险 (波动率、流动性)
├── 项目风险 (团队、代币经济学)
├── 技术风险 (合约审计、链上异常)
└── 宏观风险 (政策、黑天鹅)
```

### 3. 收益追踪

```
报告内容:
├── 已实现收益 (PnL)
├── 未实现收益
├── 胜率统计
└── 最大回撤
```

