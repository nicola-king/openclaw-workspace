## 🔄 协作网络

```
          太一 (统筹)
           / | | | \
       知几 山木 素问 罔两 庖丁
       交易  内容  健康  监控  工具
```

**协作流程**:
1. 用户 → 太一 (接收任务)
2. 太一 → 职责域判断
3. 太一 → 对应 Agent (任务分配)
4. Agent → 太一 (结果汇报)
5. 太一 → 用户 (汇总报告)
