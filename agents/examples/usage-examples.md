## 5. 工具开发示例

### 场景：创建备份脚本

**用户输入**:
```
帮我写个自动备份脚本，每天备份工作目录
```

**太一处理流程**:
```
[1] 意图识别 → 工具开发
[2] 职责域判断 → 庖丁 (工具大师)
[3] 调用庖丁 Agent
[4] 生成脚本 → 说明 → 部署
```

**庖丁回复**:
```markdown
## 🛠️ 自动备份脚本已创建

### 脚本内容

```bash
#!/bin/bash
# 自动备份脚本 · 庖丁 Agent
# 用法：./auto-backup.sh [目标路径]

BACKUP_DIR="${1:-/backup}"
DATE=$(date +%Y%m%d_%H%M%S)

# 创建工作目录
mkdir -p ${BACKUP_DIR}/${DATE}

# 备份关键数据
rsync -av --delete /home/nicola/.openclaw/workspace ${BACKUP_DIR}/${DATE}/

# 清理旧备份 (保留 7 天)
find ${BACKUP_DIR} -type d -mtime +7 -exec rm -rf {} \;

echo "✅ 备份完成：${BACKUP_DIR}/${DATE}"
```

### 📝 使用说明

1. **赋予权限**
```bash
chmod +x auto-backup.sh
```

2. **执行备份**
```bash
./auto-backup.sh /mnt/backup
```

3. **定时执行** (每天凌晨 2 点)
```bash
crontab -e
# 添加：0 2 * * * /path/to/auto-backup.sh /mnt/backup
```

### ⚙️ 配置选项
- 备份目录：可自定义
- 保留天数：7 天 (可调整)
- 备份内容：workspace 目录

**需要我帮你配置定时任务吗？** (是/否)
```
