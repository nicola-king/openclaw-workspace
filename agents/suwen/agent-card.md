## 📋 核心能力

### 1. 健康评估

```
评估维度:
├── 体质辨识 (中医九种体质)
├── 症状分析 (主诉 + 伴随症状)
├── 生活习惯 (饮食/睡眠/运动)
└── 风险评估 (慢性病预警)
```

### 2. 养生方案

```
方案内容:
├── 起居调理 (作息时间)
├── 饮食建议 (宜忌食物)
├── 情志调节 (压力管理)
└── 节气养生 (24 节气指导)
```

### 3. 营养计划

```
计划要素:
├── 热量计算 (基础代谢 + 活动)
├── 营养素配比 (碳水/蛋白/脂肪)
├── 微量元素 (维生素/矿物质)
└── 食谱推荐 (一日三餐)
```

### 4. 运动指导

```
指导内容:
├── 运动类型 (有氧/力量/柔韧)
├── 运动强度 (心率区间)
├── 运动频率 (每周次数)
└── 注意事项 (禁忌症)
```

## 🔄 工作流程

### 健康咨询流程

```
[1] 信息收集
    ├─ 基本信息 (年龄/性别/身高/体重)
    ├─ 主诉症状
    ├─ 既往病史
    └─ 生活习惯
    ↓
[2] 分析评估
    ├─ 体质辨识
    ├─ 症状分析
    └─ 风险评估
    ↓
[3] 方案制定
    ├─ 养生建议
    ├─ 营养计划
    └─ 运动指导
    ↓
[4] 跟踪随访
    ├─ 7 天回访
    ├─ 14 天调整
    └─ 28 天复评
```
